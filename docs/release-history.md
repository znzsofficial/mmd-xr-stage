# 发布里程碑

当前线上版本及下一步看[交接页](./HANDOFF.md)。这里的测试数与设备结论属于对应提交，后续文档提交不改变线上功能。

| 功能提交 | 已发布内容与验证范围 |
|---|---|
| `c4d068a` | 去掉共享骨架的重复渲染同步与辅助碰撞体互碰，增加 Bullet 输入、原生步进和输出分段。275 项测试；[桌面基准与真实 Bullet 回归](./performance/xr-runtime-performance.md)。 |
| `bb3fa87` | 共用材质图的透明度取样去重。指定角色每次建模读回 19 → 3 次，透明度判断一致；271 项测试。[加载对照](./performance/viewing-and-diagnostics.md) |
| `a701677` | 省略舞台不用的四份骨骼调试快照，保留世界矩阵同步；新增 `physicsPoseWork` 和 `physicsRebuilds`。266 项测试。 |
| `6076029` | 泳池、草坪、Live House、简易地台近景精修；每景两个固定机位对照、模拟 XR 落点和切回通过。[制作方式](./scenery/README.md) |
| `5b13356` | 纸鸢站、泡影渡口、返场染印社。屏幕模式和模拟 XR 验证了选方向、角色换手、VMD 跟随及切景清理。263 项测试。[四幕清单](./gameplay/README.md) |
| `f02fbea` | 晨光礼拜堂。模拟 XR 验证中央过道和侧窗附近可放，长椅和台阶不可放，切回恢复。 |
| `a51d548` | 屏幕观看，与 VR 共用同页背包和布局；模拟验证跨模式续场，屏幕不会覆盖 VR 性能报告。 |
| `9405bcf` | 星环遗庭、星辉光剑；模拟 XR 检查亮灭、递给两侧腕骨、VMD 跟随和清理。 |
| `7b63232` | 四景增设泳旗与救生架、紫藤架、鼓组与电琴、柔光箱与刻度弧架。 |
| `e0060ba` | 腕骨递道具、左右换手和握姿微调；新增匿名 loader 阶段计时。 |
| `4c50b7b` | 泡泡枪、星孔盖印器和月面邮局。模拟手柄交替取还 10 次、三印成票通过；用户在 Quest 上反馈玩家道具可用。 |
| `091ade3`、`3c44ed7` | 四景设施、落点约束和异步贴图就绪更新。 |
| `a7f52fb`、`ac546a6` | 准备页「窗光工作室」、同页背包、窗边教室、就地工具与分景恢复。 |

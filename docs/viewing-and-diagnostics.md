# 观看模式与画质诊断

## 观看与调整

- 完成加载后默认显示精简控制条：播放/暂停、展开、退出。
- 展开面板保留模型、材质、灯光和物理调整；收起后仍可播放或退出。
- 加载失败报告与物理错误独立于面板展开状态。物理异常可点击查看完整分页详情，不会因为收起面板而消失。
- 调整面板中的重置视图也会把 HUD 放回默认位置。

## 诊断值的含义

从调整面板打开「画质诊断」。数据分为三类：

| 数据 | 来源与含义 |
|---|---|
| 进入时请求 | 本次创建渲染器时的 AA 和刷新率策略；未开启实验覆盖的倍率/注视点参数显示“运行时默认” |
| 会话刷新率 | `XRSession.frameRate`，不是所选预设中的目标值 |
| 回调 FPS / 毫秒 | 一秒窗口内的渲染回调频率与平均回调间隔，不是 GPU 渲染耗时，也不是合成器提交率 |
| 图层类型与总尺寸 | 当前 `XRProjectionLayer` 的 texture 尺寸或 `XRWebGLLayer` 的 framebuffer 尺寸，不冒充单眼分辨率 |
| 图层报告 AA | 仅显示 `XRWebGLLayer.antialias`；Projection 图层没有这个字段时显示“未报告” |
| 目标 samples | 当前 XR 渲染目标的 Three.js samples 配置，不是驱动实际采样数实测；普通离屏目标不计入 |
| 注视点强度 | 当前图层的 `fixedFoveation` 报告值；浏览器不暴露时显示“未报告” |

会话不可见或采样出现长间断时重置 FPS 窗口。退出时清除诊断数据，不在下一次会话显示旧读数。

准备页的自动刷新率仅显示“自动高/中/低档”，不承诺固定 Hz。AA、framebuffer 倍率等创建时参数需要退出再进入才能应用。

## 本地验证

- `renderDiagnostics.test.ts` 覆盖请求 120Hz、实际报告 90Hz，以及缺失字段、两种 XR 图层、采样中断和退出清理。
- `CompactPlaybackControls.test.tsx` 驱动播放/暂停、展开、退出与物理错误详情回调，不启动 WebGL。
- 头显中的文字清晰度、按钮命中和实际性能需要在 Quest 上确认。

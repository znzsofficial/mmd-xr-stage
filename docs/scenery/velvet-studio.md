# 黑绒私摄棚

从门口沿地板看过去，月相铜版画前是一张黑绒贵妃榻。把背包里的角色放在沙发前的一对铜色角标，既能拍单人肖像，也能并排放两个人。向右穿过宽门洞是试衣休息区：衣橱前还有一对落点，旁边是皮凳和带灯梳妆镜。两边在同一层，走过去不会重载角色。布景没有预置人物。

**操作条灯：** 摄影区入口左前方有一台带两块按键的立式调光台。屏幕用鼠标点；VR 收起公共菜单，将控制器射线对准按键，按下并松开扳机。「灯轨位置」在左、中、右三档间循环，天花轨道上的整盏柔光条随之移动；「灯光强度」在柔、标准、强之间切换。位置改主光方向，强度改主光输出，两项都会影响已上场 PMX 的卡通明暗。切景回来保留同一页内的档位；不会修改其他房间的光照预设。

**近看材质：** 贵妃榻的菱形拉扣面和背景厚帘有绒毛掠射光；沙发上的披巾、衣架上的吊带裙和系带袍有方向性缎光；短马甲、箱子和皮凳使用凹凸粒纹和较窄的表层反光。三件衣物各有独立裁片、悬挂点和真实开口，只是衣橱陈列品。月相版画与三种平铺法线由 [`bakeSurfaces.py`](../../src/mmdVrShowcase/scenery/velvet/bakeSurfaces.py) 离线生成。

## 接入与核对

- [`velvetLayout.ts`](../../src/mmdVrShowcase/scenery/velvet/velvetLayout.ts) 持有墙、门洞、家具占地、机位和站位。屏幕机位 `velvetPortrait`、`velvetLounge` 只移动镜头。场地中央 `(0,0)` 可以放置，穿墙或落在家具里的地板射线无效。
- [`velvetLight.ts`](../../src/mmdVrShowcase/scenery/velvet/velvetLight.ts) 的 `getVelvetLight` 和 `subscribeVelvetLight` 提供稳定的档位快照；`resolveVelvetLight(base,state)` 把实体条灯到主体的方向换算为共用方向光。`StageRoom` 同时把结果传给环境和导入角色。试衣区的局部灯只补衣橱，不是角色主光。
- [`velvetStudio.test.ts`](../../src/mmdVrShowcase/scenery/velvet/velvetStudio.test.ts) 用实际渲染几何查询玩家柱体，沿入口、门洞走到衣橱前，检查家具、穿墙射线及换档信号。硬件回归时在固定机位和静止 PMX 下从左档切到右档，确认脸部阴影换侧；再站到试衣区，近看凳面的粒纹和披巾的窄亮带。

### 已验（本地生产构建）

屏幕以鼠标点沙发及衣橱内部，放置均未提交；随后通过地板射线分别放下两份导入的测试 PMX，落点为 `(0.38,0,-1.32)` 和 `(5.04,0,-1.64)`。固定镜头和姿态，仅绘制第一位角色并读回 WebGL 像素：左灯移至中灯有 **8,846** 个像素 RGB 绝对差之和超过 6；同档位从强调至柔有 **12,946** 个。近距离检查了沙发、披巾、皮凳及衣橱裁片。

模拟 Quest 控制器收起菜单后，扳机各触发一次移灯和调光；用摇杆穿过门洞，在衣橱前实际通过背包射线放置 PMX。屏幕与模拟 XR 的 WebGL 着色器全部编译通过。尚未用 Quest 3S 真机测帧率或评价显示效果。

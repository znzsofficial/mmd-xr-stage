# 下一轮建模：中式婚礼喜院、Live House 后台、秦淮歌楼近景

**状态：压缩会话前的实施计划，尚未开工。** 线上功能基线是 `943379d`，共九景。用户点名要传统中式婚礼；下面的江南民居风格、两处旧景和分工是建议方案。下一会话先读[短交接](../HANDOFF.md)，再按本页分派。公开 README 保留原 badge 和技术章节，新景通过实景验收后再进画廊。

## 主景：花轿进门，穿院入喜堂

建议做一座**江南民居式喜院**（暂名「双喜堂」，建议独立 ID `weddingCourt`）。秦淮歌楼让人从楼上看台上的演员；喜院的中心是两个人并肩站在堂前，门外、院中、席边都能看见他们。视觉参考民俗陈设，不宣称复原某一朝代或地区的一套标准婚仪。

| 走到哪里 | 角色怎么摆，镜头看什么 | 需要实做的细节 |
|---|---|---|
| 巷口迎亲 | 一位角色站花轿旁，从门内回望能同时看到人和轿 | 做出轿杆离地的高度、抬杆绑绳、掀起的轿帘与踏脚；轿杆也有占地，不能穿过去放人。 |
| 天井入席 | 从影壁旁转入院子，沿两侧宴桌间的通路前进；从宾席斜看堂前双人全身 | 石板、灰瓦和木柱保留原色，红绸集中在门楣和礼案。席面近处做瓷盏、筷架和碗碟叠放的厚度，中央通路留空。 |
| 正堂行礼 | 礼案前并排放两位自选角色；从院中拍正面，侧廊拍半身 | 成对椅、礼案、双喜剪纸、烛台。留独立的脸部照明，不让背后的红墙、烛焰或悬匾淹没人脸。首版用静态陈设，不要求角色自带拜堂动作。 |
| 侧室整妆 | 从侧门到妆台旁放一个角色，再转身透过门洞看回喜堂 | 铜镜、梳篦、漆盒和窗上的剪纸；铜镜先用有色金属表现，不开实时反射相机。门扇和屏风真挡射线。 |

**第一步是摆两个人的灰模，不是画喜字。** 初版约定：礼案前的双人空地以 **3 × 2 米**为起点；主通路净宽约 **1.5 米**。把 `(0,0)` 留作「放在中央」的合法位置。第一版全程同层，可步行到每个取景点；同一场景不因跨院门或进侧室而卸载角色。门口回望、宾席斜看双人、梳妆台近看，是优先保留的三个镜头。尺寸是设计起点，实际用两名角色走位后可调。

## 哪些现有场景值得先改

1. **Live House：从侧幕到候场间。** [现有舞台](../screenshots/live-house.webp)已经有鼓、键盘、监听箱和观众区，但当前[落点](../../src/mmdVrShowcase/scenery/placementAreas.ts)集中在台面，[普通导览](../../src/mmdVrShowcase/scenery/roomViews.ts)只有入口机位。优先在一侧做真幕口，接同标高的候场角：折叠谱架、贴编号的巡演箱、搭在椅背上的外套，给角色留一个候场站位。从那里要能透过幕缝看到原舞台，再走上台；不用先开放整片低处观众席。原有返场幕纹、话筒和台中央落点都要回归。
2. **秦淮歌楼：把琴案和埠头做到一臂之内也经得起看。** [二楼俯视、楼上摆人](./qinhuai.md)已经可用，优先利用现有路线。从[琴案机位](../screenshots/qinhuai-music.webp)看琴身弧度、弦枕和桌缘，从[画舫机位](../screenshots/qinhuai-river.webp)看系缆桩、绕桩的绳结与石驳岸水痕。弦和绳只保留双眼近看真正可辨的轮廓，细纹进图集。琴案与埠头同机位前后对照，保住登楼视线、原站位和水域拒放。

泳池刚修复[水面着色器](../screenshots/pool-water-compile-fix.webp)，医院刚完成[近景陈列](./clinic-teaching.md)；建议本轮只在联调时回归。礼拜堂要是改透明彩窗或阴影，另排同场性能对照。

## 合入门槛

- **能走、能摆、能回望**：屏幕和模拟 XR 各走一次。喜院用两名角色和一件物件验证堂前并排、妆台旁放置、隔屏拒放、离景回来仍在原位；Live House 从候场进台；歌楼复测上楼与楼上恢复。只测试布局函数不代替实际鼠标/扳机射线。
- **实景可比**：每处交一张带尺度参照的内部验证画面，公开画廊只用可公开的实景。旧景固定镜头、灯光、阴影和画质重拍；婚礼至少交入口回望、堂前双人构图、侧室近景。以脸部可读、衣服不融进背景、桌脚和轿杆不悬空为准。
- **性能单列**：记录同机位的绘制调用、三角形、纹理；反复切出再返回，查几何/纹理是否持续增长。Shader 在真实 WebGL 编译出图；桌面模拟不换算成 Quest FPS。各组先跑专项，主代理统一类型检查、全测、构建、模拟 XR 和生产资源校验。真机近看舒适度下次自然游玩时再验。

## 婚礼之后的新景候选（未排期）

- **首推海边终点站**：站房檐下、站台尽头、通向海堤的步道共享海平线。搪瓷站牌旁拍全身，长椅边拍侧脸，从堤上回望站灯；与喜院的内向围合形成反差。先做安全站位和海风感，列车经过留作可选效果。
- **雨夜唱片行**：街边橱窗、试听位、收银台形成三段两三步可达的近景。雨玻璃和封套适合拍近景；不依赖背景音乐功能。
- **旧城皮影台**：在幕前看角色与影子，绕到幕后看灯架和皮影实体。先用一段绢幕验证透明发梢与剪影在双眼里是否稳定，再决定是否扩成完整院落。

## 后续功能：简单本地音乐播放（低优先级，未排期）

首版只选一首本地音频，进场后可手动播放／暂停、调音量，退出观看即停。音乐独立于 VMD，静止摆角色时也能听。先在普通屏幕验证；Quest 上没有音频文件时照常进场，不提示补文件。此项不占本轮五组建模名额，也不是喜院、Live House 或唱片行的验收条件。

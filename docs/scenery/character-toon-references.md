# 普通 PMX 的角色画风：卡拉彼丘与终末地

优先借鉴脸、头发和衣料对**同一盏主光**的不同反应：脸颊有连贯的明暗边界，发束保留成片的亮带，浅色衣褶在亮面仍可读。单纯拉高对比度会一起压黑眼线和衣纹。

**洛茜半身首图：**[官方 Operator Combat Demo](https://www.youtube.com/watch?v=A5C7-5vi9SM)的[第三张视频帧缩略图](https://i.ytimg.com/vi/A5C7-5vi9SM/hq3.jpg)用于对照脸颊、金发和帽兜，非同光基准。开发页选「Loader 原色」和「仿终末地 · Hybrid NPR-PBR」，用同一已求值的姿势、侧前 25° 机位、左前 60° 主光及固定曝光导出；两个原帧各 1200×1200，切回原色与首帧逐像素一致。脸颊以眼距及头部朝向组织大块明暗；头发在手绘发色上分受光面，衣服用已有布／皮反射，眼周与轮廓保留原材质。半身已见脸和发的区别，披肩及白衣仍偏平。原图和私有配置在 `local-review/screenshots/rossi-hybrid-bust/`。普通 PMX 可在对照页手填槽号，不推断其他模型的材质身份。卡拉彼丘仍保留；星铁只取可共用的眼周／刘海做法。

## 从作者资料看什么

洛茜第二版保留首图的脸、发、光线与机位；[衣料材质](../../scripts/webgpu-actor/endfieldCloth.js)按同一 UV 读取配套法线和参数，缎面与高 R 饰边各自反射。帧间对照在 `local-review/screenshots/rossi-hybrid-bust-v2/`：看红披肩折面及白衣明褶，暗侧的衣褶目前较硬。脸与刘海取样区逐像素相同，缺少配套图恢复首版。内部页只沿用既有的布料选槽，没有新增画风控件。

**着色范围和可复用实现：**通用按槽材质有方向光 GGX、Smith 近似与 Schlick Fresnel；第二版有图的衣料走法线／粗糙度／金属遮罩控制的美术高光，没用通用槽的 GGX。第二版的脸是头骨驱动的程序渐变。现有 loader 按视口像素外扩轮廓；专用平滑描边法线可参考 [OutlineNormalSmoother](https://github.com/JasonMa0012/OutlineNormalSmoother)（MIT），单独验近远机位的发梢断线／闪烁。这些是实现参考，并非鹰角管线证据。

**第三版走面部受光，不改二版衣料。** 社区[佩丽卡 FaceToonShader](https://github.com/Morgana-lgtm/Arknights-Endfield-Inspired-Perlica-Character-Shader/blob/HEAD/Assets/Shader/FaceToonShader.shader)将灯投影到头部坐标，用镜像的 UV 采 RG 控制脸影，另有几何自投影阶段。[实时皮肤散射综述](https://therealmjp.github.io/posts/sss-intro/)把明暗边界的扩散与穿过薄组织的光分开；[Three 快速透光示例](https://threejs.org/examples/webgpu_materials_sss.html)提供了可在材质内部做的透射参照。因此本轮：

- **脸图**：用本地模型脸颊、鼻梁顶点核对 UV，从 −X 到 +X，U 约由 0.2 升至 0.8。实际 SDF 在相同 V 的两颊 RG 均值分别约 .72 和 .34，据此约定光从 +X 来时镜像U。在已求值头骨坐标里判灯向，用同包的脸部 Ramp 为过渡染色，颈侧按控制图过渡回实际法线。找不到唯一配套、格式不匹配或缺少头骨，保留程序渐变。
- **薄处透光**：在原 PMX 绑定姿势按可识别指骨的蒙皮权重、皮肤到骨段的距离估计指尖厚薄，只给身体皮肤槽增加背光透射项。不把毛耳、衣物或整张脸当薄组织。这是局部近似；刘海投下的软阴影和多次散射另计。
- **出图判据**：同姿同光同曝光的二版／三版，分别从正前、左后及右后打光。先看脸影能否随光换边，再另看同一手的侧逆光开／关；衣料留作原位对照。沿用原 probe 和围绕同一角色的私有机位。

实绘：`local-review/screenshots/rossi-hybrid-bust-v3/face-lights.png` 可见脸影由鼻翼越过另一侧脸颊，顺光保留眼线；侧逆光阴面较二版更灰。`comparison.png` 为原 −60° 主光半身；原位白衣和帽兜／头发抽样未变。`hand-light.png` 为原手套与露指在同一近景 −145° 主光下的前后对照；变化大于两码的 10,479 个像素，RGB 变化逐通道 P90 为 +12／+3／+1。普通半身机位的身体皮肤取样未见该效果，不将手部放大图说成整人皮肤改善。

专题接续：[卡拉彼丘脸影、发束与眼周](./strinova-render-study.md)核对两份社区源码，并给出头骨旋转的对照；[终末地 Cloth1 参数图](./endfield-material-study.md)记录同槽双区域的离线转灯控制、R/A 取样约定和各自的保留条件。

## 没有专用贴图时

- **脸：**有作者指定、UV 匹配的脸影图才启用 SDF。只有普通底色时，保留眉眼与腮红；对已识别的脸材质减弱法线产生的碎阴影，让脸颊柔和分档。脸与衣服共用材质又无分区时，沿用原 toon，不按肤色猜遮罩。
- **发与衣：**保留 PMX 自带的 toon 渐变、球面贴图及原混合方式。没有发光带遮罩就沿用发纹，不额外叠白；衣料靠原渐变读出褶皱，不用全局曝光制造分层。

**同姿转灯参考（建议对照，非实测）：**用同一件本地 PMX，冻结同一已求值姿势，取同时看得见双颊、刘海和衣领的正面半身。固定机位、环境光、曝光及主光强度，仅将主光以同一仰角从角色左前 60° 经正前转到右前 60°。三个角度各并排比原 toon 与候选：两侧受光时脸影是否换边、眼线是否始终清楚、发亮带是否局限在发束、白衣亮侧能否分出衣褶。只比较角色同一部位，不用全画面平均亮度代替观察。

## 写实卡渲：用同一束光认出材质

[《终末地》主创访谈](https://www.gcores.com/articles/207170)描述的是美术目标：服装选一种真实材料作为参照，保留会随光线变化的手绘质感。舞台的内部样板从这条原则出发：白布保留褶皱、皮革呈宽柔高光、金属扣呈较集中的反射。只对玩家指定的原 PMX 材质槽试色，保留作者原图、肤色及脸部画法。若布料和金属印在同一个材质槽里，首版只能选一种材质；要分开控制，需有对应 UV 的区域遮罩。

**怎么试：**用 `pnpm dev` 打开 `/scripts/webgpu-actor/probe.html`，选一套本地 PMX 与贴图，先用「舞台平衡色」渲染一帧。切到「写实卡渲」，从当前模型的材质表分别填写布料、皮革和金属的原槽号，点「渲染对照」。同机位显示上一次 WebGPU 图和这一次；WebGL 一侧始终用原舞台平衡色。再切换主光和相机方位观察。设置只在开发页生效，不保存到演员或背包。

**实现与范围：**[三类材质](../../scripts/webgpu-actor/hybridToon.js)在原 toon 明暗与纹理之上使用方向光 GGX 和菲涅耳反射。布料、皮革、金属的粗糙度依次为 0.80、0.43、0.32；布料掠射角带少许柔光，金属另有随主光定向的软条形反光，颜色取自原材质和底色贴图。场景反射、发丝亮带和随光笔触尚未接入。只对选中材质的 RGB 节点增加运算，透明度及描边仍走原路径。

**桌面实绘：**固定同一原衣、VMD 第 4 秒、600×600，在原生 WebGPU 上渲染两档。先固定机位把灯从左前 60° 转到右前 60°，再固定左前光把机位从正面绕到 45°。对两机位都能看到的同一三角形中心，取「写实卡渲相对平衡色的亮度差」随视角变化的绝对值 P90，布料 **3.6**、皮革 **11.4**、金属 **22.6**（屏幕码值 0–255）；金属对视角变化的反应最大。左前光下被测白布没有 RGB 三通道均 ≥250 的像素。实际按钮切换时，未选脸部的 3,386 个取样像素无变化，切回平衡色后整张图逐像素恢复。本机并排动图：`local-review/screenshots/webgpu-hybrid/turn-light.webp`、`orbit.webp`。本次没有测头显帧时。

**终末地参数图的接续点：**洛茜的只读研究已结束。腕环和披风内衬在同一衣料槽，已找到同一机位的高／低 R 区域；两个区域的 A 也不同。5.2 模板的服装1用 P.R 混合金属支，P.A 在金属支直通粗糙度、光泽支用 `A^(1/2.2)`。另一作者的成品工程另有通道重排、材质接法和灯光条件，只作独立参考。若决定推进，仅在同一 PMX 上对比关图、单独启用 R、再启用 A；看转灯时腕环的反光与内衬的褶皱，然后决定保留或停止。尚未实现此映射；不扫全库、不据此复制 Blender 插件。精确机位、UV 和节点证据从 `local-review/README.md` 的「11-26 接续」找。

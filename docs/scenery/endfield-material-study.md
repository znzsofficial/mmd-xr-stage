# 同一衣料槽怎样分出腕环和内衬

**值得在内部材质页做一次 `关图 → 只用 R → R+A` 的同机位对照。** 目标是腕环随转灯出现、移走一段反光，而紧邻的内衬仍看得出布褶。CPU 控制显示：现有灯位足以测出腕环差异，却几乎照不到内衬的镜面方向。因此，常规转灯下内衬不变是好的隔离证据，不能用来否决或证实 A。以下是对[既有按槽样板](./character-toon-references.md#写实卡渲用同一束光认出材质)的一项局部提案，尚无接图后的 GPU 画面。

## 接哪两个数

只对当前演员明确选中的 **Cloth1 原槽**绑定其配套 P 图。依据是社区 5.2 模板「服装1」的实线，而不是游戏的通用通道表：`P.R` 是光泽支和金属支的连续混合权重，`P.A` 在金属支是直接的粗糙度，在光泽支是 `A^(1/2.2)`。把现有 cloth 当作非金属支、metal 当作金属支，是舞台自己的近似；这没有重建模板的整套光照或 IBL。

| 输入 | 在这一次实验中的用法 | 不据此推定 |
| --- | --- | --- |
| P.R | 原始 0–1，0 走布支、1 走金属支。保留中间值和抗锯齿边缘。 | 高／低阈值只用于圈测量区；不用它切硬边，也不把高 R 当成所有 PMX 的金属标签。 |
| P.A | 第二步分别控制两支的**感知粗糙度**。腕环主导的金属约由 .32 变 .573，应查高光是否展宽；内衬主导的布支约由 .80 变 .524，应查是否出现不合适的窄亮斑。 | A 不是透明度；其幂次只属于布支，不是整张 P 的 gamma。另一作者成品中 DDS 通道有重排，衣1实挂槽还用曲线和固定粗糙度；不能套在这张 PNG 上。 |
| P.G/B、N、发光 | 首轮都不启用。保留原面的法线与 PMX 已有球面图、toon、材质形态。 | 没有证据把 G/B 指定为遮蔽、布纹或自发光；法线的切线基、绿通道符号与强度也未经此对照。 |

## 怎样接进现有节点

1. **数据与颜色分开上传。** 一个可复现的实验入口是本地把 P 的 straight RGBA8 原字节按行打成 RG8：第一个字节放原 R，第二个放原 A；保留源宽高，校验 `2 × 宽 × 高`，用 `DataTexture(Uint8Array, w, h, RGFormat, UnsignedByteType)`、`NoColorSpace`、`premultiplyAlpha=false`。随后一次 `texture(P).sample(uv()).rg` 取出 `(R,A)`；重排后的 `.g` 来自源 Alpha，**不是**源绿色。这样避开 Canvas 在透明像素上预乘／丢失 RGB，以及 PNG 查看器的显示变换。保持 D 的既有 sRGB 标记，沿 loader 自己的 MMD 合成和平衡色流程；`conductorF0` 复用未打光的 D 采样和实时材质因子，别把已着色的衣纹再解码一次。见 [Three 色彩管理](https://threejs.org/manual/en/color-management.html)。
2. **复用底图的 UV，不拿 Blender 的 V 约定改 PMX。** 当前 fork 的 `createThreeBufferGeometry` 原样复制 UV0；`configureMmdTexture` 对普通 D 设 Repeat，`flipY` 缺省 false；底图 TSL 用 `texture(D).sample(uv())`。此样本的 P 行 0 是顶行，P 上传 `flipY=false`，无 `1−v`。P 与 D 用同一求值后的 UV0 和有效纹理变换／重复方式，不取附加 UV、球面 UV 或静态烘出的屏幕坐标。先指定双线性、无 mip 核对 level 0（像素中心 `u·w−.5, v·h−.5`）；再单测正常缩小时的线性数据 mip、腕环边缘串色及移动时闪烁。DataTexture 默认最近邻，别依赖默认过滤。仅同尺寸、同文件名不足以证明两图套准。
3. **混合两个分支的线性出光，再过一次亮部压缩。** 在 [`materialAdapter.js`](../../scripts/webgpu-actor/materialAdapter.js) 原本包 `material.colorNode` 的地方，只给被选中的表面节点传额外样本。令 `B` 为同一份已选基色节点（通常为平衡色后的线性 RGB），`C(B,r)`、`M(B,r)` 分别是 [`hybridToon.js`](../../scripts/webgpu-actor/hybridToon.js) 布／金属在末尾 shoulder **之前**的 RGB，保留各自的底色保留量、Fresnel、布料柔光／金属条形反光。三档如下：

   ```text
   关图  = shoulder(C(B, .80))
   只用R = shoulder(mix(C(B, .80),             M(B, .32),       R))
   R+A   = shoulder(mix(C(B, max(.12,A^(1/2.2))), M(B,max(.12,A)), R))
   ```

   `.12` 是防 GGX 奇点的实验下限，不是参考模板的值；上述两区均未触及。现在 `a2 = roughness ** 4` 和 `k` 是 JS 常量，接图后两者均须改为 TSL 节点运算；`a2=r⁴`、`k=(1+r)²/8`，GGX 分母可写成 `(1−nh²)+nh²·a2`。不可只插值两档粗糙度后算一个高光，也不要分别压缩两档再插值。共享 N、V、L、form；沿用现有世界定向条形反光（它**不随粗糙度变宽**）。输出沿用渲染器的一次显示转换。fork 已截掉的底色高光，后置节点不能恢复。
4. **关图要能原样返回。** 关图就是已有按槽 cloth；退出整个风格则还原所选平衡色或 loader 原色。保留原节点引用，不在切档时叠包；不动 D.A、`opacityNode`、alpha test、深度、描边、几何或阴影 helper。多槽共用 D 不扩展绑定。缺 P、槽歧义、UV 无法与 D 对齐、纹理解码／能力失败，沿用先前有效材质；若 R 可验证而无可信的源 A，则最多开 R。额外纹理由实验页持有：按演员、原槽和 File 身份提交，换人／换文件废弃迟到结果，退出时只释放自有资源；不往背包或 PMX 写私模识别规则。

## 新的离线控制：按可见面转灯，不按贴图颜色猜高光

两圆各 901 个像素，使用旧 CPU 遮挡判定选中的面，另读原 PMX 的位置／法线／UV，以相机射线和三角形重算重心插值。与原 UV 的最大差 **<.0001 纹素**；straight P.R/A 和重排 RG8 的双线性样本全部相等。腕环 R 中位应为 **.976**，误用预乘会变 **.558**；错翻 V 后，腕环 R 仍有 **.761**、内衬仍为 0，**只看一亮一暗会漏检**。内衬 A 却从 **.242** 变 **.514**。另用 `(R,A)=(128,64)/255` 中间值校验：正确 R 是 .502；错当 sRGB 是 .216；按 A 预乘是 .126。将来可将这个探针读回原始数据缓冲，不要从经过显示转换的灰图直接读码。

固定 V、真实顶点法线及 D 给出的金属色，采用实验页主光颜色、强度及仰角（约 34.4°）。仅为隔离材料增量，把所有取样点的已着色底层固定为线性中灰 .18；这**不是**原衣成图。下表对每个像素先取两档之差 `d`，再取 `−60°、0°、+60°` 三个灯位的 `max(d)−min(d)`，最后取区域中位数。单位为 shoulder 后、sRGB 编码后加权的 0–255 亮度码值，未取整。

| 转灯时材质差异的变化 | 腕环 | 内衬 |
| --- | ---: | ---: |
| 只用 R − 关图 | 11.78 | 0.00 |
| R+A − 只用 R | 5.05 | 0.31 |

在正前灯，腕环中 `R+A − 只用 R` 的逐点差 P05／P50／P95 为 **−26.29／+6.16／+9.37**：部分亮芯减弱，周围可以变亮。仅把金属粗糙度还原为常量后，腕环几乎不剩 A 响应；仅把布粗糙度还原后，内衬几乎不剩 A 响应。**低 R 并不意味着 A 没作用**：单将主光对准内衬的中位镜面方向（世界方位 +73.2°、仰角 −48.1°），其 `R+A − 只用 R` 中位从普通三灯下不到 1 码变为 **+8.39**。这盏下方灯只用来判别接线，不用来证明舞台观感改善。

## 最小实绘与停线标准（待做）

- **同一 PMX、一个原槽、一张 P。** 用既有静止姿势和裁幅，固定演员、相机、曝光、环境光。只转主光 `−60° / 0° / +60°`，每角度取上述三档；补一张同光关图复位。按同一像素取两区差值，并在原显示尺寸看腕环反光有没有在表面移动、旁边的内衬折线有没有被照平。不要用两区谁更亮作比较。只在怀疑布支接错时，补一次上述下方灯的 R 与 R+A 配对。
- **保留 R 的条件：**预先以「腕环三灯逐点差的变化中位 ≥4 码、内衬 ≤1 码」作可见性筛查，还得在原尺寸认出随灯走的反光；只是整圈一起变暗不算。未选不透明脸部、alpha 和描边不变，同光关图恢复到既有按槽 cloth。取样约定没过先修输入，不靠调曝光掩盖。修正后仍无局部观感收益就停在按槽方案。
- **是否加 A 单独决定：**正前灯与侧灯下比较亮芯和两翼；只在腕环的宽窄变化确实更贴合表面、附近内衬褶皱对比保留且不显塑料时保留。对正常灯位无额外可见收益、只在诊断灯下好看，或引入闪烁／高光抹纹，就只留 R。两档都通过也只说明此槽值得接图，不扩展其他角色、普通 PMX 或整套舞台。

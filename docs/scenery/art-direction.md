# 布景美术方向：给游戏角色拍照的实景片场

本页记录整体方向。首轮已实施两处：[喜院门楼：漆门、石灰和灰瓦](./wedding-materials.md)，[教室窗边：清漆木板、钢架与脚垫](./classroom-materials.md)。其他场景的建议仍未实施。希望空场有地方感，放进不同画风的游戏角色后，人仍是第一眼的主体。

**海站的都市日景。** 从站台能实走到喷泉，再绕进长椅树荫或逛花店旁的小巷。入口要留天空和能看懂的下一段路，沿街店面只围两侧；从座位仍能回望海堤。白天的反光集中在水面、湿石和喷口，干铺装、衣料与树皮留出不同粗糙度。玩家已说明收进星环大厅的小片场过于压抑，后续布景优先走这种开阔取向。

## 先看光和体积，再决定画什么纹理

同样是浅色墙，[教室](../../src/mmdVrShowcase/prep/classroom-window.webp)靠窗边亮带、过道和背光桌腿，就能读出阳光从哪里来；[门诊候诊廊](../screenshots/clinic-entrance.webp)的标牌很清楚，但长墙、门套与地面之间明度接近，空间显得浅。[喜院门口](../screenshots/wedding-court-entry.webp)的剪影足以识别江南宅院，屋檐下和受光墙面的区别却比轿帘花纹弱。给所有墙加颗粒，只会让同一张平面更忙。

制作时先把镜头放在角色站位：远处靠房屋轮廓、地面大色块和天光认路；两三米处靠柱脚、窗洞、门槛和物体接地读出深度；走到一臂之内，才让木孔、釉面、织纹显出来。沿着柱身或桌沿移动头部，能看到窄亮边的是倒角和反光，不能用画死的白线代替。先给檐底、墙根、桌下等固定结构画局部遮蔽，直射光的方向交给场景主光；不要把同一条投影既烤进颜色又用实时阴影画一次。

## 各景保留什么，先改哪里

| 布景 | 保留的风格 | 最值得改的一组关系 |
|---|---|---|
| 双喜堂 | 暖灰宅院衬朱红花轿 | **先做门楼一跨**：石灰墙漫反射柔而干；红漆门转头时才有一条宽亮带；灰瓦沟与瓦脊受光不同。门下阴影有进深，院内双人脸仍亮。花轿留作红色焦点，不把墙也染红。 |
| 秦淮歌楼 | 水面冷、灯笼暖、人物站在两者之间 | 从埠头看台口，先分清灯纸透光、栏杆漆面和岸石湿线。湿暗与稍强的反光止于水线，干石不作统一镜面；琴案已有纹理，优先让周围木台和它接得上。 |
| 窗边教室 | 窗侧午后光、干净的黑板背景 | 一套桌椅先区分清漆木面、磨亮的手肘区和喷漆钢管；木纹沿桌板长轴，板边露出封边。窗帘保留透亮的大褶，不在远处画密织线。 |
| 草坪／泳池 | 明亮的校园日光，沿步道能认方向 | 草坪先看树冠内外明暗和不规则轮廓，再看叶脉；小径压实处与松土边缘不同。池边先分干燥防滑砖、溢水槽附近的湿带和上釉池砖；计时台的金属支架靠窄边反光，不靠浅灰色假装金属。 |
| 医院 | 明洁、可读、有自然补光 | 以[用品柜](../screenshots/clinic-casework-side.webp)为参照，下一处选候诊长椅：软垫压缝和宽钝反光、扶手细亮边、椅下柔影。墙膜保持干净；不靠污渍营造真实。 |
| 晨光礼拜堂 | 室内彩窗与室外暖石庭的明暗转换 | 石窗框和池沿用磨圆边、浅石孔；彩窗负责带色，墙面仍留中性色。日光不要把整座庭院洗成同一种米黄。 |
| 星环遗庭 | 深色剪影与星图刻度，保留幻想感 | 只在扶手常触处露铜，凹刻留暗，仪器刻线在近处可读；远桥靠边灯找路，避免细金线铺满后双眼闪烁。 |
| 简易地台／Live House | 一处中性试镜，一处演出灯光 | 地台作为比较人物材质与肤色的基准；Live House 维持当前内容，不进本轮精修。 |

## 第一轮怎样判断值得推广

建议先拿**喜院门楼**做样板，再用**教室窗边桌椅**检查同一方法能否适用于现代日景。保留原机位、灯光、曝光、画质和角色姿态，各拍全身、近景与短距离横移。连做两组消融对照：维持底色只切换法线／粗糙度，看转头时亮部是否跟着表面走；维持材质只切换局部遮蔽，看接地是否改善而人脸不被压暗。纹理按实物尺寸定比例，不从底色亮度直接生成凹凸（金色字并不等于凸起、黑墨并不等于凹槽）。

验收优先级：① 黑发深衣与浅发白衣都能从背景分出来；② 近看三种材质不用靠颜色也能区分；③ 退回全身机位，细纹不摩尔闪、不抢脸；④ 低画质关闭实时阴影仍成立。记录新增的图集下载字节、尺寸、绘制调用和切景回访的纹理数；最后在 Quest 3S 双眼移动时复核。先验证这两景，再决定哪些材质值得带去其他地图。

**实际全身对照。** 用两份测试 PMX 在[喜院](../screenshots/portrait-readability-wedding.webp)和[教室窗边](../screenshots/portrait-readability-classroom.webp)同灯光换位。喜院两人轮廓清楚，但纯白衣身表面的层次弱；教室深衣清楚，浅发贴亮窗时一段发缘与背景的局部亮度比只有约 1.20:1。不要仅凭「没被家具挡住」判定可读。测试人物只用于拍摄，不随产品进场。

# 舞台可见泌乳｜首版提案，未实现

**交接状态：待会话压缩后讨论。** 本页没有对应的运行时改动、排期或真机验收。下面写的是候选行为，不是当前按钮的承诺。

现有功能是[分侧存量、回充与 HUD 观察](./pose-and-body-states.md#泌乳目前能看到什么)。建议首版只做一件事：玩家点「排出左侧／右侧」时，在**已适配角色的对应侧**看见短暂的乳白液滴。沿用现有按钮，先不做触碰触发、衣物湿痕或 PMX 分侧胀缩。

**一次按键，一笔变化。** 由现有[草稿排出操作](../../src/mmdVrShowcase/bodyState/store.ts)返回该侧实际减少量，再通知[当前房间](../../src/mmdVrShowcase/bodyState/room.ts)显示一次。左 10%、右 50% 时按左侧，最多显示左侧 10 个百分点对应的量；右侧不扣，空侧不出。不要监听百分比下降来触发：拖滑杆、取消草稿、撤销保存都可能降值，却不是排出动作。

**先验证落点，再接效果。** 提议先用一个有明确出口的测试模型，逐侧标定随骨骼运动的位置与朝向，再试转身、缩放和暂停。胸骨只能作跟随基准，不能证明乳头位置或衣物是否遮挡。没有可靠出口或未确认露出时保留原有扣量和 HUD 反馈，提示「仅更新充盈度」，不在衣物外猜点、也不排队补播。

**预览和保存分开。** 按钮可在草稿上即时预演；保存只提交存量，不再播放。放弃改动恢复存量并清掉仍可见的液滴；换人、隐藏、退出或切景也清场。绘图区只读，不写账；不用骨盆道具的释放队列或账本。

**开工门槛：**先证明同一侧出口在屏幕和双眼中都跟随正确，再验“低存量只排剩余量、一次按键只扣一次、另一侧不动、撤销／换人无残留”。参考 PMX 的着装轮廓不能作为衣下出口证据；未适配时能正确退回 HUD 就算该模型通过。

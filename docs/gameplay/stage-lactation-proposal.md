# 舞台可见泌乳｜实际排出和存量设置

从角色的「互动 → 泌乳」可按住排出，松开停止继续排出；[身体设置](./pose-and-body-states.md#泌乳目前能看到什么)只调整角色参数。能定位且未被挡住时，液滴从角色自身对应侧挂起、脱落；同一位置有衣物或无法定位时，只改变存量。「身体观察 → 乳房」使用这份真实存量显示分侧充盈和百分比；这是观察示意，不是对 PMX 进行分侧缩放。

**什么叫能定位？** 出口依据模型作者明确标记的局部顶点形态，绑定到实际皮肤三角形；播放、摆姿和缩放时读取变形后的表面与朝向。仅有胸骨或笼统的胸型形态，不足以推断出口。HUD 示意图不提供舞台坐标。

支持有相容标记的线性蒙皮 PMX，包括加载器按材质拆开的模型。分片皮肤用自己的三角形和当前形态权重定位；检查遮挡时也检查衣物、配饰和其他皮肤分片。不能找到明确出口、采用 SDEF／QDEF 或超出可验证规模时显示「未找到出口」，不影响分侧回充或使用观察图。

**怎么确认露出？** 独立的乳头／乳晕皮肤材质与可靠局部形态可用于识别。普通身体材质可能画了衣物，需要在「确认露出」逐侧勾选，且当帧没有遮挡。区分「待确认裸露」「出口被遮挡」和「未找到出口」：被挡时可进入「服装」检查内衣与外衣，返回等待该侧显示「可出滴」。衣物或头发重新盖上该侧时，效果停止，不会等露出时补播。

**实际按住才扣量。** [房间](../../src/mmdVrShowcase/bodyState/lactation/roomMilk.ts)在首次验证按键仍按住的显示帧尝试排出，之后持续按住才按节奏重复；如果两帧之间已松手，会提示轻点未排出。每次单侧最多扣 3.4 个百分点，剩余不足时只扣[实际差额](../../src/mmdVrShowcase/bodyState/store.ts)。没有有效追踪、切景或停帧时不累计欠账。挂滴按当前角色的显示尺度，从皮肤出口形成；脱落后在舞台中独立下落，无需开启物理。

**设定和操作分开。** 点「互动」下方的「初始乳量」，调存量和回充时间，保存才写入当前演员；放弃恢复保存值。只有「互动 → 泌乳」的按压会扣除实际用量并尝试出滴。观察、滑杆、自动回充、保存和撤销都不会额外出滴。

复验时区分[实模与合成夹具](../performance/actor-tools-regression.md)、屏幕／模拟双眼和[Quest 3S 真机](../performance/next-quest-export.md)。参考 PMX 的着装轮廓不能作为衣下出口证据；未适配时正确退回 HUD 就算该模型通过。

# 舞台可见泌乳｜实际排出和存量设置

从角色的「互动 → 泌乳」可按住排出，松开停止继续排出；[身体设置](./pose-and-body-states.md#泌乳目前能看到什么)只调整角色参数。能定位且未被挡住时，液滴从角色自身对应侧挂起、脱落；同一位置有衣物或无法定位时，只改变存量。「身体观察 → 乳房」使用这份真实存量显示分侧充盈和百分比；这是观察示意，不是对 PMX 进行分侧缩放。

**什么叫能定位？** 出口依据模型作者明确标记的局部顶点形态，绑定到实际皮肤三角形；播放、摆姿和缩放时读取变形后的表面与朝向。仅有胸骨或笼统的胸型形态，不足以推断出口。HUD 示意图不提供舞台坐标。

首版支持有相容标记的线性蒙皮 PMX。分拆网格、SDEF／QDEF 或规模超过可验证上限的模型退回数值反馈；这不妨碍正常播放、分侧回充或使用观察图。

**怎么确认露出？** 独立的乳头／乳晕皮肤材质与可靠局部形态可用于识别。普通身体材质可能画了衣物，不能靠名字判断：需要玩家逐侧确认裸露，仍须通过出口和当帧遮挡检查。不会按私模文件名或贴图指纹放行。衣物或头发重新盖上该侧时，效果停止，不会等露出时补播。

**一次按键，一笔变化。** [扣量操作](../../src/mmdVrShowcase/bodyState/store.ts)只把本次真实差额[同步交给当前房间](../../src/mmdVrShowcase/bodyState/lactation/events.ts)。左侧仅余 10% 时只能扣 10 个百分点，右侧不扣，空侧不出。挂滴跟随表面，脱落后按舞台重力下落；不需要打开 Bullet。

**设定和操作分开。** 在「身体设置 → 泌乳」调存量和回充时间，保存才写入当前演员；放弃恢复保存值。只有互动页的按压会扣除实际用量并尝试出滴。观察、滑杆、自动回充、保存和撤销都不会额外出滴。

复验时区分[实模与合成夹具](../performance/actor-tools-regression.md)、屏幕／模拟双眼和[Quest 3S 真机](../performance/next-quest-export.md)。参考 PMX 的着装轮廓不能作为衣下出口证据；未适配时正确退回 HUD 就算该模型通过。

# 玩法与道具

**原计划的四幕均已上线。** 它们是四个现有布景中的互动，不是四个额外的场景。先选布景，再打开背包：VR 选「玩具」并用侧握键，屏幕模式直接点本景的玩法按钮。没有角色也可以先试演。

| 布景／玩法 | 道具与操作 | 可以在哪里玩 |
|---|---|---|
| 简易地台 · 月面邮局 | 用星孔盖印器依次点亮月牙、彗尾和双星；首枚决定邮徽，收回盖印器仍可看邮票。 | VR 手柄盖印（`4c50b7b`） |
| 晴空草坪 · 纸鸢站 | 借风线轴交给角色，播动作时可换左右风签；收回线轴结束放飞。 | 屏幕、VR（`5b13356`） |
| 夏日泳池 · 泡影渡口 | 用贝壳泡泡枪选左门或右门，彩环引小船从所选一侧出发。 | 屏幕、VR（`5b13356`） |
| Live House · 返场染印社 | 先染左翼得日出幕，先染右翼得月夜幕；完成后把丝带话筒交给角色，收回话筒仍保留幕纹。 | 屏幕、VR（`5b13356`） |

**通用玩具**：星辉光剑在所有七个布景都可递给角色，VR 可用侧握键展开或收起；泡泡枪的自由吹泡泡用 VR 手柄。一次只拿一件玩具，不占角色或物件名额；切景或退出会结束本轮互动。屏幕导演按钮与玩家在 VR 中手持玩具是两种操作。

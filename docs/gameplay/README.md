# 玩法与道具

VR：**背包 → 玩具**，选手柄拿取。屏幕：选中已放置角色，在「角色道具」操作。十件道具中，九件能递给有腕骨的角色；遥控跳蛋由角色佩戴、玩家持遥控器。一次用一件，不占角色或物件名额，切景收回。[递道具与调握姿](./vr-controls.md#把道具递给角色)

## 道具接触与手柄震动

在 **右 B → 更多 → 玩家 → 震动** 选「关／轻柔／标准」，默认轻柔。

| 道具 | 操作 | 持有手的反馈 |
|---|---|---|
| 硅胶假阳具 | 软头碰可见角色表面。按侧握释放；绑定附件时按[当帧喷口](./pelvic-attachment.md#精液与计量)判定内部计量、外喷或不释放。 | 初触短振一次；持续贴着不连震，移开再碰可重触发。 |
| 无线按摩棒（第三页） | 侧握依次切低、高、关；一圈／两圈灯表示运行档位。换手保档。「接触反馈」可另选目标角色的表情。 | 空中也有节律：低档每秒 4 拍，高档每秒 7 拍、稍强。启用接触反馈时，棒头初触加重一拍，贴住不重复加重。暂停动作照常振；打开菜单、递给角色或失追时停振。 |
| 遥控跳蛋（第四页） | 拿遥控器，选自选成年角色 →「佩戴跳蛋」，可按 1 cm 调位置。开启角色物理，让佩戴件从衣物外侧靠近有活动刚体的裙片；暂停时也可试。 | 遥控手的节律与佩戴件同步。常振、渐强、间歇驱动佩戴件轻微摆动；衣物碰撞不额外震遥控手。换手保档，收回佩戴者、换件或切景即停。 |

**拨衣与短振是两件事。** 打开「角色物理」，从外侧用杆身或端部托起有活动刚体的衣摆，暂停也能拨动，按摩棒停机也能托衣。只用杆身推衣不会另发一次道具脉冲。尖端触碰可见表面的短振不依赖 Bullet；递给角色后也不会震玩家的手柄。失追后先移出衣物，再靠近。

## 四幕玩法

| 地点 | 怎么玩 |
|---|---|
| 简易地台 · 月面邮局 | VR 用盖印器依次点亮月牙、彗尾和双星。首枚决定邮徽，收回盖印器仍可看邮票。 |
| 晴空草坪 · 纸鸢站 | 把线轴递给角色，播动作时切换左右风签；收回线轴结束放飞。 |
| 夏日泳池 · 泡影渡口 | 用贝壳泡泡枪选门，小船从所选一侧出发。泡泡枪也能在其他布景吹泡泡。 |
| Live House · 返场染印社 | 先染左翼得日出幕，先染右翼得月夜幕。完成后可把丝带话筒递给角色。 |

后三幕也支持屏幕操作。其余三件是侧握开合的星辉光剑、随腕摆动的羽毛刷和双面并蒂莲团扇。[布景操作与站位](./vr-controls.md#在布景中给角色选位置) · [待选互动提案](./interactive-scene-studies.md)

选中已放置的角色后可[手动摆姿势、锁脚或保存姿势，并预览身体状态](./pose-and-body-states.md)。

点角色可直接开[服装、互动与身体观察](./actor-tools.md)。「互动 → 插入」有[校准入口、手动滑轨／自动支架、XR 手持、实测杆位剖面及液量计量](./pelvic-attachment.md)。

# 玩法与道具

**十件道具在任何布景都能拿。** VR 打开「背包 → 玩具」，选左手或右手。可吹泡泡、开合光刃，或轻握硅胶假阳具的侧握键喷出一小股液滴。九件手持道具能交给有腕骨的角色；遥控跳蛋由角色佩戴，遥控器仍在玩家手里。切景会收起道具。

**第三页：按摩棒、羽毛刷、并蒂莲团扇。** 按摩棒侧握依次切换低档（一圈灯）、高档（两圈灯）、关闭，换腕保档。低／高档接触自选成年角色时，硅胶棒头局部压缩，手持它的控制器在初触时短振。可点目标角色的「接触反馈」，选其已有的顶点表情，调节叠加强度；默认不改表情。暂停时同样有效，移开或关档恢复。屏幕端把棒交给手腕，用握姿或动作让棒头碰到模型。羽毛刷与团扇随腕摆姿。

**第四页：遥控跳蛋。** 拿遥控器后点自选成年角色 →「佩戴跳蛋」；在角色旁分别调横向、高度和前后，每次 1 cm。遥控器留在手中，收好菜单后侧握依次切换关、常振、渐强、间歇，本体和遥控器同步显示节律。屏幕端从「角色道具」选择、佩戴，再点模式或调位置。目标没有腕骨也能佩戴。隐藏或收回佩戴者、换道具、切房、退出都会结束这一对设备。

**用道具拨衣：** 在场内开启「角色物理」，拿硅胶假阳具或按摩棒，从衣摆外侧慢慢托起、撤手。道具的杆身和端部推动的是 PMX 已有的活动刚体，裙片、发梢等部位能动到哪里取决于作者设置的碰撞组与关节；不会给普通皮肤凭空生成软体。暂停 VMD 也可操作，按摩棒不必开机就能托衣。另一个效果是道具本身的软头接触可见模型表面：假阳具不需按侧握，按摩棒开低／高档才压缩，偏好开启时初触有短反馈。换手、追踪丢失或在衣物内重新出现后，先移开再接近。

|---|---|---|
| 简易地台 · 月面邮局 | 用星孔盖印器依次点亮月牙、彗尾和双星；首枚决定邮徽，收回盖印器仍可看邮票。 | VR 手柄盖印（`4c50b7b`） |
| 晴空草坪 · 纸鸢站 | 借风线轴交给角色，播动作时可换左右风签；收回线轴结束放飞。 | 屏幕、VR（`5b13356`） |

**星辉光剑**初始收刃，握一下展开，再握一下收起；换腕保持亮灭。泡泡枪的泳池贝壳装饰不是额外一件道具。一次只拿一件，不占角色或物件名额。

## 上手与验收

**接下来做什么（候选）**：[合卺对影与霜岬回波](./interactive-scene-studies.md)列出了场内触发点、近看／远看各能看见什么，以及进入真机测试前要过的检查。

**玩家移动**：[模式切换与按键](./vr-controls.md#普通与自由移动) · [碰撞范围、模拟结果和真机短测](./player-movement.md)。模式只改变玩家怎么走，不会放宽角色落点或关闭手部碰撞。

**本地音乐（可选）**：在准备页「音乐」选一首本机音频。屏幕观看用底部的「播放音乐」和音量滑杆；VR 按右手柄 B →「更多」→「音乐」。暂停角色动作或切换布景都不会打断音乐。退出观看即停，再进场手动从头播；返回准备页可更换或移除。没选曲也可直接进场。

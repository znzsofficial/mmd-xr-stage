# 看动作时收起菜单：下一轮方案

**观看与角色首层已实现。** 用户选定观看时默认净场，右手 B 呼出。模拟 XR 已实际用扳机、B、腕侧捏合和低头捏合走通；实机舒适度待看。[当前操作](./vr-controls.md)。下文保留设计目标；泳池连接仍待两区真机回场基线。

## 从进场到看一段舞

- **初次进空场**：一次可关闭的提示，告诉用户如何选景、从背包放角色、再次叫出菜单。退出再进或从草坪回教室，不重复教学。
- **观看**：播放或暂停都可以净场。B 在面前呼出「播放／暂停、背包、场景」，有动作才显示进度；设置和退出在同一面板的次要位置。播放后收起；打开子页时一眼能找到「返回观看」。选位置过程中 B 优先取消，不提交移动。被遮住的角色仍能从背包找回。
- **点角色**：首层只给「换动作」「摆位置」。移动、转身、大小在角色旁的摆放页，不在公共设置重复一份；持道具时才多出「递给角色」，角色已持有时换成「调整握姿」。其余角色管理（含收回、材质）从角色详情进。一次只接收一块面板的输入。
- **拿道具**：「背包 → 玩具」就地拿五件，逐件保留可关闭的「用法」；切景是用法里的另一个动作。没有拿道具时不出现握姿或玩法按钮。暂停后伸手拨衣即可，接触衣服不会打开菜单。
- **手追与错误恢复**：无手柄也能召回。原型采用面向自己的腕侧「菜单」目标，由另一只手远射线点选；不占用普通近距离捏合或系统手势。需在纯手追首次进场、丢失一只手再恢复时验证可发现性，并提供可定向点选的回退入口。加载失败时主动显示重试、继续、退出；不能要求用户先找到 B。

**角色自己的手托裙摆**在场内「接触细调」，默认关闭。它独立于胸部受压和玩家手追拨衣。

**验收**：看完整段动作时没有常驻板；从净场按 B 后一次点选即可暂停；背包放置、换动作、异景递道具不经设置；取消摆放不移位；拨衣、持物侧握和射线点菜单互不误触。用实际扳机／手追射线跑模拟，再在 Quest 验可达性。屏幕观看沿用鼠标／触摸入口，不借用 B 键。

## 工程顺序

1. HUD 先改观看与角色首层。可并行做[持续播放对照](../performance/README.md)：同一角色、机位、VMD，物理关作基线；开物理后分别测参与求解的接触和裙摆约束，固定步长与质量。仅在探针里做隔离，不能把禁用有效接触或删减 PMX 约束当成上线优化。以单步耗时、播放帧间隔 P95、衣摆和骨骼轨迹、暂停首触一起验收。
2. **回教室**先用同一角色回放恢复队列；有新版 Quest 成功的 `roomRestores[]` 后校准。队列前慢就拆旧区释放／新区挂载；模型或动作任务慢才试同页有上限的只读解析结果复用，贴图阶段慢先区分解码、上传与让步；就绪后慢则查首次姿态求值与首帧提交。缓存按文件及依赖身份隔离，限制内存，退出／淘汰可释放，不保留离区 Bullet 世界。验证回到原站位和原播放时刻，没有 T 姿首帧、残留道具或累计资源增长。计时终点是可见 XR 回调，不是屏幕呈现。
3. **下一段路选草坪 → 夏日泳池**：沿草坪小径到池边，近处有可摆角色的站位，回望看得到来路。只运行所在区，远处用简模；跨界再启用水面、角色和玩法。门槛是先取得两区回场基线，再做两区／三区同机位、同 VMD 对照：检查稳定播放 P95、往返等待和重复往返的纹理／几何体数是否持续增长；未去泳池时不启动水面和渡船更新。超出基线重复测量的波动就先保留两区。每次只接一段，原场景菜单可直达。

# 下一轮场景互动：留一幅能陪角色演出的画面

**设计提案，尚未实现。** 喜房帘绳、摄影棚灯台和两条风道已可用。下一步推荐先做双喜堂的「合卺对影」：坐在普通屏幕前也能看到完整效果，不必先飞到另一颗星才能判断它值不值得做。

## 第一幕：双喜堂 · 合卺对影

把机关放在礼案右边的红线旁，婚书压着半张剪纸作提示。**点一次绳结，两盏灯分别在礼案后墙投出半幅剪纸；最后两只燕子合成一幅双喜灯影。** 角色站在原有双人脚位，正好在画面前景。站在礼案旁看，先看到红线收紧、穗子摆动；退回院中，仍能认出两盏灯和墙上的成图。再点一次收灯，回到原来的正堂。

第一版只做一个绳结、一段收放动作、一幅原创窗花。穗子绕实际悬挂点转动；用一张带留白的剪纸遮罩在后墙上投色，两半共用同一张图。不改全局曝光，不用两盏实时阴影灯。收回和切景时结束演出，不把瞬时动画写进角色快照。

**过关条件**：在「庭中 · 望双灯喜幔」和「近看 · 婚书与合卺礼器」各看一遍；摆两名角色播放动作，看灯影是否在人物背后、白衣是否还留有细节。扳机按住不连发，拖动镜头不点灯；从妆间隔墙点绳不生效。切景再回来，演员在原位，灯影已收。

## 第二幕：霜岬星 · 接收回波

落地先在天线底座看到两道没对齐的刻线。**点机身的调谐轮，天线转向母星；对准后，冰面上一圈窄光沿地形向外传播。** 飞回母星，罗盘边保留一段冰蓝的回波刻度，作为这次实地观测的结果。再点底座可重播，离开整个星系清除。这样，飞去霜岬星有了只在当地能做的事，回来也有东西可看。

先做三档调谐和一个目标方向，让普通屏幕和 VR 共享同一操作。后续若需要连续旋钮，再做拖动。天线接收盘围绕轴承转，底座和脚架固定；波前按球面方向算角距离，绕着已有冰脊传播，经过仪器和地平线时正确遮挡。近眼淡出，不用铺满视野的闪光。风道仍只由 G／左 X 启动，调谐不移动玩家。

**过关条件**：环外能调谐但不会误起飞；从球背不能隔着星体操作。带一个正在播放的 PMX 出发，回来后实例、动作和脚位没变。Rapier 延迟或失败时测站照常响应。站在着陆环、天线侧面和母星罗盘三个地方检查效果；在 Quest 3S 同机位比较待机和回波播放时的慢帧，再决定是否增加粒子。

## 写机关时怎么接

- **输入**：已有的 [`useSceneAction`](../../src/mmdVrShowcase/scenery/input/useSceneAction.ts) 接受布景 ID、视线判断和激活回调；把 `bindings` 挂到真正的绳牌或旋钮上。机关自己给出世界坐标下的遮挡规则，不能只靠透明拾取盒。
- **状态**：离房即结束的灯影用当前房间的状态。风道往返不卸载星系，因此观测结果可由星系组件持有；不用扩展全局背包或新增房间 ID。动画进度写在本地 ref 中，不按帧发布到 store。
- **画面**：先用一个近景验证材质和动作，再用一个演员全身机位验证轮廓和构图。只有触发后的几秒需要推进动画；完成后保留静态结果。逐眼检查实际材质的编译与链接，再做真机舒适度和帧率验收。

# 下一轮角色工具：压缩后从哪里接

**本轮范围：**`5bc0d37` 是流程评审的基线。玩家指定今晚收尾首次互动、做角色回应与水滴胸型局部样式，之后用一份 Quest JSON 看性能。摆姿势增强仍是明确需求，下一轮再决定最难摆的动作。

## 摆姿势：先选要摆成的动作

现在已经能[锁脚坐下、抓腕推拉、绕轴旋转、微调肘膝、撤销、命名存姿并恢复原动作](./pose-and-body-states.md#从站姿调成坐姿)。续聊先选一个**现在摆起来费劲的具体姿势**：例如要把手稳放在膝上时，是难选中手腕、难判断前后距离，还是调上身时要反复把手放回去？答案分别指向选点、微调或临时固定接触点，不要一开始就给所有骨骼加滑杆。这些是讨论例子，不是已选功能。

选定后，用同一角色在屏幕和 XR 各走一次「摆好 → 收起控制点 → 再调一处 → 恢复原动作」。看手脚实际落点、衣物和腕上道具是否跟随，而不只看控制点数值。已有的[锁脚与抓腕实模基线](../performance/actor-tools-regression.md)可直接沿用；骨链不完整时应保留可用的操作。实现入口：[姿势编辑器](../../src/mmdVrShowcase/pose/usePoseEditor.ts)、[姿势求解](../../src/mmdVrShowcase/pose/poseSolver.ts)。

## 乳头与乳晕：在批准的水滴胸型上比较局部样式

试样 01 因方硬被否决；**水滴形 02 已获确认并用于动态图**。`5bc0d37` 只有固定色带；本轮[正式画笔](../../src/mmdVrShowcase/bodyState/breast/art/teardropPaint.ts)将「轻柔」与「圆隆」画在同一曲面上。角色 → 身体观察 → 乳房，定格后切两款：正面看范围和边缘过渡，斜／侧面看乳头的起伏与高光。按本页背包资产记住选择。

## 上轮流程评审与后续玩法

「选穿衣角色 → 整理衣着 → 互动 → 看细节 → 回原位继续」已有[实模与模拟双眼证据](../performance/actor-tools-regression.md#从角色面板开始的互动)。评审认为短板是：不看读数时，还不容易凭演员本身分辨短触、停留和撤开。这是体验判断，不是新一轮真机测试结论。

- **角色回应已选入本轮。** 重点是看着演员能否分辨刚停住和继续推进的区别；短触两次也不应与持续停留相同。撤开后回到原动作的表情。
- **支架手法回放次之。** 现有自动往复能调速度和幅度，但不能录下玩家自己的停顿。双角色持具、撤出回流继续留作候选；[候选行为与计量边界](./pelvic-attachment.md#假阳具玩法候选尚未实现)保留在道具指南。

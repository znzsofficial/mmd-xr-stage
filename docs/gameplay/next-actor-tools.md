## 当前角色流程

- **整理衣着再互动：**从「服装 → 查找漏件」预览实际材质槽；同一皮肤表面上的衣物可换同角色、同 UV 的贴图。[衣柜与互动路径](./actor-tools.md)。「互动 → 泌乳」用面板按键，不是直接捏模型；本机带衣版的分片出口是这次修复的反例，不能再笼统归为“不支持这类模型”。[出口与遮挡判据](./stage-lactation-proposal.md)
- **观察与事件：**插入页左栏看部位，右栏选手法和释放目标。外阴三款靠连续曲面的轮廓区分，膜缘和首次有效进入记录均为可选。子宫两处入口共用演员记录：卵数、单次游戏概率、当前阶段／孕日；改预览日期、切景或重开图都不重抽。[生育进程与成功／失败分支](./pose-and-body-states.md#生育进程从排卵玩到着床)
- **视觉与文案：**二次元风格体现在角色反应、粉嫩曲面、近景和事件节奏。按钮只写「开始往复」「释放到宫腔」「取消释放」等普通游戏动作，说明放详情。后续取舍见[流程评审](./actor-flow-review.md)。

**本机审图：**在 Git 忽略的 `local-review/` 下，`art/vulva/index.html` 是三款无标签对照、偏压与撤回；`art/uterus/event-02/` 有 38° 受精动图、小图与失败分支；`verification/actor-round/` 保存实际操作台画面、泌乳和球际验收记录。不复制到公开文档或部署目录。

# 角色工具：当前玩法与下一步候选

当前玩法见下节，线上版本见[交接页](../HANDOFF.md)。后文带提交号的选型与实测按当时构建保留。

## 当前角色流程

- **穿裙摆姿：**开物理，套用仰卧抬腿后可继续调脚踝、改膝盖朝向并保留姿势。[玩家操作](./pose-and-body-states.md#快速体位) · [前裙掉回与深跪穿模的区别](../performance/pose-cloth-contact.md)。最新同机位对照从本机 `local-review/README.md` 顶部进入。
- **双人换姿：**在半透明搭档的「调整姿势」里直接换体位或移动一侧腿，保留后再推进。16 种是单演员姿势目录数；其中 7 种做过[搭档双眼与接触回归](../performance/actor-tools-regression.md#搭档姿势单腿编辑与重新跨入)。半跪的头胸避让已复核，手指与宽松衣料仍可能局部相交。
- **看孕态参考：**在身体观察中手动切换图示，以相同角度对照外阴、阴道和子宫的独立主图。子宫斜面能看睡脸、贴颊的小手与脐带，侧面看蜷曲轮廓；这是[只读参考插图](./observation-reference.md)，不是演员怀孕状态。
- **整理衣着再互动：**从「服装 → 查找漏件」预览实际材质槽；同一皮肤表面上的衣物可换同角色、同 UV 的贴图。[衣柜与互动路径](./actor-tools.md)。「互动 → 泌乳」用面板按键，按实际出口和对应侧的遮挡区分可见液滴与仅扣存量。[出口与遮挡判据](./stage-lactation-proposal.md)
- **观察与事件：**插入页左栏看部位，右栏直接按目的地释放。外阴图下选膜缘，子宫图看完整器官；在「卵子」按强制排卵、调游戏受孕率，看[一次实际交付的融合或散开](./pelvic-attachment.md#一次释放的受精演出)。身体观察只读该演员的结果。
- **视觉与文案：**二次元风格体现在角色反应、粉嫩曲面、近景和事件节奏。按钮只写「开始往复」「释放到宫腔」「取消释放」等普通游戏动作，说明放详情。后续取舍见[流程评审](./actor-flow-review.md)。

**本机审图：**在 Git 忽略的 `local-review/` 下，`art/vulva/index.html` 是三款无标签对照、偏压与撤回；`art/uterus/event-02/` 有旧版 38° 受精动图、小图与失败分支，供画面对照；`verification/actor-round/` 保存当时的操作台、泌乳和球际验收记录。这些画面不验证新版判定，也不复制到公开文档或部署目录。

## 候选：主动表情

当前[角色回应](../../src/mmdVrShowcase/play/actorResponse.ts)已经随实测进退组合眼睑、嘴形和头部动作。下一步建议给玩家主动控制：在已选演员的半身镜头里，按住「吐舌」调用作者的表情，松开恢复这一刻应有的脸；支持停姿，也支持播放中的 VMD。

先看素材再定适配：两份本机 PMX 分别有 3 个和 1 个吐舌相关的顶点形态，现有[人脸形态识别](../../src/mmdVrShowcase/play/faceMorphs.ts)还没收录它们。只有名称和类型经过核对；要实际推到半量和全量，看是否连带眨眼、嘴角或牙齿，再决定能否和自动表情叠加。无适配形态的演员保留现有眼口回应。

**收工条件：**两份实模在固定半身和侧面都看得清动作，舌头不明显穿唇；松手、失追和换演员都不残留、不串人。暂停时和按前同帧比，播放时和同一 VMD 时刻的未按对照比。这是待确认的里程碑，尚未开发。

**后备：**若更想用公园长椅，先让一张椅子提供真实座面高度、朝向和两脚的地面支点，再验证不同腿长的两名演员坐下、起身及恢复。当前姿势按演员原站立面拟合，把「后撑分腿坐」应用在椅旁不会自动坐到椅上。

## 摆姿势：把手留在落点

`fb03527` 在[锁脚坐下、抓腕推拉、微调肘膝及命名存姿](./pose-and-body-states.md#从站姿调成坐姿)的基础上解决了「摆好手以后调身体，得反复把手放回去」。用同一姿势对照自由腕和固定腕，而不以控制点停在原位作为验收证据。

[角色工具回归](../performance/actor-tools-regression.md)区分实模、合成夹具和模拟双眼。实现入口：[姿势编辑器](../../src/mmdVrShowcase/pose/usePoseEditor.ts)、[姿势求解](../../src/mmdVrShowcase/pose/poseSolver.ts)。

试样 01 因方硬被否决；**水滴形 02 已获确认并用于动态图**。`5bc0d37` 只有固定色带；`e26b03a` 的[正式画笔](../../src/mmdVrShowcase/bodyState/breast/art/teardropPaint.ts)将「轻柔」与「圆隆」画在同一曲面上。角色 → 身体观察 → 乳房，定格后切两款：正面看范围和边缘过渡，斜／侧面看乳头的起伏与高光。按本页背包资产记住选择。

## 上轮流程评审与后续玩法

`5bc0d37` 时「选穿衣角色 → 整理衣着 → 互动 → 看细节 → 回原位继续」已有[实模与模拟双眼证据](../performance/actor-tools-regression.md#从角色面板开始的互动)。当时评审提出：不看读数时，还不容易凭演员本身分辨短触、停留和撤开。这是后续改动的理由，不是对当前版本的真机评价。

- **角色回应在 `e26b03a` 上线。** 实模固定机位对照了刚停住和继续推进的脸部变化，完全撤开、回落后的裁图与原帧一致。无适配表情的模型照常互动。
- **支架手法回放已接入手动支架。** 自动往复仍是参数驱动；录放保存玩家实操的行程与停顿。双角色持具、撤出回流继续留作候选；[候选行为与计量边界](./pelvic-attachment.md#假阳具玩法候选尚未实现)保留在道具指南。

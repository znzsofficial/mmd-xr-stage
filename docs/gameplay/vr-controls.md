# VR 控制面板

**右手 B 召回菜单**，可以播放／暂停、打开背包或选景。手追时抬起左腕，用另一只手指向「菜单」；也可低头点「菜单」。点「返回观看」收起面板。首次进入空场有提示，加载失败会主动显示详情和重试。

**背包 → 角色／物件 → 放置**：用射线指向地面，脚印表示可放，叉号表示不可放。按下并松开扳机确认，B 取消。净场中点角色，可换动作、摆位置或调整材质；隐藏或被遮住的角色仍能从背包选中。[导入与续场](./asset-workflow.md)

## 普通与自由移动

**B → 更多 → 玩家**。两种模式都用左杆平移、右杆横拨转向，速度为慢走 1.2、常速 2.4（默认）、快跑 4.8、疾行 8 米/秒。轻推摇杆可微移。

- **普通模式：**贴地、有碰撞，右 A 跳跃。觉得太高，可按 10 cm 调眼高（最多 ±80 cm），头手一起移动，脚仍在地面。摇杆不能穿墙，现实中探头越界时仍可看见舞台。
- **自由模式：**可穿过墙和楼板，右杆前推上升、后拉下降，松开悬停，不自动过门。切回普通模式落在最近一次安全脚位；重置视角回本景入口。飞行不放宽角色落点，也不改变衣物重力。[碰撞范围与验收](./player-movement.md)

## 角色物理与接触

在角色旁选[「摆姿势」](./pose-and-body-states.md)后，用射线选圆心、扣住扳机平移手柄；圆心是关节，菱形是你想放到的位置。「身体状态」顶部直接选胸型、周期或泌乳：点「乳房观察」转动示意图，点「周期」对比日期。切栏目保留预览，点「保存到角色」才保存。[「骨盆附件」](./pelvic-attachment.md)负责外阴附件、手持／支架和实测剖面。

改完想先看角色，点「收起看角色」。角色旁只留「预览中 · 继续编辑」，点它回原栏。右手 B 仍能召回公共菜单；返回观看后可继续同一角色的草稿。看[按钮版泌乳](./stage-lactation-proposal.md)时，先选角色自身左侧或右侧，以当次回执区分舞台出液和只改存量。

| 想调什么 | 在哪里调 |
|---|---|
| 手柄或手追拨衣 | **B → 更多 → 角色 → 角色物理**。暂停也能拨动有活动刚体的衣物，不需第二个开关。追踪恢复时若手已在衣服里，先移开再接近。 |
| 手柄震动 | **B → 更多 → 玩家 → 震动：关／轻柔／标准**。软头初触、遥控节律和原生衣物碰撞的区别见[道具触觉](./README.md#道具接触与手柄震动)。隐藏手模型仍可用菜单射线。 |
| 贴身轻压 | 手追轻触随角色物理生效；[指腹附近的形变](../performance/fingertip-indent.md)依赖网格和蒙皮。角色自己的舞蹈由「胸部受压形变」控制（默认开），不改变原动作手臂轨迹，不依赖物理开关。 |
| 手部碰撞体与托裙补救 | **角色 → 接触细调**，关物理后改、再开生效。手柄半径 4／8／12／16 cm（默认 8），手追掌面与指腹按比例调整。默认标准摩擦、无回弹。「角色托裙摆」仅补模型缺失的掌面碰撞，默认关，不生成托举动作。 |
| 人物偏亮 | **角色 → 角色色彩**，可在同一姿态对比「保留亮部细节」与「明亮（原版）」。这只调 MMD 材质；全景曝光在「环境」。[对照图](../scenery/model-highlight-color.md) |

「环境」也管灯光、阴影、天空、雾、网格和布景原有人物；「场景人物」默认关，只影响医院护士等环境模型。地面光、轮廓光限简易地台与 Live House。

## 准备页还可以调什么

准备页负责导入、补缺图、起始布景、继续观看和导出 JSON。「画质与设备设置」可选 Quest 预设、目标刷新率、抗锯齿、阴影分辨率等；目标 Hz 是向设备申请的值，实际 Hz 看会话报告。日常观看设置在场内。

## 手持玩具与月面邮局

**B → 背包 → 玩具**，每页三件，每行有「用法」。扳机选菜单，侧握使用道具。简易地台的盖印器对准月牙、彗尾、双星，分别按下和松开侧握；首枚决定邮徽，集齐三枚后可收回道具留下邮票。「清空邮票」重来。

硅胶件在第二页，无线按摩棒在第三页，遥控跳蛋在第四页。[十件道具的操作、佩戴和接触条件](./README.md)

## 三幕布景玩法

从道具「用法」可前往所属布景。草坪交角色线轴、选风签；泳池瞄准左／右门发船；Live House 的染色顺序决定幕纹。三幕也支持屏幕操作，切景或退出结束。[道具与按键](./README.md#四幕玩法) · [屏幕操作](./screen-viewing.md)

## 把道具递给角色

1. 拿起手持道具，点已放置的角色 →「递道具」→ 左手或右手。只有已识别的腕骨能接；交接失败，道具留在玩家手里。遥控跳蛋改选「佩戴跳蛋」，不用腕骨。
2. 在角色旁「调整握姿」可抬高／压低 15°、移近／移远 1 cm、绕握柄转 30°。道具跟随腕骨和掌心，不扭角色的手。屏幕在「角色道具」里调。
3. 「收回道具」只归还玩具。收回角色、换件、切景或退出也会解除挂接；回场恢复演员，不恢复手持状态。

## 在布景中给角色选位置

主列表有 **10 个入口**，共 16 个独立布景。六个小片场从[星环遗庭传送大厅](../scenery/README.md)的实景星门进入，B 菜单可返回大厅。射线只检查脚位和视线，不保证任意大小的模型全身都能放下；近距离触碰衣物不会选中或移动角色。

- **琉璃星系：**角色摆在母星北台。走近或点编号预览风道，环内站稳后新按左 X 起飞／返航；足印上右 A 可跨跳。五条风道通卫星，两座小屿只能跨跳。[白脊采谱与星系路线](../scenery/opal-planet.md)
- **校园：**普通步行可从[教室、门诊、草坪和泳池](../scenery/campus-garden-routes.md)过门，跨区保留头向，各景各存布局。[电玩厅](../scenery/arcade-hall.md)须瞄准实际楼层，可在洞口按左 X 换层；[校园环线](../scenery/campus-arcade-loop.md)可走到泳池计时台。
- **江南：**[双喜堂](../scenery/wedding-court.md)可在礼案前并排摆两人，沿[枕河街](../scenery/jiangnan-river-street.md)去[秦淮歌楼](../scenery/qinhuai.md)；楼上、楼下共享本景角色名额。
- **其他站位：**礼拜堂过道与水庭干地、星环遗庭的圆庭和三座露台都可摆角色。家具、池水和露台外不接受落点。[全部布景与机位](../scenery/README.md)

## 性能与诊断

**B → 更多 → 环境 → 画质诊断** 可看 FPS、绘制调用和物理调试。`runtime.update` 计时不等于 GPU 耗时；纹理数量不等于显存字节数。退出 VR 后先在准备页导出上次会话 JSON，再刷新或重进。[Quest 3S 分次短测](../performance/next-quest-export.md)

手柄配置和模型从本站 `public/xr-input/1.0.20/` 加载。已有真机反馈确认手柄和手追可用；准星斜视可读性、不同道具的实际震感和稳定帧率仍需真机判断。[输入与会话生命周期](../xr-session-lifecycle.md) · [HUD 视觉规范](../../DESIGN.md)

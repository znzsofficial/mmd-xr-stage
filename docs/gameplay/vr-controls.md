# VR 控制面板

[四幕玩法与道具](./README.md) · [导入与续场](./asset-workflow.md) · [性能记录](../performance/viewing-and-diagnostics.md)

**看动作时默认净场。** 右手 B 呼出「播放／暂停、背包、场景」。用手追时，把左腕抬到面前，再用右手射线点「菜单」；只有一只手时可低头点「菜单」。点播放／暂停或「返回观看」都会收起公共面板。首次进空场有一次提示；错误恢复仍会主动出现。场景可直达全部布景；切回来会恢复该布景自己的布局。

点「背包」，找到角色或物件，选「放置」。用射线瞄准地面，看脚印和朝向，扣下并松开扳机确认。无效位置会显示叉号；B 可取消，原位置不变。净场中点已放置角色，首层是「换动作」和「摆位置」。转向、大小、收回在「摆位置」里；「详情」可调材质。手持玩具才显示「递道具」，角色已持有则显示「调整握姿」。隐藏角色仍能从背包选中。画质、物理、操作与诊断在公共菜单「更多」。

教室、泳池与草坪使用日景天空，可见太阳与角色主光方向一致。教室关闭实时阴影时用沿日照方向投到地板的窗格光斑，开启时由实时阴影表现；泳池用动态水面表现波纹与高光。灯光按钮从「自然观看」依次切换到「小型演出」及其他预设。「柔化高光」默认关闭，使用 Neutral 色调映射，不增加全屏渲染或影响 HUD。

**B → 更多** 打开「玩家／角色／环境」左侧栏。默认先调玩家；一次只显示一个对象的设置。

- **玩家**：选择普通或自由模式，调移动速度、转向角、手模型、面板朝向和手柄震动。移动模式和速度会记住；旧版眼高偏移不再把玩家带到空中。
- **角色**：「胸部受压形变」默认开，按原舞姿读取上臂、前臂和手掌位置，只让接触附近的胸部骨骼压缩、移开后回弹。不限物理开关；衣料需有对应蒙皮权重才会跟随。没有可识别的专用骨骼就跳过，深度穿透不保证消失。屏幕模式也可在播放条实时切换。「接触细调」收纳玩家碰撞体和独立的托裙摆试验。
- **环境**：灯光、阴影、柔化高光、天空、雾、网格、曝光与视距。地面光和轮廓光限简易地台、Live House。选景统一从公共菜单「场景」进。「画质诊断」里可开关设置面板帧率和额外物理调试。
- **场景人物**：医院的「更多 → 环境」可隐藏或恢复诊室里原有的坐姿护士。椅子、教具和自行导入的角色不受影响。该场景原本没有人物时，不显示这个开关。

## 普通与自由移动

右手 **B → 更多 → 玩家** 切换模式。两种模式都是左摇杆平移、右摇杆横拨转向。速度按钮依次切换 **慢走 1.2、常速 2.4（默认）、快跑 4.8、疾行 8 米/秒**；轻推摇杆可微移，速度与画质独立。

- **普通模式**：跟随头显的真实眼高，按右手 **A** 跳起，落地前不能再跳。地板、墙、门楣、家具和低顶限制虚拟移动；从矮台边走出去会下落。右摇杆纵向不会抬升视点。真实俯身或迈步仍按头显追踪；若头部跨入墙内，舞台视野暂时遮住，退回来即恢复。正常过校园门线会切景。
- **自由模式**：右摇杆前推上升、后拉下降，放开悬停。可以穿过墙顶、楼板、导入物件，飞出布景；掠过门线不会误切场景，可用菜单选景。切回普通模式会回到本景最近一次安全落脚点。重置视角回到本景入口。
- **摆放与接触是另外两件事**：自由飞行不会让角色能摆到水面、家具内或隔墙的地面。普通模式下静态导入 GLB 按网格限制玩家，导入角色只用身体中心的简化占地，不用裙摆当墙。手柄／手追能否拨衣仍由角色物理控制，不受玩家移动模式影响。

## 角色物理与接触

**B → 更多 → 角色**。打开整场的角色物理后，手柄和追踪到的手就能拨动有物理的衣摆，暂停也可以，不需要第二个开关。下方「胸部受压形变」默认开，关物理也能用。手柄震动在「玩家」，物理调试在「环境 → 画质诊断」。

**手追轻触**：暂停后让食指从角色前方接近，轻按胸前贴身衣料，再横向滑动一点、移开。网格足够细且有相应胸骨权重的表面会在指腹附近轻微凹陷并回弹；深按、掌压与宽松裙摆仍保留原有响应。这项随角色物理生效，与舞蹈胸部受压开关独立。[适用模型和实测](../performance/fingertip-indent.md)

用**手追**时，打开角色物理，掌心和指腹会让接触处的专用胸骨及对应蒙皮受压，收手后回弹。暂停或尚未绑动作也可以。这个接触随玩家物理生效；「角色动作」里的形变开关管角色自己的手臂。若追踪中断后手在模型内部重新出现，先移出来，再接近。

在**接触细调**里可直接关物理、修改以下设置，再开物理应用：

- **玩家的手**：球半径 4／8／12／16 cm（默认 8），摩擦易滑动／标准／更抓牢，回弹无／弱／强。默认标准摩擦、无回弹。半径是手柄碰撞球的尺寸；手追的掌心和指腹按比例调整，不是每根手指都有 8 cm 粗。
- **模型补救：缺少手掌碰撞**：「角色托裙摆（试验）」默认关。只有舞步本来就让角色的手掌经过裙下、模型有裙摆物理却缺掌面碰撞时，才值得试；已经有手部刚体的一侧保留原配置。不会生成托举动作。

普通屏幕在**播放条**调物理和胸部受压，在**背包 → 接触细调**调角色托裙摆；没有 VR 玩家的手部碰撞设置。

## 准备页还可以调什么

可选起始布景和 ZIP 文件名编码（自动／Shift-JIS／GBK）。导入、背包、补缺图、屏幕观看、进入或继续 VR，以及有记录时的 JSON 导出也在这里。

「画质与设备设置」默认收起。Quest 快捷预设为**安全／平衡／清晰**，「自定义」只显示当前状态。高级项有画质档、画布像素比、目标刷新率（自动／72／80／90／120 Hz）、抗锯齿、阴影分辨率。启用「应用头显分辨率与周边细节设置」才可指定投影倍率与周边细节。目标 Hz 是设备请求，场内帧率显示是测量值；阴影**分辨率**在准备页，阴影**开关**在场内「环境」。

## 手持玩具与月面邮局

「背包 → 玩具」的道具不占角色／物件名额。选左手或右手拿，食指扳机操作菜单。任一布景都能按住侧握键吹泡泡；持硅胶假阳具时每次轻握从尖端喷出一小股液滴，松开再握可重复。简易地台的盖印器需分别对准月牙、彗尾、双星，每次松开再握一下。三枚齐后出现星空邮票，第一枚决定邮徽；收回道具保留邮票，「清空邮票」可重画。切景或退出结束本轮。

第三页的**无线按摩棒**初始关闭，侧握键每次新按下依次切到低、高、关；握柄上方一圈／两圈灯对应棒头的两种摆速。**羽毛挑逗刷**无需按键，可转动手腕或递给自选成年角色摆姿。两件都可换到另一侧腕骨；收回、替换或离开布景会关停按摩棒。

## 三幕布景玩法

在任一布景的「背包 → 玩具」都能拿取全部道具，每行有独立「用法」。有专属玩法的道具可从说明前往所属布景。不放角色也能用手柄试演：

- **放学后的纸鸢站**：在晴空草坪拿「借风线轴」，轻握侧键切换左右风签。把线轴递给角色后，进入她身旁的「调整握姿」，用两枚风签选方向。风筝线从线轴放出，不拉动手骨或衣物。
- **泡影渡口**：在夏日泳池拿「贝壳泡泡枪」，瞄准水上的左门或右门，再轻握侧键。彩环穿门后，小船从所选一侧出发。递给角色后，用角色旁的「左门发船／右门发船」再次开演。收回玩具会结束航行。
- **返场染印社**：在 Live House 拿「丝带话筒」，瞄准左右翼各握一次侧键。先染的一翼决定展开方向；将话筒递给角色就能配合 VMD 谢幕。收回话筒保留幕纹；在「背包 → 玩具」点「清除染印」可换顺序。

三幕在切景或退出时结束。普通屏幕的[玩法按钮与机位](./screen-viewing.md)无需手柄。

## 把道具递给角色

1. 在「背包 → 玩具」给**自己的手**选一件道具，不用为递道具换景。星辉光剑在任何布景都可轻握侧键展开光刃，松开再握一次收起；递给角色或换到另一只腕骨时保留亮灭状态。
2. 用食指扳机点已放置的角色（被挡住时可从背包选中），在**角色旁的工具**选「递道具」，再选「给角色左手」或「给角色右手」。如果某一侧不可选，先确认角色已显示；只有识别到腕骨的一侧能接。交接失败时，道具仍在你手中。
3. 道具跟随正在播放的腕骨，默认将道具自己的握柄放在掌心，枪口沿手掌朝指根方向，话筒和剑柄朝拇指一侧。缺指骨的模型使用简化对齐。角色旁「调整握姿」可抬高／压低 15°、移近／移远 1 厘米，或点「转握柄」绕握点每次转 30°。屏幕在已选角色的「角色道具」下也能调整。不改写动作，也不会让张开的手指强行握拳。

「收回道具」会把玩具归还背包，角色仍在场上。重新从玩具页拿一件、收回角色、切景或退出 VR，也会解除挂接。角色持物不随布局恢复。

## 在布景中给角色选位置

- **双喜堂 · 江南喜院**：巷口花轿旁适合单人迎亲照；进门绕过影壁，在喜堂礼案前并排摆两个人。退到两席之间看全身，或从东侧门进妆室，在铜镜旁放第三位。[机位和推荐脚位](../scenery/wedding-court.md)
- **草坪／门诊步道**：从木栅端的花园石路走进门诊东门，出口在两排候诊席之间；原路出门回草坪。和教室、泳池一样，过门前先确认或取消放置，回到各区会恢复各自摆放的角色。医院内的三道房门只是普通通道。
- **妇科医院**：从门诊候诊廊进各房间，诊室在左手近处、手术室在右手、女卫生间在左手走廊尽头。可以把角色摆在诊室帘前或手术台旁的空地。从门外对准地面时要能实际看到落点，墙、家具和隔间不接受角色落点。
- **秦淮歌楼**：从埠头进堂，堂前三级台阶通往戏台；面向正门沿左侧长梯可上二楼。站在听曲廊看台上角色，也能在楼上放置另一位角色。画舫、水面、梯级和家具不接收角色。[楼梯和导览图](../scenery/qinhuai.md)

- **晨光礼拜堂**：在过道靠祭坛的石花上摆全身，或在左侧百合彩窗前拍半身。背向祭坛穿过常开的橡木双门，向前约 15 米到水池中心；绕池到远侧看钟楼，或沿侧边花坛前往石拱廊。池畔与廊间能放角色，水池、花坛、门扇、柱脚和长椅不能放置。

- **窗边教室／晴空草坪**：背向黑板，沿窗边过道走出后门，短檐下的砖径接到花园；回望教学楼可沿同一条砖径进教室。各区分别保留摆法与播放位置，过门前收起脚印并等加载结束。
- **草坪／泳池东岸**：从藤径穿过泳场门楼，上青釉地带便是东岸；沿岸可直走到远端计时台。回程从门楼看得见藤架中央的小径。水面、椅脚和钟座不能放人。[三条路线与六个方向](../scenery/campus-garden-routes.md)
- **星环遗庭**：从罗盘圆庭穿过残拱，左摇杆沿灯桥前行。十字路口直走是北侧观星台，左转是西侧星图库，右转是东侧测星台。桥面、三个露台的空位都可以从背包放角色，栏边、仪器基座和桥外虚空不能放。北台向南回望，旧圆庭会成为角色身后的远景。逛远后按右手 B 可召回菜单。
- **夏日泳池**：从浅水端的水深砖往对岸看，两道仰泳旗压在泳道上方。池边救生圈和梯子旁可拍侧面，留意脚印是否避开支架和水面。
- **晴空草坪**：紫藤花架下的小径和树下长椅前可以放角色；背向太阳看格栅在草地上的斜影。柱脚、树干、长椅、栅栏与土丘不能落脚。
- **Live House**：面向舞台，鼓组在左、电琴在右，中间错缝木地板留给角色跳舞。沿着地板胶带能找到乐器边界；转身可以看楼座和调音台。
- **简易地台**：双侧八角柔光箱夹着后方刻度弧架，圆台中央适合正面全身机位。器材位于可摆放台面以外，网格仍可单独开关。

手柄及手追的远射线使用约 39 mm 的空心双色光标。背包放置时会检查布景中可站立的地面（教室避开家具、泳池避开水面）。这是对落脚点的检查，并不模拟任意尺寸模型与房间的几何碰撞。近距离手部触碰不会选中模型。

## 输入资源可靠性

手柄 profile 与手柄/手模型统一从本站 `public/xr-input/1.0.20/` 加载。此前使用 XR 库默认的 jsDelivr 地址；模拟器阻断该 CDN 后，原生 session 仍报告两个手柄，但应用 `inputSourceStates` 为空，手柄与射线消失。手模型也依赖同一 CDN。没有用户设备的网络日志，不能认定这就是其设备上唯一的原因。

同源修复在阻断 CDN 的完整应用 IWER 测试中验证了左右手柄模型、扳机释放展开菜单、切换左右手模型，以及捏合释放收起菜单；这次通过模拟设备事件驱动真实射线，而不是直接调用 HUD 回调。`xrInputAssets.test.ts` 验证同源状态初始化、Quest B 键/摇杆映射和全部打包 GLB 引用完整性。`24fb854` 部署后，用户在 Quest 3S 再次测试并确认“手柄手追正常”；其余专项回归仍单独验收。

## 浅瓷与墨蓝视觉更新

用户确认 Quest 3S、观看为主、手柄操作为主，手追用于体验物理，并选择浅瓷与墨蓝方向。VR 控件使用独立 `hudAppearance.ts` 配色，准备页使用固定窗光绿，舞台底色、网格与放置辅助各自定义。旧系统强调色不参与这些表面的渲染。

冷白面板、墨色文字、蓝色选中提示；移除厚描边和数值标签外框，缩细滑块轨道，选中 tab 同时有下划线。观看小控制条有完整背景，展开时顶栏/分类/内容/播放区用留白和细分隔线划分。交互命中范围、B 键召回与分页语义不变。

颜色对比度测试覆盖普通、次要、选中、禁用、危险状态 ≥4.5:1（代码色值，不等于头显光学实测）。图形由 Canvas/Three 几何绘制，不添加模糊后处理、阴影灯或生成图片。GUI 模拟器截图验证不替代 Quest 3S 实机可读性验收。

- HudButton 最小高度 0.13 米；文字限制在纹理宽度内；去掉重复内层背景贴图。按下、停留、松开即可执行，支持慢速扳机操作；移出/取消不执行，随后合成 click 被抑制，防止重复触发。

## 性能与诊断

**角色自己的手托裙摆**：VR「角色 → 接触细调」或屏幕「背包 → 接触细调」。关物理时选择，再开物理即可应用到当前角色，不必退场。只给缺少掌面且能识别腕骨和裙摆的模型加掌面；默认关，与胸部受压和玩家手追拨衣独立。

- 普通 GLB/glTF 网格恢复视锥裁剪，变形网格维持保守策略。实际收益取决于资产是否合理拆分，单一巨大网格不会因这个改动自动变成分块场景，也不会自动获得 LOD。
- 浏览器 WebGL 合成场景：300 个普通立方体，1 个在视野内；draw calls 300 → 1；移到另一组网格后 draw calls=3，物件可重新进入视野。不是 Quest 帧率基准。
- 诊断增加上一渲染调用的 draw calls / triangles、renderer 跟踪的纹理/几何体数量，以及采样窗口内 `runtime.update` CPU 平均/峰值。后者包括模型动画/物理/材质同步，不包含全部 React、UI、渲染提交或 GPU 时间。计数不是显存字节数，不能据此估算完整 GPU 预算。
- 当前未接入 GPU timer query；不将 FPS 间隔或模型 CPU 时间冒充 GPU 耗时。

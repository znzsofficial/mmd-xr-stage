# 点角色之后

屏幕点舞台上的角色，VR 用射线选角色。首页第一排直接选**插入、泌乳**。服装、摆姿势、身体观察和身体设置也在这一页。要找被遮住的演员，可以在背包里按名字选。

演员界面的截图只留本机；可公开复核的操作及数值见[角色工具回归](../performance/actor-tools-regression.md)。

**服装。** 屏幕上每件都有显隐开关，点部件名展开不透明度；VR 用上一件／下一件选中部件再调。自动识别只决定常用列表。没列出的衣件，在「查找漏件」选材质槽 →「预览网格范围」→「保存为衣件」，同名材质按槽号区分。网格若连着身体，改用「更换皮肤贴图」挑同角色、同 UV 的替换图；可恢复原图。屏幕可选本地文件，XR 可用随模型导入的图片或为该槽已设的变体。没有替换图时不能从单张原图恢复被画掉的皮肤。

**插入。** 右栏选手动／自动支架和衣着状态，再推进或开始往复。要释放时直接点「释放到阴道」或「释放到宫腔」，不用另选目标。按键请求一剂，实际交付才记账；自动往复还能「取消释放」而不停机。左栏切换外阴、阴道或子宫只换图，不改剂量去处。屏幕端可「近看表情」。[支架、手持、停止与容量](./pelvic-attachment.md)

**穿着衣服时看哪里？** 直接看 HUD 的实时模型。图角「放大」近看 1.5 倍，「全图」返回，支架按钮保持原位。鼠标或手指横拖图面转动，手机竖滑翻页。VR 按住扳机横拖图面旋转；在标题的「拖动」处按住则移动整张面板。身体观察也支持同样的手势，不会因此改变衣着、机位或启动道具。

默认的「子宫」是器官全貌。要看**受精演出**，在旁边的「卵子」按「强制排卵」；每位演员从零枚开始，上限三枚。「受孕率（游戏）」也只在此处调。每一剂在内并有留存时，有可用卵子才判一次。[什么时候判定、改概率影响哪一剂](./pelvic-attachment.md#一次释放的受精演出)

**泌乳。** 开启后先看对应侧是「可出滴」还是「仅数值」。可直接点「服装」整理衣着，再点「返回泌乳」。按住左、右或双侧，松开停止继续排出；已脱落的液滴可以落完。「确认露出」只勾选确实露出的一侧。屏幕可点「近看角色」，VR 自己选站位。用量即时记到当前角色，不用再保存。点「看乳房」进入身体观察器，看图中的左右轮廓及存量，再原路返回。[哪些模型有舞台效果](./stage-lactation-proposal.md)

**身体设置。** 胸型和初始乳量共用当前演员的一份草稿。可跨栏预览，再「保存到角色」或「放弃改动」；「不保存并退出」丢弃草稿并回角色首页。想先看舞台上的效果，用「收起」（VR 为「收起看角色」），再点「预览中 · 继续编辑」回原栏。屏幕打开背包或 VR 按 B 召回公共菜单都不会提交预览；换人不会把草稿带给另一位演员。

**身体观察。** 直接选乳房、外阴、阴道、子宫或卵子，再选正面、斜面或侧面。无需装道具。这里能查看演员各枚卵子的状态，不会生成卵子或改变概率。插入操作页就地复用日常观察图。手动切到[孕态参考](./observation-reference.md)可在同角度查看独立参考插图；退出后重新打开从日常开始。

**看角色回应。** 穿衣也可看脸。让棒头从外面进入，比较慢推、加快、在内停住和退回。自动回应按实杆进退速度组合眼睑和嘴形，停住时嘴唇有呼吸般的开合，有可识别头骨时也会轻微抬头；没有适配脸部形态时仍可有头部动作。「更多操作」可指定单一表情或关闭回应。正常退出后渐渐回到原姿态；按「停止」、失追则直接还原。

想退开看一次同样的节奏，用手动支架的[手法录放](./pelvic-attachment.md#用手动支架录下自己的节奏)。想先给演员摆好双手撑住的姿势，可在[摆姿势里固定手腕](./pose-and-body-states.md#手留在桌面再调上身)再回到互动。

点「乳房」，在外观页切「轻柔／圆隆」。两款沿用水滴胸型 02，正面能比较乳晕的宽度和边缘，侧面能比较乳头的突出程度。只改变当前角色的观察图。

**打开「插入」会在角色身上显示附件吗？默认不会。** 左边是观察图。要安装角色身上的网格，去「调整入口 → 模型 → 将外阴附件装到裸肤上」。有单独的裙片或内衣挡住时也能开启；拨开或隐藏遮挡层，附件自动出现，衣物落下后仍保持开启。贴在皮肤纹理上的衣服不能像单独裙片那样掀开，请将附件拟合在实际裸肤位置。附件开关不放置支架，也不代替互动里的「确认入口露出」。

舞台只绘出附件没有被衣物盖住的部分。安装一次后，调位置、角度、尺寸或「还原入口设置」，附件都会跟着走，不用重新开启。改标定会停下正在运行的支架；若要在新位置做体外释放，需要重新确认入口露出。附件埋进身体时可继续调位置与角度，它不会透过身体显示。

点「外阴」，可切换「外侧覆盖」「内缘突出」「自然不对称」。舞台附件和观察图的外层用同一曲面：阴唇前支延入包皮，包皮下方部分可见阴蒂头，前庭内的尿道口与唯一标定的阴道口分开。实测偏侧接触只带动相应软组织；撤出后回到所选轮廓。

外阴观察使用 C 版近景材质：外侧偏哑光，褶根有软阴影，内缘的一小段亮边随观察角度移动，转到侧面会隐去。在同一演员的「身体观察 → 外阴」或「互动 → 插入 → 外阴」均可看到。屏幕根据图窗大小取样，VR 根据面板纹理取样。舞台上已露出的外阴附件用同一套材质分区，在当前布景灯光下显示；皮肤或衣物遮住的地方不会透视显示。

默认的「自然不对称」在静息时两侧靠拢；推进时，接触侧的下段向外展开，退回后形体复原。「外侧覆盖」「内缘突出」保留各自的外形。要看 **PMX 自己的开合**，进入「互动 → 插入 → 调整入口」（首次为「成年角色入口设置」），在「模型 → 选择开合形态」挑一个作者制作的形态键，保持舞台附件隐藏。回「操作」选手动支架，确认入口露出后推进、退回。选择形态键本身不触发变形；观察图始终是游戏自绘的模型。

三款自绘外形都使用外侧浅肉色、内缘与入口珊瑚粉红的配色。舞台附件跟随当前布景的柔光和方向光；不改变演员本身的皮肤或全局曝光。

**在「插入」里看动态。** 左栏选「外阴」看入口组织：张开时能看见一小段有深浅的内壁，斜面会遮住远侧，撤回后重新靠拢。选「子宫」看实测杆身在下方阴道里的位置，哪里的壁面被撑开、退回后哪里合拢；只有到达宫颈，宫颈下缘才略有形变。上方宫腔不是道具通道。「阴道」页是同次进退的局部放大，点线标记在「对位与测量」查看。

**处女膜缘。** 在「互动 → 插入 → 外阴」图下直接选「关／弹性／记住首次」，不用先放支架。默认「关」；「弹性」显示有自然开口的边缘；「记住首次」会在下一次从外向内的有效跨越后保留局部舒展。已有记录的角色切回「记住首次」会显示原记录。换模式、浏览观察图、在内部重新追踪或切景都不会补记。这是当前角色的游戏事件，不代表性经历，不产生出血。

# 点角色之后

屏幕点舞台上的角色，VR 用射线选角色。要找被遮住的演员，也可以在背包里按名字选。角色名下直接有**服装、互动、身体观察**；「身体状态」仍是调胸型、周期和分侧存量的草稿编辑器。

[屏幕实拍：演员首页、泌乳操作与子宫侧面](../screenshots/actor-activities.webp)（合成示例角色）。

**服装。** 屏幕上每件都有显隐开关，点部件名展开不透明度；VR 用上一件／下一件选中部件再调。在「配件」「服装形态」里可调作者提供的相容项目。「恢复原装」去掉衣柜覆盖；「撤销衣柜改动」回到改动前的值。直接画在皮肤上的衣服不能单独开关，不会用隐藏整个人来代替。

**互动 → 插入。** 先把支架放在已校准的入口外。衣物挡住时可以整理衣服，也可以选「保持穿衣继续」。后者保留穿着，不假装衣下已经露出；棒头仍须实际从入口外推进。在同一页选择「阴道／宫腔」，看当前目标的释放按钮。选择宫腔只决定这次游戏计量的去向，不会让棒头越过宫颈。[支架、手持、停止与容量](./pelvic-attachment.md)

**互动 → 泌乳。** 开启后先看对应侧是「可出滴」还是「仅数值」。按住左、右或双侧，松开停止继续排出；已脱落的液滴可以落完。「裸露与回充」里只确认确实露出的那一侧。屏幕可点「近看角色」，VR 自己选站位。用量就地记到当前角色，不用再保存；到乳房观察看效果再返回，上一步不会重播或回滚。[哪些模型有舞台效果](./stage-lactation-proposal.md)

**身体观察。** 直接选乳房、外阴、阴道或子宫，再选正面、斜面或侧面。无需先装道具。没有测量时看的是原创示意；有当前支架／杆位和存量时，观察读当前演员的状态。从插入或泌乳进入可直接返回该互动。

# 点角色之后

屏幕点舞台上的角色，VR 用射线选角色。要找被遮住的演员，也可以在背包里按名字选。**身体观察**用来单独看四个部位；**身体设置**用来编辑胸型、模拟日期和分侧存量，保存后才写入角色；**互动**里的操作直接生效。

演员界面的截图只留本机；可公开复核的操作及数值见[角色工具回归](../performance/actor-tools-regression.md)。

**服装。** 屏幕上每件都有显隐开关，点部件名展开不透明度；VR 用上一件／下一件选中部件再调。自动识别只决定常用列表。没列出的衣件，在「查找漏件」选材质槽 →「预览网格范围」→「保存为衣件」，同名材质按槽号区分。网格若连着身体，改用「更换皮肤贴图」挑同角色、同 UV 的替换图；可恢复原图。屏幕可选本地文件，XR 可用随模型导入的图片或为该槽已设的变体。没有替换图时不能从单张原图恢复被画掉的皮肤。

**互动 → 插入。** 左栏切换外阴、阴道或子宫的实时图，右栏选手动／自动支架和衣着状态，再推进或开始往复。改变观察部位不会改变释放目标。自动模式点「释放到阴道」或「释放到宫腔」，单次记账，可在待释放时取消。选择宫腔不延长棒头行程。屏幕端可「近看表情」。[支架、手持、停止与容量](./pelvic-attachment.md)

**互动 → 泌乳。** 开启后先看对应侧是「可出滴」还是「仅数值」。可直接点「服装」整理衣着，再点「返回泌乳」。按住左、右或双侧，松开停止继续排出；已脱落的液滴可以落完。「确认露出」只勾选确实露出的一侧。屏幕可点「近看角色」，VR 自己选站位。用量即时记到当前角色，不用再保存。点「看乳房」进入身体观察器，看图中的左右轮廓及存量，再原路返回。[哪些模型有舞台效果](./stage-lactation-proposal.md)

**身体观察。** 直接选乳房、外阴、阴道或子宫，再选正面、斜面或侧面。无需先装道具。没有测量时看的是原创示意；有当前支架／杆位和存量时，观察读当前演员的状态。插入操作页就地复用同一套图，不另开页面。

**看角色回应。** 穿衣也可看脸。让棒头从外面进入，在内停半秒，再推进、退出；短触、持续移动、停留和正常退出用角色自带的可用脸部形态表现。默认自动选形态，种类少时用幅度区分；没有可用表情的模型照常互动。「更多操作」可更换或关闭回应。正常退出后渐渐回到原表情；按「停止」、失追则直接还原。

想退开看一次同样的节奏，用手动支架的[手法录放](./pelvic-attachment.md#用手动支架录下自己的节奏)。想先给演员摆好双手撑住的姿势，可在[摆姿势里固定手腕](./pose-and-body-states.md#手留在桌面再调上身)再回到互动。

点「乳房」，在外观页切「轻柔／圆隆」。两款沿用水滴胸型 02，正面能比较乳晕的宽度和边缘，侧面能比较乳头的突出程度。只改变当前角色的观察图。

点「外阴」，可切换「外侧覆盖」「内缘突出」「自然不对称」。舞台附件和观察图用同一曲面：阴唇前支延入包皮，包皮下方部分可见阴蒂头，前庭内的尿道口与唯一标定的阴道口分开。实测偏侧接触只带动相应软组织；撤出后回到所选轮廓。

「互动 → 插入 → 调整入口 → 模型」可为当前成年角色开启「处女膜缘」；默认关闭，开启后仍有正常开口。另开「记住首次有效进入」，会记下**此选项开启后**第一次从外向内的有效跨越，并保留一小段边缘的舒展。事件只属于本页背包里的这位角色，不代表性经历，不产生出血。留在内部重新追踪、浏览观察图或切景都不会补记。关闭记录可看弹性基准，关闭膜缘仍可正常操作。

# 设计草案：给角色摆姿势，预览身体状态

**未实现、未排期。** 适用于玩家选定的成年角色。建议先做可撤销的姿势编辑，再做可预览的周期与乳房状态；不用等骨盆附件完成。现在已经能导入 [VPD 姿势](./asset-workflow.md)，运行时也有[胸部受压与回弹](../../src/mmdVrShowcase/mmdRuntime/chestCompression.ts)，但不是场内姿势编辑器或周期系统。

## 姿势：先让一个人能在长椅上坐好

1. 在角色旁选「摆姿势」，暂停在当前动作帧，出现头、骨盆、左右手和脚的控制点。普通触碰继续用于拨衣，只有抓到控制点才改姿势。屏幕可选骨骼用旋转环，VR 用扳机选点再抓取。
2. 锁住两只脚，降低骨盆，膝盖朝可调的方向弯；把手拖到膝上，再扭手腕或转头看镜头。手脚位置用两段式 IK 解算，关节朝向可单独微调。超出手臂或腿长时停在可达范围，不拉长模型；骨链不完整就改用单关节旋转。
3. 每次放手记一步撤销。保存为同一角色的命名姿势，也可取消并精确回原帧，或恢复原 VMD 播放。首版不在播放中持续改动作，不承诺不同骨架直接通用；之后再考虑 VPD 导出和姿势之间的过渡。

**实现边界：** 底稿取冻结帧的动画骨骼姿态，手工编辑用模型局部骨骼变换或目标点记录；不要把衣料的 Bullet 解算结果、显示用胸部形变或世界坐标烘进底稿。姿势必须作为求值输入供衣物碰撞与腕持挂点读取，不能仅在整帧末尾改显示骨。当前 0.8.6 的公开逐帧接口可覆盖 morph，但没有同等的骨骼覆盖参数；可先验证临时单帧动作源，避免每次拖动都重新调用会重置物理的 `setAnimation`。物理大跳变在确认／取消时重新播种，连续拖动不要每帧重建世界。优先验证一坐一站、手持件跟腕、恢复跳舞后无关节漂移。

**已做的可行性小试：** 使用[合成 PMX/VMD](../../scripts/cloth-smoke-fixture.js)与发货版 JS 求值器，关闭物理，在第 60 帧复制右腕轨道成独立单帧动作。只绑定一次，改关键帧后在同一时刻重算：右腕转动 45°、食指根跟随；重新绑定原 VMD 回到第 60 帧，腕部角度与指根位置误差均小于 10⁻⁶（弧度／模型单位）。尚未验证交互控件、全身 IK 或衣物物理。

## 周期：玩家可以对比同一个人的两个时间点

每名角色有自己的虚构时间线，能关闭、锁定当前日、手动快进一天或拖动预览。不读现实日期，不跟 VMD 歌曲长度或循环次数走；预览与确认分开。示意轴可标经期、经后、排卵前后及黄体期，阶段与长度可调，也可不模拟排卵。阶段间连续过渡，而非所有角色在固定一天骤变。

- **剖面反馈：** 同一姿势下前后拖时间，看子宫内膜示意的厚薄及经期脱落标记；可另用图例显示周期性分泌物的相对变化。它不改变道具的可达深度，也不把排卵提示当成受孕预测。道具释放量、经期显示和幻想模式腔体计量各自记账。
- **个体差异：** 每项可选「无变化／轻微／明显」并手动覆盖。重点是在切换时间后能看见对应反馈，而不是给每个阶段强制绑定情绪、行为或表情。

## 乳房：基础外观、即时受压、可选泌乳分开

- **基础状态（按天）：** 支持「平常／略饱满」或连续程度。允许角色在某些周期阶段更有胀感，也允许完全不变。优先使用原模型已有的形态键；有合适权重的模型再适配专用骨。不把躯干整体缩放当胸型变化。
- **接触响应（按帧）：** 手掌压上时已有局部压缩、撤手后回弹。可按角色设形变幅度与回弹时间；“触痛／敏感”另做可选表情或状态提示，不把疼痛等同于更软或更容易变形。每帧应恢复到该角色当日的基础状态，不覆盖原舞姿、手腕或 VMD 表情。没有匹配的胸骨、形态键或衣物蒙皮就只显示状态，并标明哪些效果不可用。
- **泌乳（独立可选）：** 若需要，可做未启用／泌乳状态、左右独立的相对充盈度及排出后的缓慢恢复。做成可预览的角色设定，不让一般月经周期或一次触碰自动开启泌乳。外观适配与状态计量分开，不给所有模型一个固定容量。

**首版值得验证的画面：** 暂停同一角色，让她坐稳并将手放在膝上，保存姿势。固定相机切换两个周期日，看剖面与可选胸型变化；轻压、撤手后恢复的是当日外观。切到第二名角色不能串状态，退出编辑后原动作照常播放。

# 骨盆附件与佩戴件物理

## 第一次使用：先放到入口外，再推进

1. 选已上场的成年角色 → 首页「插入」，在右侧选择「手动支架」或「自动支架」。找到入口后即放置，支架应静止可见；屏幕端可点「近看支架」。若只想调标定而不放道具，选「成年角色入口设置」。
2. 衣物挡住时可开服装逐件隐藏或恢复，也可选「保持穿衣继续」，不用为了推进把整件衣服脱掉。后者只授权当前角色按校准轨道互动，不等于已经看见皮肤。标记偏了才用「调整入口」改位置、角度和尺寸；缺骨盆骨骼时从「模型」手动指定起点。
3. 确认露出或选择穿衣继续后点「推进」。**放好不算进入**，以棒头实际从外侧穿过入口为准。「停止」停在原位，「退回起点」是撤出。无论哪种衣着，重新追踪时直接出现在里面，都不能开始计量。

**实时观察和操作在同一张面板。** 默认看完整子宫；外阴、阴道和卵子各有独立视图。右边调支架的深度和速度，看实际深度，或按目标释放。窄屏图在上、操作在下。观察部位不决定剂量去处，换图不会暂停往复。「对位与测量」保留校准和容量。只看舞台外阴附件可从「调整入口 → 模型」安装；可以先在裙下开启，附件随实际遮挡显隐。它不会给封闭皮面开洞，开启也不确认外部喷口露出。

左栏选「外阴」，图下的处女膜模式可直接选「关」（默认）、「弹性」或「记住首次」。选模式本身不产生进入事件；「记住首次」只记录该角色首次符合条件的进入。切到弹性或关闭会保留已有记录，切回即可看到原来的局部变化。

**看内壁的变化：**切「阴道 → 斜面」，先看静止时贴合的前后壁，深端是宫颈和周围的穹隆。用手动支架推进、停住，再退回起点。画面里的硅胶头对应实际喷口与杆身，不叠定位靶心；需要标线可切「对位与测量」。只有实杆经过的褶皱会被撑开，撤回时深处先合拢。乳白色表示这个部位实际留存的精液。子宫页始终是器官全貌，宫颈仍是杆身行程的终点。

屏幕横拖图面，VR 用扳机直接横拖或点角度按钮。图角可放大，按住标题可挪动 XR 面板；手持观察牌仍是只读的。静止时的杆身是实物位置，不是“已进入”的凭据；退出控制面板后的手持观察牌沿用该演员最后选的测量模式和角度。「近看支架」后仍可滚轮缩放、环绕和重置。衣物可在衣柜恢复；绘制于同一片皮肤的衣服可用同 UV 贴图切换。

## 调整面板里的阴道长度

选「调整入口 → 尺寸」，拖动「阴道长度」。同页的阴道剖面会跟着改变：入口留在原处，内壁和深端的位置随长度变化。不用先放支架，也可以横拖图面换角度；回「操作 → 阴道」或打开该角色的「身体观察 → 阴道」会看到同一份尺寸。调标定会停下运行中的互动，确认露出后可重新启动。

## 选择支架或半透明搭档

首次进入「插入」可以直接点「半透明搭档」。搭档先停在入口外，手动控制下用「推进」「退回起点」，选「自动往复」则用「开始往复／停止往复」。屏幕端可点「近看搭档」，再用滚轮或环绕调整机位。互动中点「支架／半透明搭档」只换外观，保留当前位置和运行状态。搭档不占背包演员名额，点「收起搭档」仍保留演员原先摆好的姿势。VR 交给左手或右手时使用手持道具。

**边看搭档边摆姿。** 在已放置的搭档旁点「调整姿势」，会停下往复、取消待释放并回到入口外。可以套用快速体位，也可以直接拖演员的脚踝，观察搭档的肩、腰和支撑手如何跟随。点「保留姿势并返回」回到原搭档，再按「推进」或「开始往复」。只改姿势不会计入接触或自行启动。录制手法期间须先保存或明确停止录制。

侧卧时，搭档沿演员的躯干方向横卧在标定入口一侧，胸口朝向演员；靠地的手支撑，另一只手给抬起的腿让位。四点跪撑或前臂跪撑时，搭档在演员身后面朝头端，两只手分别靠近腰侧。手调、已存姿势和 VMD 都读取当前演员的肩、髋、膝位置，不要求保持某个预设名。屏幕端点「近看搭档」会按两人当前姿势一起取景，仍可用滚轮拉近或拖动环绕；VR 保留玩家自己的视角。

## 手动、自动与手持控制

- **手动支架：**滑杆是目标位置，不是实测深度。在内停住再启动，先退到入口外重新对准。
- **自动支架：**主操作区直接调速度和最深位置，实际到达的深度由舞台测量。上排左键「开始往复」原位变为「停止往复」；右键「取消释放」只取消待发的一剂。下排按键直接指定释放部位。舞蹈暂停时仍可运行。
- **手持（仅 VR）：**在「更多操作」选「交给左手／交给右手」。在操作页选好内部目标，点「开始手持并收起面板」。从外侧对准再推进，观察牌沿用刚选的视图。侧擦或失追后直接出现在里面不算进入；恢复后须重新启动并从外侧接近。

## 用手动支架录下自己的节奏

放好手动支架、确认衣着后，点「手法录放 → 录制手法」。用「推进」「退出」或位置滑杆操作；想让回放也停一下，就让杆停在原位。点「保存手法」会在当前位置停住。每位演员在本页背包保留一段，最长 20 秒；重录时，保存才替换旧段。

点「退出到起点」，等实杆完全回到入口外，再点「播放手法」。可调 0.5–2 倍速或打开循环。单次播放停在片段末位；如果结尾在内，循环会先连续撤回，回到起点才重播。只记录手动支架相对入口的行程与停顿；屏幕和 XR 均可操作，不包含自由手持轨迹或释放动作。回放时角色表情和接触仍按当帧实杆判断。换人、切景、停止或失追不会自行续播。

## 精液与计量

手动支架在「插入 → 操作」直接点「释放到阴道」或「释放到宫腔」；手持模式选目标本身不释放，用手柄侧握交付。每次 1 游戏单位，乳白色表示精液。**交付时已验证在内**才计入指定部位。确认在外的释放与内部释放分开；位置改变或越限不会把支架按钮的原始请求改成另一种效果，也不会补发。切换观察部位不转移存量，选择宫腔也不延长棒身行程。

自动往复时点一次「释放到阴道／释放到宫腔」，不用在喷口经过入口的瞬间抢按。在内时核对当帧位置；在外时只等本次有效进入。状态为「待释放」时可点「取消释放」。错过有效进入、超时、停止、换目标或失追均不补发，更不会改为外喷。更换支架在停机状态可用。

**体外释放**就在同一排。入口无遮挡且已经「确认入口露出」时，自动往复中可提前点；实际退到外侧时只释放一次，可以单独取消。手动控制下按「退回起点」后保持运行，喷口在外时点「体外释放」即可。「保持穿衣继续」只允许内部互动，按钮旁会显示体外释放不可用的原因。体外释放不会改变内部存量。

「对位与测量」可查看或调整各部位容量；内部剂量超过所选部位的容量就记溢出。「排出 1 单位」按实际排出量增加累计；「清空此处」只清当前存量。两部位各有存量与容量，共用该角色的溢出和已排出累计。校准和存量按背包资产隔离。切景、退出后支架不会继续运行；手持、腕持和支架不会各生成一份道具。

## 一次释放的受精演出

在成年角色的**互动 → 插入 → 卵子**按「强制排卵」，每次增加一枚，最多三枚（含已受精）。默认没有卵子，也不会随时间自动排卵。只有这一页能调「受孕率（游戏）」，范围 **0–100%，默认 60%**。选哪枚只是查看，右侧按键仍决定释放部位。

仅在**交付当帧确实在内、所选部位有正量留存、演员还有未受精卵子**时，才按当时的概率判定一次，不按卵子数连抽。部分溢出但仍有留存也只算一次。没有可用卵子时只更新液量，之后排卵不会补算；预约、取消、外喷、全量溢出和清空也不触发。

「卵子」显示所选卵子的近景。**0%** 时精子散开，卵子仍可参与下一次；**100%** 时一笔有效交付只让一枚卵子受精。逐枚查看可区分不同结果。换概率、切景、换演员或在「身体观察」转动和定格都不会重抽。「子宫」保留器官全貌，不会因为发生事件自动切到放大镜。

错过演出时，选那枚卵子，点「回看最近结果」。只重播该卵子最近一次已有记录，未交付时不可用；按钮原位可停止。回看不启动支架，不增加液量，也不会把失败改为成功。

## 假阳具玩法候选（尚未实现）

- **双角色持具：**一人腕持，可定格摆腕或播放动作；另一人作为独立校准、计量的目标。现有腕持摆拍不等于已实现双角色计量。
- **撤出回流：**让实际扣除的排出／溢出量显示在入口处，不额外生成剂量。

## 跳蛋如何推衣物

选遥控跳蛋 →「佩戴跳蛋并启动」，立即进入低档。舞蹈暂停且不开物理，佩戴件也会摆动，有相容脸部形态的演员还会随节奏变化。点「停机」保留位置，「摘下」才移除；换人需主动转戴。要让它推裙片，再开启角色物理，让外壳从外侧接近有动态刚体的衣片。初始埋在衣物时先移开再接近。

**本机候选 `8f1006f`（WebGL／WebGPU）**：佩戴后可直接选「腰前衣面」或「胸前」。佩戴件贴合当前穿着的可见表面，附近衣料随节律局部起伏；这是可恢复的显示效果，不要求开启 Bullet。旧版用骨盆偏移，外壳或表情虽动，穿衣实模所在的衣面却没有可见反馈。保持同姿、关物理、只隐藏外壳后，旧 WebGL 两处开／关差均为 0；修复后腰前／胸前分别有 576／2004 个像素最大通道差超过 12/255，停机均逐像素恢复。模拟 XR 的 WebGPU 双眼亦见衣面变化，失追停机、不自行重启。私有对照：`local-review/screenshots/remote-egg/webgl-comparison.png`。

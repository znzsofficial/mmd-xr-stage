# 骨盆附件与佩戴件物理

## 第一次使用：先放到入口外，再推进

1. 选已上场的成年角色 →「互动 → 插入」→「为此成年角色放置支架」。找到入口后即放置，支架应静止可见；屏幕端可点「近看支架」。若只想调标定而不放道具，选「仅设置成年角色入口」。
2. 衣物挡住时可开服装逐件隐藏或恢复，也可选「保持穿衣继续」，不用为了推进把整件衣服脱掉。后者只授权当前角色按校准轨道互动，不等于已经看见皮肤。标记偏了才用「调整入口」改位置、角度和尺寸；缺骨盆骨骼时从「模型」手动指定起点。
3. 确认露出或选择穿衣继续后点「推进」。**放好不算进入**，以棒头实际从外侧穿过入口为准。「停止」停在原位，「退出」才是撤出。无论哪种衣着，重新追踪时直接出现在里面，都不能开始计量。

**身体观察**可从角色首页直接开，或从插入页开并返回。按外阴、阴道、子宫选部位即可看外观、通道或本地宫壁示意。需要深度、偏移或容量时用「测量与容量」。定格图像不冻结测量。只看舞台外阴附件可从「调整入口 → 模型」确认露出并显示，不需支架；若原模型衣下缺皮面，边缘未必贴合。附件不会给封闭皮面开洞；模型自带开合形态可单独映射。

屏幕横拖图面，VR 用观察角度滑杆。静止时的杆身是实物位置，不是“已进入”的凭据；退出控制面板后的手持观察牌沿用该演员最后选的模式和角度。「近看支架」后仍可滚轮缩放、环绕和重置。衣物材质可在同一页恢复；画在皮肤贴图上的衣服不能单独隐藏。

## 三种控制用的是同一件道具

- **手动支架：**滑杆是目标位置，不是实测深度。在内停住再启动，先退到入口外重新对准。
- **自动支架：**「拿法与支架设置 → 自动支架 → 开始自动往复」。可调速度、幅度，舞蹈暂停时仍可运行。
- **手持（仅 VR）：**选左／右手，点「开始手持并收起面板」。从外侧对准再推进，观察牌沿用刚选的视图。侧擦或失追后直接出现在里面不算进入；恢复后须重新启动并从外侧接近。

## 用手动支架录下自己的节奏

放好手动支架、确认衣着后，点「手法录放 → 录制手法」。用「推进」「退出」或位置滑杆操作；想让回放也停一下，就让杆停在原位。点「保存手法」会在当前位置停住。每位演员在本页背包保留一段，最长 20 秒；重录时，保存才替换旧段。

点「退出到起点」，等实杆完全回到入口外，再点「播放手法」。可调 0.5–2 倍速或打开循环。单次播放停在片段末位；如果结尾在内，循环会先连续撤回，回到起点才重播。只记录手动支架相对入口的行程与停顿；屏幕和 XR 均可操作，不包含自由手持轨迹或释放动作。回放时角色表情和接触仍按当帧实杆判断。换人、切景、停止或失追不会自行续播。

## 精液与计量

手持时按一次侧握；支架在「插入」操作页选阴道或宫腔，再按对应的释放按钮。每次 1 游戏单位，乳白色表示精液。**已验证在内**才计入所选部位。确认在外的释放与内部释放分开；位置改变或越限不会把支架按钮的原始请求改成另一种效果，也不会补发。切换部位不转移存量，也不延长棒身行程。

「测量与容量」可查看或调整各部位容量；内部剂量超过所选部位的容量就记溢出。「排出 1 单位」按实际排出量增加累计；「清空此处」只清当前存量。两部位各有存量与容量，共用该角色的溢出和已排出累计。校准和存量按背包资产隔离。切景、退出后支架不会继续运行；手持、腕持和支架不会各生成一份道具。

## 假阳具玩法候选（尚未实现）

- **双角色持具：**一人腕持，可定格摆腕或播放动作；另一人作为独立校准、计量的目标。现有腕持摆拍不等于已实现双角色计量。
- **撤出回流：**让实际扣除的排出／溢出量显示在入口处，不额外生成剂量。

## 跳蛋如何推衣物

从「背包 → 玩具」给角色佩戴，开启角色物理。将外壳从衣物外侧缓慢靠近有动态刚体的裙片，对比开／关机；遥控器本身不推衣。初始埋在衣物中时先移开再接近。没有相容刚体的布面不会自动变成软体。

# 骨盆附件与佩戴件物理

## 第一次使用：先放到入口外，再推进

1. 选已上场的成年角色 →「骨盆附件 → 为此成年角色启用 → 把假阳具放到入口外」。支架应静止可见；屏幕端可点「近看支架」。
2. 衣物挡住时，从「调整衣物」逐件隐藏或恢复。标记偏了才用「调整入口」改位置、角度和尺寸；缺骨盆骨骼时从「模型」手动指定起点。「还没看清入口」可暂停布料让检查完成；数据无效或超限需调衣物或换模型，手动确认不能绕过遮挡。
3. 入口露出后点「我看到了入口 → 向内推一段」。**放好不算进入**，以棒头实际从外侧穿过入口为准。「停止」停在原位，「退到入口外」才是撤出。

**观察图：**「入口对位」对照[外阴、入口与杆位](../screenshots/vulva-views.webp)，「测量剖面」读深度、偏移与限位，「子宫动态」看[本地可转动的宫壁示意](../screenshots/organ-motion.webp)。定格图像不冻结测量。只看角色外观可从「调整入口 → 模型」确认露出并显示外阴附件，不需支架；若原模型衣下缺皮面，边缘未必贴合。附件不会给封闭皮面开洞；模型自带开合形态可单独映射。

## 三种控制用的是同一件道具

- **手动支架：**滑杆是目标位置，不是实测深度。在内停住再启动，先退到入口外重新对准。
- **自动支架：**「换拿法或收起 → 自动支架 → 开始自动往复」。可调速度、幅度，舞蹈暂停时仍可运行。
- **手持（仅 VR）：**选左／右手，点「开始手持并收起面板」。从外侧对准再推进，观察牌沿用刚选的视图。侧擦或失追后直接出现在里面不算进入；恢复后须重新启动并从外侧接近。

## 精液与计量

手持时按一次侧握；支架运行时点「射出精液」。每次 1 游戏单位，乳白色表示精液。**已验证在内**才计入所选阴道或宫腔；**确认在外**只外喷；**未验证或越限**不释放、不补发。切换部位不转移存量，也不延长棒身行程。

「观察图 → 精液存量与容量」可调各部位容量。「排出 1 单位」增加本角色的已排出累计；「清空此处」只清当前存量。两部位各有存量与容量，共用该角色的溢出和已排出累计。切景、退出后支架不会继续运行。

## 假阳具玩法候选（尚未实现）

- **手法回放：**录下相对入口的推进、停留与撤回，交给支架回放；释放仍单独触发。
- **双角色持具：**一人腕持，另一人作为独立校准、计量的目标。
- **撤出回流：**让实际扣除的排出／溢出量显示在入口处，不额外生成剂量。

## 跳蛋如何推衣物

从「背包 → 玩具」给角色佩戴，开启角色物理。将外壳从衣物外侧缓慢靠近有动态刚体的裙片，对比开／关机；遥控器本身不推衣。初始埋在衣物中时先移开再接近。没有相容刚体的布面不会自动变成软体。

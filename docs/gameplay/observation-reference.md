# 身体观察：日常观察／孕态参考

点选演员 → **身体观察**。默认「日常观察」。选「孕态参考」后可以换部位、旋转或切回日常作同角度对照；退出身体观察或换演员，再进从日常开始。

- **子宫**：固定姿态的宫壁剖窗、胎体、胎盘和脐带，可选结构标注。**乳房**：独立外观与腺小叶剖面；若显示「角色乳量（左／右）」，数值取自演员已保存的分侧存量，不参与参考图造型。
- **阴道／外阴**：左图仍是原观察画笔和真实采样；右图金色标记仅表示部位。右图跟随左图实际画出的角度，不表示开度或插入深度。**卵子**始终显示该演员真实的数量、所选结果及原有回看。
- 这是手动选择的一套本地插图。不表示演员已怀孕，不计时、不改变身体或模型。**互动 → 插入**仍是原操作面板。

## 同一轮屏幕／IWER 验收

两端串行，各自在草坪放置一名成年本地演员、暂停 VMD，打开演员工具。第一轮用空卵子、无道具和无身体草稿的演员。中文界面按以下路线：

1. 身体观察 → 孕态参考 → 子宫，点正面、斜面、侧面，再拖图（XR 用右栏角度滑杆）。看同一胎体与脐带的遮挡变化。开关结构标注；停着不操作时图像不持续更新。
2. 不退出直接点乳房，在三角度各看外观、剖面，再切日常核对读数。屏幕另用 360 × 800，实际触摸横拖后滚到读数，再点返回。IWER 用控制器射线按下并释放每个键，分别检查双眼的图、选中态和返回键。
3. 阴道、外阴选斜面。日常与参考切换时左图同一接触状态，右侧只换位置标记。卵子仍为 0 / 3。返回角色再进是日常；切另一个演员也是日常。进互动 → 插入，默认是日常子宫，无参考选择。
4. 第二轮用已有分侧乳量和已记录卵子的演员，记录左／右存量、卵子编号与结果；回看及换参考不改这些值（泌乳自动回充启用时区分回充）。在插入页通过手动支架**实际推进**后，保持杆位返回观察；同角度对比两种图的实测杆位与壁面，回插入页退回起点再比一次。切参考不能制造首次进入、释放或受精事件。无待释放的一剂时做此对照。

可在发布者已进入同一舞台的 Playwright 测试中调用 [`observationReferenceFlow`](../../scripts/art/observation-reference-flow.mjs)。它实际点按钮并等待 DOM 画布／HUD 材质已有对应图像，核对三角度、乳房剖面、卵子记录、退出和插入页。IWER 使用项目验收夹具的 `qa.click`（扳机）和 `qa.all`，不直接调用 HUD 回调。`capture` 是可选的本地截屏钩子，双眼需在当帧分别取样；截图只写 `local-review/`。

```js
import {observationReferenceFlow} from './scripts/art/observation-reference-flow.mjs';
const pictures = await observationReferenceFlow(page, {xr: false}); // IWER 传 true
```

无浏览器的本地三视图：`node scripts/art/observation-reference-study.mjs <已有的 @napi-rs/canvas 安装路径>`，输出 `local-review/art/observation-reference/three-angles.png`。它只检验画笔，不能替代上述操作与实戴。

**本轮已测。** 屏幕实模与模拟双眼分别从角色工具实际点入，共各核对 15 张画面：子宫三角度，乳房外观和剖面的三角度，阴道／外阴的参考与日常，卵子及返回插入页。换图、翻转剖面后像素不同；退出身体观察后插入面板仍是普通子宫。在演员有已记录结果和已保存分侧乳量的条件下，另以组件测试确认同一批记录、乳量和当前杆位没有被参考页改写。镜片上的清晰度仍待实戴。

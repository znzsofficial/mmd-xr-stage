# 身体观察：日常观察／孕态参考

点选演员 → **身体观察**，默认是「日常观察」。点「孕态参考」，同一部位会换成一幅可旋转的解剖示意；再点「日常观察」，以原角度看演员当前的图。退出或换演员后重新进入，从日常开始。

- **外阴**：参考图的两侧软垫更宽、前后更厚，内侧薄褶相贴，上端汇成覆盖褶。侧转时近侧遮住远侧，能看到褶缘的起伏和皮下的淡血管色。入口保持静息闭合。
- **阴道**：纵剖移去一段前壁，露出后壁的横褶、纵向隆起和宫颈端。保留的前壁有肌层断面和外层；回转能分清是在看褶面、外壁还是切缘。剖窗不是张开的管腔。
- **子宫**：固定剖窗保留宫体和宫底壁厚；下方可沿宫颈管看到突入阴道上端的宫颈。胎盘贴在宫内壁，脐带从胎盘血管汇合处弯回胎体腹部。结构标注可单独开关。
- **乳房**保留独立的外观和腺小叶剖面。**卵子**仍是演员自身的数量、所选结果和回看。

三处参考画的是一种可能的外观，并非人人都有的孕态征象，也不表示所选演员怀孕。静息图不接收杆位、容积或时间输入。图外的「角色实测杆位」「实测在内深度」来自当前演员的实际采样；「角色阴道存量」和「角色乳量（左／右）」读各自的账本。接触变化不会撑开参考图。要看杆身和组织的实时位置关系，切回日常。**互动 → 插入**仍是日常操作面板。

造型参考的是血流增加可能带来的组织饱满和黏膜色调差别（[生理变化综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5715231/)），而非按颜色或外形判断个体状态。没有把所有组织统一涂成深色或画成分娩时的开度。

## 屏幕与 IWER 验收

两端串行，各自在草坪放置一名成年本地演员、暂停 VMD，打开角色工具，使用中文界面。

1. 身体观察 → 孕态参考。对**外阴、阴道、子宫**各点正面、斜面、侧面；每个角度切到日常再回来。先不加字看组织轮廓、壁厚和前后遮挡，再在斜面给子宫加标注，检查引线是否落在组织上。停住不操作时，参考图不继续上传。
2. 乳房检查三个角度的外观与剖面。卵子核对已有编号与结果；空演员显示 0 / 3。退出再进或换演员，从日常开始。进互动 → 插入，默认仍是日常子宫。
3. 对已有身体数据的演员，在插入页用手动支架实际推进并停住；无待释放的一剂时返回观察。日常图和图外实测可反映杆位，参考图应仍与同角度无接触图相同。退回起点再比一次；切图不新增记录。乳量如有回充，区分计时回充与切图行为。
4. 窄屏 `360 × 800` 横拖主图、纵向滚动到读数、点返回；IWER 用扳机按下再释放，分别看两眼的主图和选中态。小图上仍应认得外阴内外褶、阴道壁剖面和子宫下端连接。清晰度与舒适度最后上 Quest 实戴。

[`observationReferenceFlow`](../../scripts/art/observation-reference-flow.mjs) 从已选中演员的角色工具开始，实际点按钮，等到屏幕画布或 XR 材质显示请求的角度。三处都检查同角度重开的参考图像素一致，并与日常**主轮廓**作比较。`capture` 可在图像就绪后保存当前舞台／当帧双眼到 `local-review/`。例如：

```js
import {observationReferenceFlow} from './scripts/art/observation-reference-flow.mjs';
const rows = await observationReferenceFlow(page, {xr: false, capture}); // IWER 传 true，需 qa.click / qa.all
```

发布者如使用本机现有的实模夹具，在已验证构建上依次运行 `node local-review/verify-reference-views.mjs screen`、`node local-review/verify-reference-views.mjs xr`。新版路线每端取 27 张画布摘要。该流程不自动操作支架，也不代替第 3、4 步。

**已测的画面与实操。** 屏幕和模拟双眼的 27 张摘要均通过；三处在 0°／38°／90° 切换日常再切回，参考画面可重复。另在手动支架推进、保持、退回时比较：屏幕实模实测 6.5 cm，模拟 XR 夹具为 6.4 cm，各有一单位阴道留存。参考图外的读数跟随实际杆位；同角度下，外阴／阴道参考画布在未操作、实测在内和退回后三次的 PNG 哈希相同，存量仍为一单位。360 × 800 模拟触屏实际横拖，从正面转到 38°，切日常保持同角度，可返回角色。**并非实际 Quest 镜片或手机硬件测量。** 本机证据在 `local-review/art/gestational-reference-revision/after/`。

## 画笔对照（仅 CPU）

`node scripts/art/observation-reference-study.mjs <已有的 @napi-rs/canvas 安装路径>` 将日常与参考在 **0° / 38° / 90°** 的无接触图写入 `local-review/art/observation-reference/maternal/`。本轮在改动前用 `--before` 留下了原版主图；外阴／阴道取当时定位小图旁的完整日常画笔，子宫取原参考。`{vulva,vagina,uterus}-{156,344}-comparison.png` 的三行依次是原版主图、日常、新参考。已按这两档尺寸检查三处主图；这是 CPU 画笔结果，屏幕、模拟双眼与真机记录应分别验证。

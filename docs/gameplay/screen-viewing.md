# 屏幕观看

[导入角色和动作](./asset-workflow.md) · [四幕玩法与道具](./README.md)

普通电脑或触屏浏览器只需支持 WebGL 2。在准备页导入模型包、配套贴图和动作，点「屏幕观看」。没导入文件也可以进场逛布景。

放下角色后，播放条可直接切「胸部受压形变」。手臂沿 VMD 原轨迹，接触附近的专用胸骨压缩后回弹；屏幕背包内另有「环境」和「接触细调」。

「背包 → 环境 → 角色色彩：保留亮部细节」可原地切换旧版明亮或新版柔和的角色高光，选择会记住，场景灯不随之改变。

- **镜头**：拖动画面环绕，滚轮或双指缩放，鼠标右键拖动平移。「重置视角」回到当前布景的起始机位；选中角色后「看向选中项」会按尺寸重新取景。
- **键盘机位**：进入屏幕观看后，按住 W / S 朝镜头前方／后方水平移动，A / D 向左／右平移。从上往下看，Q 顺时针、E 逆时针，都是在原地转头；F 升高、C 降低，R 恢复当前布景的入口机位和视野。用过菜单后，点回画面或用 Tab 聚焦画面即可继续；选落点时键盘移动暂停。
- **步行过门**：把镜头放在站立高度，用 WASD 穿过两景相接的路面，过门时保留行进方向；高空俯看、滚轮缩放和拖动环绕不会切景。也可以在「游览机位」直接选带箭头的目的地。每个布景各自保留摆法。
- **摆放**：打开「背包」，点某个角色或物件，再点地上允许放置的位置。单层落点明确的布景也可点「放在中央」；[电玩厅](../scenery/arcade-hall.md)要点实际楼面，板旁黄框内按 **G** 换层。每个布景最多同时摆 3 个角色和 3 个物件。
- **医院的场景人物**：诊室护士默认隐藏。在「背包 → 环境」勾选「场景人物」即可显示；保存过的开关值继续生效，不影响导入的角色或教具。
- **动作**：选中已放置的角色，在「用于身体」或「用于表情」选动作。下方可以暂停、循环、拖进度或开关物理。支持腕骨的角色还可选择左手或右手拿点亮的星辉光剑。收起背包后，点角色会再打开工具。
- **继续看**：返回准备页后，点「屏幕观看」会恢复当前所选布景的布局；在支持 VR 的同一页面点「继续上次舞台」可戴头显续看。换浏览器、换设备、刷新或关闭页面不会传递模型。光剑和机位不会随布局保存。

**屏幕也能导演三幕。** 背包的「全部手持道具」可查看九件道具。进入晴空草坪、夏日泳池或 Live House 后，在本景玩法下选方向或幕翼，「玩法机位」可把镜头对准表演区。草坪的试放线轴放在长椅上。在任一布景选中有腕骨的角色后，都可从「角色道具」选一件，再点要交给的手。角色佩戴本景的道具时，同一组玩法按钮仍可用。

每件道具旁的「用法」可打开或关闭，有场景机关的道具还可从说明前往该景。手追拨衣、侧握喷射、吹泡泡和盖印需进入 VR；屏幕在任何布景都能给角色递上点亮的光剑。屏幕观看不会生成或覆盖 Quest 性能记录。

**逛星环遗庭**：左上「游览机位」可俯看星桥、直达北侧观星台、西侧星图库、东侧测星台，或在桥上回望圆庭。切机位只移动屏幕镜头；从背包选角色后，直接点所在露台的地面放置，「放在中央」仍指原圆庭中心。「重置视角」回到入口。

**逛晨光礼拜堂**：在「游览机位」选「百合彩窗」「从正门看花园」「薰衣草水庭」或「池畔回望教堂」。想摆在室外，可从背包选角色后点池边石砖或拱廊下的空位。

**逛双喜堂**：先在「正堂礼案」机位用鼠标并排放两位角色，再选「宾席望喜堂」拍斜侧面。想看轿帘或镜前陈设，选「巷口迎亲」或「侧室妆台」。这些机位都在同一院里，不会重载角色。

**两人的私密取景**：菜单可单独进入[暮灯情侣套房或月庭双人私汤](../scenery/private-retreats.md)。套房推荐从床尾穿过木隔扇，到夜窗前并排放两人；私汤从更衣间经门洞沿池东岸走到月门石台。两景均可直接切换近景机位，不改变角色位置。

**看材质**：喜院选「门楼漆木与灰瓦」，从门环往上看脊瓦和檐口；教室选「窗边课桌」，从桌面看到封边、漆管和脚垫。轻拖镜头，比较贴在板上的木纹和随视角移动的窗光。[喜院前后对照](../scenery/wedding-materials.md) · [教室前后对照](../scenery/classroom-materials.md)

**给浅发或白衣角色拍照**：选「窗边人像」，让浅色角色站在画面左侧的黑板前，深色角色站在右侧的浅墙前。机位借窗户的侧前光，把亮窗留在画外。[双人摆位实拍](../screenshots/portrait-classroom-shot.webp)

**逛秦淮歌楼**：在原来的登楼与戏台机位之外，选「近看琴弦与漆面」能辨认七弦和十三徽；「埠头系舟处」看缆绳如何绕桩、石岸的水位线落在哪儿。

**逛妇科医院**：在「游览机位」选择「解剖教具台」「妇产科器械盘」或「卫生用品架」看近景。候诊廊、诊室、手术室、女卫生间和候诊宣教墙的原机位也保留。都在同一层；角色可放在镜头能直接看到的空地，「放在中央」仍指走廊中央。

**走校园花园**：教室的「后排走道望花园门」只切机位，「从后门去花园草坪」会换区。返程选「沿砖径回教室」。角色、动作、物件按区恢复，纸鸢仍在草坪玩。

草坪的第二个出口是「穿过门楼去泳池东岸」；「藤径望泳场门楼」只换机位。泳池可选「池畔计时台」「东岸回望藤径」，最后用「出泳场回藤径」切回。屏幕与 VR 读取[同一张连接表](../scenery/campus-garden-routes.md)。

草坪另有「步行进门诊」，从医院选「出门去草坪」即返回。先在两边各留一位角色，可以从雨棚和候诊厅两个方向看同一条花径；每次只显示当前布景里的角色。

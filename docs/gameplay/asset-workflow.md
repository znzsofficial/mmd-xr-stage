# 资产导入与继续舞台

[四幕玩法与道具](./README.md) · [屏幕观看](./screen-viewing.md) · [VR 操作](./vr-controls.md)

## 导入

准备页导入的是**同页背包**。PMX/PMD 是角色，GLB/glTF 是物件，VMD/VPD 是可选动作／姿势；贴图和外部 buffer 仍按原包归属。导入只建目录、检查引用，新开舞台不会把整个包解析成网格或上传到 GPU。不选文件也可进入空场。

屏幕和 Quest 用同一份随游戏发布的角色加载器。点地放置时才建立这位演员的网格、贴图和需要的物理世界；收回会释放上场实例，文件仍可再次放置。正式游戏默认 WebGL＋Bullet；[WebGPU 裙摆实验](../performance/gpu-cloth-lab.md)目前是独立对照，玩家不用挑 loader 或安装插件。

有 Blender 工程时，可用[本地角色转换器](./blender-characters.md)生成可摆姿和测试接触的 ZIP；已转换的包直接选择即可，不用打开 Blender。

- 可选择完整文件夹、ZIP 或单个文件，也可拖放。ZIP 按需加载解压库，在本地解压，不上传文件。
- ZIP 路径以包名为前缀，内部相对路径不变。不同包的同名纹理不会互相替换。
- 同路径（忽略大小写、统一分隔符）的后续文件不覆盖原文件，会列在冲突报告里。可重命名包，或清空后重新导入。
- 检查报告中的缺失/歧义引用提供“为此引用选择资源文件”。选中的文件仅绑定到该模型的该引用；精确匹配完整 ZIP 相对路径的普通文件也可补入，不会使用另一个 ZIP 的同名纹理。
- 同时上场最多 3 个角色和 3 个物件，背包不按这个数量截断。把某件资产收回后可以再取，不需要重新导入。
- 背包封面是可选的：例如在 `角色.pmx` 同目录放 `角色.preview.jpg`。有明确文件夹的资产也可共用该目录的 `cover.png`；散文件只匹配专属封面。不超过 256 KiB 且宽高各不超过 512 像素的 PNG/JPEG 才作封面，缺失或不支持就显示类型图标。
- 有些人形 PMX 用 MMD 单位制作，按米直接摆放会高过屋顶。角色**第一次从背包取出**时，如果能识别头／眼和脚踝骨且它们相距超过 3 米，会按约 1.6 米的骨骼间距设置初始比例。可在角色旁继续调大小。没有识别到人形骨骼的模型、普通物件和已经保存的比例不套用此规则。
- 非 UTF-8 文件名可选择 Shift-JIS 或 GBK 后重新导入。暂不支持加密 ZIP。
- 导入预算：4096 项、单文件 256 MiB、已导入资产总计 512 MiB；大模型仍可能因 GPU 内存限制无法运行。
- 导入检查读取 PMX/PMD 纹理引用及 glTF 外部 buffer/image URI，报告缺失、重名和按文件名回退匹配。检查提示不禁止尝试加载，实际渲染以舞台加载结果为准。

### 放一件 GLB 或 glTF

带内嵌贴图的 `.glb` 可以只选这个文件。`.gltf` 如果旁边还有 `.bin` 或贴图，请选包含它们的整个文件夹，保留子目录。进入屏幕观看 → 背包 → 物件，点文件名，再点地面或「放在中央」。选中物件后可移动、旋转、缩放或收回；退出后在同一标签页继续，无需重新导入。

本地相对路径找不到或对应多个文件时，舞台会报告具体引用，保留原布局。回准备页补入文件或为该引用选择正确的资源，再放置；不会用其他物件的同名纹理，也不会把缺图的白模当作成功上场。

屏幕 WebGL 已用一个内嵌贴图 GLB 和两个外部资源同名、目录不同的 glTF 同场验证：红十字、绿双杠、蓝叉分别显示各自贴图；移动绿件并放大到 1.25 倍，单独收回蓝件，退出再入后剩余两件的位置、缩放和标记都恢复。这个样本覆盖普通网格与 PNG 贴图；特殊压缩扩展不在这项验证内。

## 解除已绑定的动作

角色动作页分别显示「身体 VMD」和「表情 VMD」。解除一个槽，另一个槽及其他演员继续按原时间播放。两槽都清空时，演员回到无动作姿态；全场不再有动作时播放条停止并归零。VMD 文件留在背包，可重新绑定。「暂停」则保留绑定与当前帧。

## 继续与重新开始

- 正常退出 XR 时保存舞台快照：当前模型/物件组合、位置/旋转/缩放、可见性、模型材质参数、播放位置、播放/循环状态及物理开关。
- **继续上次舞台**使用快照的文件组合；准备页当前选择不会覆盖它。
- **进入空舞台**在成功进入 VR 后才替换原来各景的布局；背包文件仍在。如果拒绝权限、取消进入或一直等不到第一帧，原来的摆放和动作绑定仍可继续。在同一轮舞台内可以分别记录各景摆法。收回保留文件，移除实例；刷新、关闭页面或清空背包才放弃本页资产。
- 快照只存在当前页面内存中；刷新或关闭页面会清除。清空资产按钮也会释放上次舞台的文件引用。
- 若尚在加载或物理重建中退出，保留上一份完整快照，避免以半成品覆盖。
- 即使加载队列已结束，只要存在未恢复的模型、动作或纹理告警，退出也不会覆盖上一份完整快照。
- 不序列化 Bullet 模拟中的速度/接触缓存；恢复后按保存的播放时刻重新初始化物理。
- 玩具、角色握姿和月面邮票只保留在当前布景的本轮互动中。切景或退出后，角色摆法可以恢复，道具需[重新递给角色](./vr-controls.md#把道具递给角色)。

## 纹理失败与重试

模型解析成功但纹理解码/解析失败时，舞台会保留可用模型并显示完整诊断。点击“重试失败项”会重建该模型、保留其摆放和材质设置，并把动作重新绑定到新模型 ID；其他成功模型不重建。缺失的本地文件需返回准备页补入后重新进入。

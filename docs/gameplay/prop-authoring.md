# 新增手持道具

道具不占背包的模型／物件槽。同一时间只有一件活动道具；普通道具只用玩家手柄或角色腕骨之一。成对的遥控器与佩戴件算同一件：前者留在玩家手中，后者只跟随绑定的可见角色。切换场景、开始新一轮或退出时归还，不写入布局。已有道具的玩家操作见[手持与交接](./vr-controls.md#把道具递给角色)。

## 只需摆姿的道具

1. 在 `src/mmdVrShowcase/play/` 写一个米制外观组件。登记 `grip.point`（在最终 `PlayPiece` 坐标系内，量取握柄中央而非模型原点）和 `grip.pitch`（弧度，抵消手柄视图的倾角）。角色面向用腕到指根的方向，握柄朝食指一侧；两只手各自拟合，校准不改角色骨骼。若自行创建纹理、合并几何体，卸载时释放它们。
2. 在 [`propViews.tsx`](../../src/mmdVrShowcase/play/propViews.tsx) 导出一个 `PropView`，例如 `export const woodFan:PropView = {Piece:Fan};`。同一个 `Piece` 同时用于手柄和角色。外观名可以复用，不必和道具 ID 相同。
3. 在 [`propCatalog.ts`](../../src/mmdVrShowcase/play/propCatalog.ts) 的 `catalog` 加一条。对象键就是唯一 ID；顺序就是货架顺序。下面是折扇的示意，先在中英语言包中提供相应的翻译键：

   ```ts
   fan: {
      label:'toyFan', home:null, homeLabel:'allSets', visit:null, view:'woodFan',
      grip:{point:[0,-.042,-.06],pitch:0},
     guide:{vr:'guideFanVr', screen:'guideFanScreen', end:'guideFanEnd'},
   },
   ```

`home` 指场景机关的位置，无机关可填 `null`。随身特效设 `portable:true` 并显示 `allSets`：不论当前房间都允许持有者使用 `HeldEffect`。如泡泡枪可以到处发泡，`home:'pool'` 则仅让泳池开船。`homeName` 可提供房间内的别名。纯摆姿道具不需要逐帧特效。`guide` 写清手柄操作、屏幕能做什么及结果如何结束。

这样就会出现在 VR 的「背包 → 玩具」、屏幕道具目录和角色下拉框。VR 每页三件，关说明回到原页，页脚的收回和翻页位置固定。不要增加底板高度、另写道具 ID 枚举或再做一张按 ID 索引的用法表。

## 需要动作时才加行为

| 入口 | 调用时机 | 已有例子 |
| --- | --- | --- |
| `onGrip(at, dir)` | 本道具由该手柄持有、在所属景内、追踪有效、菜单及放置未占用输入时，新按下侧握键一次。输入是世界坐标，跨帧保留须复制。 | 对准泳池门才发船；错过目标仍可吹泡泡。 |
| `HeldEffect`（外观导出） | 玩家持物时挂在世界根，接收同一帧的 `usable`、`action`、方向、位置和 `dt`。`off` 时不可发射；可继续让旧粒子退场。 | 气泡按住连续发射；盖印器瞄准环和三枚印记。 |
| `screenUse: { label, duration? }` | 演员拿好有 `outlet` 与 `HeldEffect` 的道具后，屏幕生成一个动作按钮。`duration` 是秒；省略即一次 `start`。房间在腕骨更新后从实际出口取样，触发同一世界空间效果。 | 星图点一次添一星；彩带连续画 1.2 秒；水母灯荚用一次按键放出。 |
| `Station`（外观导出） | 在所属景挂载一次，屏幕与 VR 共用。是否有持有人由道具自己决定。 | 幕布收回话筒后仍显示；风筝线随握点移动。 |
| `story` | 可选双侧指令，自动用于屏幕玩法区和角色握姿工具。每个故事景只注册一个 `story`。新故事景还需在 `screen/ScreenCamera.tsx` 提供相应机位。 | 左／右风向、染翼、发船。 |
| `onEquip` / `onScreenEquip` | 重新拿取时调用前者；屏幕在可用地点新取一件交给角色时调用后者。单纯换腕不调用。 | 光剑重拿收刃，屏幕在任意布景初次交接则亮刃。 |
| `onStow` | 主动收回、换另一件、持有手柄断开，或演员持物被清理。玩家递给角色和同件换腕都不是收回。 | 风筝落下、渡船消失、光剑收刃。 |
| `onLeave` | 离区、结束本轮或卸载时；此时物品可能早已收回。 | 清除染印与邮票，二者平时收回仍保留。 |

[`stagePlay.ts`](../../src/mmdVrShowcase/play/stagePlay.ts) 负责持有人和交接；[`wristSocket.ts`](../../src/mmdVrShowcase/play/wristSocket.ts) 负责识别腕骨、掌心定位和倾斜／进深。不要让外观重新查找骨骼，不要给物品添加角色动画帧循环。要做逐帧手柄效果，参考 `heldEffects.tsx`：复用公共的追踪、房间检查和握键锁存，松开后再握才能触发；不要从道具组件另行监听 XR 按键。

**依赖方向**：目录可导入纯玩法逻辑／轻量状态模块，外观名仅以 `keyof typeof import('./propViews')` 引用。`propViews` 才导入实际组件。不要从组件文件再导出动作给目录使用，否则准备页经由持握状态也会拉入渲染循环依赖。

## 验收一件新道具

- `pnpm exec vitest run src/mmdVrShowcase/play src/mmdVrShowcase/components/BackpackHud.test.tsx`，再做类型检查。测试新效果实际的开始、持续和结束，以及换腕时应该保留的状态。
- IWER 或手柄：右 B → 背包 → 玩具，翻到目标页；用扳机打开／关闭用法，选自己的左／右手。先在非所属景试，再进所属景试。打开菜单时握住侧键，关菜单后不应误触。试观看菜单的快速收回，以及任意货架页的收回。
- 已放置的角色：递给可用的一侧腕骨、换腕、调握姿、播放，再隐藏或收回角色。缺腕、不可见时不应吞掉玩家的道具。
- 屏幕：背包目录、用法、前往所属景和角色手腕按钮应与 VR 指向同一件。切景再回来，不恢复上一景的持物、飞行或画面。模拟器能验证输入链，Quest 光学可读性与手柄握感需真机判断。

## 接触、物理与触觉

**原生道具碰撞与表面反馈是两层。** Bullet 依次追加 2 个手柄、12 个手追和 8 个道具槽位：硅胶件 0–3、按摩棒 4–6、跳蛋佩戴件外壳 7。支架复用硅胶件的四段，遥控器、取出环均不另占碰撞体。佩戴件在佩戴者的物理世界中读当帧骨盆；手持读当帧握姿，腕持及支架以最近一次显示姿势喂给 Bullet。所有槽固定，重绑或失追后先停泊，移出原生动态刚体范围才能重新参与；不能从模型内部凭空弹飞衣摆。没有相容的活动刚体时不制造布料。软头自身的显示压入（硅胶件 3.5 mm、按摩棒 5 mm）不等于演员皮肤的压深。

`pnpm dev` 后用[道具拨衣探针](../../scripts/prop-cloth-smoke.html)检查发货版 Bullet：禁用其他合成碰撞、暂停在同一个 VMD 姿势，用端部／柄尾分别托起已有衣摆刚体，再撤手、失追重现，检查加权顶点、手腕矩阵和物理重建次数。无刚体模型的可见表面另用[软头探针](../../scripts/wand-surface-smoke.html)检查。

手持姿态只接受当前 `XRFrame` 的有效输入。软头查询当前蒙皮三角面；表情只在显示阶段叠加，下一次求值前还原。拓扑分帧准备，超出 45 万顶点／80 万三角形的模型跳过表面探测，不用包围盒代替。遥控跳蛋的两件共用节律时钟，三轴校准以实际厘米计，不改骨骼或分景快照。

骨盆附件的硅胶件仍只有一件：[输入接线](../../src/mmdVrShowcase/pelvic/input.ts)暂存当前手柄帧的侧握，[房间驱动](../../src/mmdVrShowcase/pelvic/rig.ts)在同帧骨架更新后，用[实际喷口](../../src/mmdVrShowcase/pelvic/solver.ts)判定有效内部、可见外部或未验证。未验证的触发消费后不可补喷，内部命中也不能产生外部粒子。剖面使用抽样副本；计量不读这份显示缓存。用户选用的开合形态是显示层，下一次求值按叠加逆序还原。

### 按摩棒电机同步

[电机](../../src/mmdVrShowcase/play/wandMotor.ts)在换档时记录起点。[棒头动画](../../src/mmdVrShowcase/play/BoutiquePieces.tsx)和[持棒手的反馈](../../src/mmdVrShowcase/play/wandContact.ts)用同一渲染帧时间算圈数：低档 4 Hz、高档 7 Hz。转交手腕保留档位；VMD 暂停、没有演员或关闭表面探测都不影响底振。

- **每拍最多发一次。** 初触加重第一个尚未发出的脉冲，当拍已发就落在下一拍；持续贴住不重复加重。帧延迟只发当前拍，不补播。仅使用玩家「关／轻柔／标准」偏好、当前持棒手和当帧有效握姿，不开后台定时器。
- **停振：** 关机、收回、交接、切景、菜单／放置占用输入、失追或会话结束时，丢弃待发重音并停止手柄输出。屏幕与角色腕持只显示棒头动作。
- **真机短测：** 暂停舞蹈，拿同一只手在空中各试两档，再触碰、撤手、换手、收回。Quest 3S 重点确认不看灯能否分档，初触那一拍是否清楚。

统计只含表中外观。手柄话筒的印靴另加两次绘制；光剑亮刃另加三次。按摩棒低／高档分别多绘制一／两圈指示灯；关闭时棒头回正并取消摆动的帧订阅。羽毛刷没有逐帧特效、衣物碰撞或触觉反馈。气泡、准星和场景机关另算，不用这些数值推断 Quest 帧率。除话筒复用一张 256 × 128 的程序网罩纹理外，没有新增随游戏分发的模型或贴图文件。

**本轮交接复核**：在桌面背包用双腕合成模型打开两件用法、交给双腕并调高。播放 VMD 时，16 帧内两件道具的实际握点分别移动约 3.2／3.6 厘米，始终保持无指骨回退的 4.5 厘米腕距。隐藏再显示持棒角色时，道具没有恢复。

在 IWER 用扳机翻到第三页、关闭说明回原页，实际侧握循环关／低／高／关；按住侧键关菜单不会误启动。棒头变速不移动握柄，递给另一只腕保持档位；第三页收回、替换道具，以及带电切景都能结束效果。Quest 近眼灯圈分辨度、羽缘稳定性和握持舒适度仍需实机检查。

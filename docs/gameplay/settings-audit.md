# 设置清查｜以 `be863f1` 实现为准

这是 `be863f1` 的历史审查。**清理已实施**：[当前三栏和实际操作](./vr-controls.md)。独立设置模块为 `src/mmdVrShowcase/settings/`；准备页设备设置在 `prep/DeviceSettings.tsx`。旧偏好中的动态同组碰撞、无效跟随系数和质量档不再被读取；维护探针仍能独立对照两种物理路径。下表保留改动原因。

## 先清理这四项

| 设置 | 实际行为 | 建议 |
|---|---|---|
| 衣物互撞 | 母项目 `1e4cf85` 已有，独立仓库从 `62fc618` 带入。对**每个非静态刚体**额外允许与自己所在组碰撞，不识别衣服。不会跨角色；关掉只撤销额外放行，原 PMX 碰撞和关节仍按作者配置工作。开物理时切换会为在场模型重建物理世界。 | 从日常「重力」页撤下。若保留复现能力，叫「强制动态刚体同组碰撞」，放维护探针，默认关。迁移旧的开启偏好时要明确处理，不能只藏按钮却继续生效。 |
| 骨骼跟随（柔顺／平衡／紧跟） | 前端传 `dynamicWithBoneRotationFeedbackScale`，当前 0.8.6 的实际后端没有读取该字段。与 VMD 骨骼跟随、角色持道具或托裙摆无关。 | 删除面向用户的三档。未来真要提供手感调节，先用同一动作证明参数会改变预期轨迹。 |
| 物理质量（低／中／高） | `maxSubSteps` 的 3／5／8 传到原生步进；`solverIterations` 的 15／20／20 没有传到原生世界。舞台每回调最多推进 50 ms，固定物理步长 1/60 秒，通常连低档的 3 个子步都已覆盖。不等于调高能让衣摆更精细。 | 日常保留固定质量；补步上限如需对照只放诊断。不基于旧文档的迭代数解释帧率。 |
| 角色材质：金属度／粗糙度 | 控件会存值、也会写 shader uniform；当前舞台以 `toon`／`mmd` 渲染，环境贴图为空、环境强度为零。这两个值在 PBR 或环境反射分支里才会改变结果。 | 按材质能力显示；当前默认路径保留显隐、透明度和发光，别给用户两根可以拖动但看不出效果的滑杆。 |

**自碰撞的实例。** 项目已有的模型检查记录中，288 个纯动态裙摆刚体在第 6 组，原作者屏蔽了该组内部碰撞。强行放行会改变哪些裙片可以相撞；头发或饰品若也符合分组条件同样会受影响。不能据此量化 FPS 损失。之前的「屏蔽裙摆接触」探针隔离的是另一种条件，不能拿来当这个开关的 A/B。[原记录](../three-mmd-loader-maintenance.md#离线诊断结果) · [碰撞掩码实现](../../src/mmdVrShowcase/mmdRuntime/mmdPhysics.ts)

**核实方式。** 从 `createCustomBulletMmdPhysicsBackend` 跟到已安装的 `dist/physics/mmdAnimBullet.js`。再在本机为[真实 Bullet 回归](../../scripts/physics-smoke.html)的 options 加读取记录：直接缓冲与复制缓冲各 240 帧，接触检查通过，两路径轨迹差 0；读到 `onStepWork`、`maxSubSteps`、`fixedTimeStep`，未读跟随系数和迭代数。此处证明的是参数连接，不是 Quest 性能或手感测试。[舞台时间上限](../../src/mmdVrShowcase/mmdVrClock.ts) · [材质着色器](../../src/mmdVrShowcase/mmdRuntime/mmdMaterialEnhance.ts)

## 功能有用，但应修行为或入口

| 设置 | 使用时会遇到什么 | 建议 |
|---|---|---|
| 手追开关 | 关闭会同时撤掉手模型、菜单射线和手部碰撞。纯手追用户可能亲手关掉唯一能点菜单的输入；低头召回只提供目标，没有射线就点不了。 | 优先保护最后一个输入源；「能用手点菜单」与「手能拨衣」分开。后者已有碰撞开关。 |
| 手碰撞、球半径、接触摩擦、回弹 | 碰撞开关同时管手柄和手追。半径除了改手柄球，还间接缩放掌面与指腹。摩擦／回弹改的是玩家碰撞体，不是布料材质。改这些刚体定义会换数组，后端下一步会重新创建原生世界、重新播种姿态。 | 保留玩家交互开关和手柄震动。半径、摩擦与回弹撤出日常操作；若保留调校，标明对象，在暂停时一次应用，验证衣摆不跳。 |
| Quest 预设／自定义／实验渲染覆盖 | 准备页既有 Quest 预设又有低中高画质。点「自定义」会关掉倍率与固定注视点覆盖；再点倍率，覆盖自动打开。只是想手调一项也会改变是否向头显提交另一组设置。 | 「自定义」改为当前组合的状态，不做会修改设置的按钮。把实际请求值和跟随设备默认区分开。 |
| DPR／抗锯齿／分辨率 | VR 的 Canvas DPR 和头显投影层倍率是不同的控制；普通屏幕 Canvas 固定 AA 开、DPR 范围 `[1,1.6]`，并不使用准备页这两项。刷新率也是设备请求值。 | 标出影响的模式、是否需重新进入；屏幕选项要么接入屏幕渲染器，要么明确写「仅 VR」。保留独立的实时阴影开关。 |
| 自动走速／跟随／用户身高 | 自动走速随画质档变（1.00／1.15／1.35），但 HUD 一律显示「中」。面板跟随只转朝向，不跟着人走。「身高」是视点的垂直偏移，滑条覆盖 −5～+50 m。 | 走速与画质解耦并显示实值；「跟随」改为「面板朝向我」；区分调眼高与大范围升降。 |
| 强调色／地面光／轮廓光 | 当前准备页已没有强调色选择器；已有主题值仍用于准备页部分控件、舞台无天空时的底色、网格和旧放置平面，不影响瓷白 HUD、角色或布景材质。地面光在原场地中心，轮廓光是预设点光源。 | 固定舞台灯按场景展示；用场内设置调实时阴影、曝光和灯光，不用强调色调材质。 |
| 显示帧率／物理调试／详细物理诊断 | FPS 小牌只挂在展开的设置页，净场看动作时看不见。准备页的详细诊断是进 VR 的初值；VR 调试是本次会话开关，控制碰撞可视化和额外计数。正常性能报告另行记录。 | 标明 FPS 的显示位置；调试交给诊断页，不让用户为了导出报告误开。 |
| 选景／返回观看／播放 | 公共菜单和画质页均可选景；展开设置的顶部和底部都有「返回观看」。VR 播放只检查有角色；屏幕播放还检查有动作，播完会从头开始。 | 选景和返回各留一个明确入口；两种模式统一无动作与播完状态。 |

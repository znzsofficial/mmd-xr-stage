# VR 控制面板

## 2026-11-17 改进

- 观看模式保留播放、进度、打开菜单和退出。调整模式为“模型/物件、画面、物理、操作”四页，同一时刻只挂载当前页内容。
- 模型与物件统一分页，每次一个资产；材质页每页四项，返回按钮回到模型页。替代旧实现的模型横向三列与物件/材质在主面板下方约 2 米的排列。
- 顶部有召回和返回观看，底部保留播放/循环/退出/诊断。主面板宽 2.65 米，召回到当前头部水平方向前方 1.8 米、下移 0.12 米。初次 XRFrame 到达后重新定位，避免使用桌面相机初始姿态。
- 右手 B 按钮召回并展开菜单；射线/手部用户也可点击面板的召回按钮。拖动或滑块交互期间禁止召回和自动朝向更新，保留移动/转向抑制逻辑。跟随开关仍指面板朝向用户，不强制持续黏住视线。
- HudButton 最小高度 0.13 米；文字限制在纹理宽度内；去掉重复内层背景贴图。按下、停留、松开即可执行，支持慢速扳机操作；移出/取消不执行，随后合成 click 被抑制，防止重复触发。

## 性能与诊断

- 普通 GLB/glTF 网格恢复视锥裁剪，变形网格维持保守策略。实际收益取决于资产是否合理拆分，单一巨大网格不会因这个改动自动变成分块场景，也不会自动获得 LOD。
- 浏览器 WebGL 合成场景：300 个普通立方体，1 个在视野内；draw calls 300 → 1；移到另一组网格后 draw calls=3，物件可重新进入视野。不是 Quest 帧率基准。
- 诊断增加上一渲染调用的 draw calls / triangles、renderer 跟踪的纹理/几何体数量，以及采样窗口内 `runtime.update` CPU 平均/峰值。后者包括模型动画/物理/材质同步，不包含全部 React、UI、渲染提交或 GPU 时间。计数不是显存字节数，不能据此估算完整 GPU 预算。
- 当前未接入 GPU timer query；不将 FPS 间隔或模型 CPU 时间冒充 GPU 耗时。

## 验证与限制

- Node 26.12.1 上迁移到 jsdom 31.0.1 / @types/node 26.6.6。
- 自动测试覆盖分页后只挂载一个模型面板、四页切换、播放退出可达性、扳机释放与取消、召回坐标变换、静态裁剪与变形网格排除、诊断采样。
- 完整应用使用 IWER 模拟器加载三个生成 PMX，检查模型分页、材质与设置页的实际渲染；截图检查无上下堆叠遮挡。没有修改准备页配色，也没有引入新的 XR UI 依赖。
- Quest 上仍需确认文字角尺寸、射线瞄准、长按松开、B 键召回、手部操作与左右眼裁剪；模拟器不能替代头显舒适度和帧率验收。

# 性能：下一轮先修什么

**先查稳定播放；遇到回场慢，用新版报告单独查恢复。** 11 月 19 日 10:17Z 的教室真机报告：120 Hz、阴影关；空教室约 116 FPS，单角色开物理播放约 49 FPS。目标仍是稳定 72 FPS。报告中的帧率来自 XR 回调，不是 GPU 耗时。[本次条件和统计](./viewing-and-diagnostics.md#已有测量)

| 优先级 | 状态与下一步 | 怎么知道有用 |
|---|---|---|
| 1 · 持续播放 | **先做本地对照**。30 个筛选后的播放窗口里，模型更新中位数 9.66 ms；动画／IK 2.34 ms，后端 5.64 ms，其中原生步进 5.30 ms。先从[物理后端](../../src/mmdVrShowcase/mmdRuntime/mmdPhysics.ts)查参与求解的碰撞对与裙摆约束。 | 同一 PMX、同一段 VMD、固定步长和质量，一次只改变一个因素。比较 `worldStepMs`、总更新时间和衣摆运动／接触。保住原 PMX 约束、暂停拨衣和恢复；桌面收益另用头显确认。没有同次「播放＋物理关」对照，不能把全部帧率差归给 Bullet。 |
| 2 · 回场恢复 | **计时已上线，待新版头显事件**。首次放置看 `placements[]`；切回有已保存资产的区域看 `roomRestores[]`。此前 8.472 秒是采样空档。 | 先筛 `success:true` 的目标布景，看 `entryToVisibleFrameMs`；用 `preQueueMs`、`queueToReadyMs`、`readyToFrameMs` 找最长一段。队列慢再拆 `taskWallMs`（模型、动作、物件）和 `modelWork`（解析、贴图、预上传）。子阶段不重复相加，空场或取消切景不算成功样本。 |
| 3 · 暂停交互 | **待验证原型**。单角色暂停开物理时约 55 FPS，模型更新约 7.19 ms。报告没有手部接触记录，不能假设当时衣摆已静止。先测静止／接近／接触三段，再试可回退的休眠。 | 只在衣摆稳定且手远离时减少求解。手靠近要在第一次触碰前唤醒；测移开回落、追踪丢失再进入、seek／循环与恢复播放。任一项漏碰或弹飞就保留旧路径。 |

**已完成的物理切换优化。** 开关时复用模型渲染资源；教室首次开／关／再开耗时 540／441／67 ms，用户反馈切换变快。旧礼拜堂的一次 3.534 秒可供参考，但不是同条件 A/B。[实现与姿态对照](./physics-toggle.md)

**后续验收。** 角色手掌托裙摆默认关闭；用手实际经过裙摆的 VMD 验证托起、移开回落及接触时的开销。10:17Z 的报告早于此功能。渲染侧若需比较阴影，固定场景、角色、机位和物理设置，只切阴影；教室关阴影与旧礼拜堂开阴影不是一组对照。地台、草坪各 15 分钟的长测另做，按实际 Hz 比较 P95 和超过 1.5 个帧周期的比例。

# 性能：下一轮先修什么

**教室真机首次开物理 540 ms，再开 67 ms。** 持续播放仍未达标：最新头显报告单角色开物理约 49 FPS，已测后端主要耗在原生步进。下一步分测原生求解的接触／约束负担，并给跨区角色恢复补直接计时。[本次条件和统计](./viewing-and-diagnostics.md#已有测量)

| 优先级 | 状态与下一步 | 怎么知道有用 |
|---|---|---|
| 1 · 物理切换 | **已实现**。开关及改自碰撞保留网格、腕骨、材质、贴图，切换每个角色自己的求值器与物理世界；失败可从文件恢复。 | [新旧路径对照](./physics-toggle.md)。头显只需看同景同角色 `physicsRebuilds[].durationWallMs`，确认播放或暂停状态与握姿保持。 |
| 2 · 持续播放 | **已修一轮，待新版真机数据**。礼拜堂旧样本物理关／开为 52／32 FPS，开物理后模型更新 16.91 ms，后端占 9.85 ms。`c4d068a` 已过滤辅助体互碰并去重共享骨架更新。 | 先看新版稳定播放窗口的 `bulletStepWork`：输入、原生步进、结果读回分别多少，再决定改哪段。`steps` 不是 Bullet 子步数。保住暂停拨衣、碰撞与动作轨迹。 |
| 3 · 渲染与长测 | **待对照**。已有记录一直开阴影，无法判断关物理时剩下的帧率差距有多少来自渲染。 | 同景同机位、同角色，先只切阴影；需要长测时，地台与草坪各播 15 分钟，每场分别导出，按实际 Hz 比较 P95 和超过 1.5 个帧周期的比例。 |

**暂缓继续调贴图上传批次。** 重复读取共用贴图已在 `bb3fa87` 修复。最近两次真机贴图阶段为 1.395 秒和 0.572 秒，场景不同、各只有一次放置；单独缩短几十毫秒的让步不是当前重点。稳定 72 FPS 仍是目标。

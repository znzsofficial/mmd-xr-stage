# 行星弹道：整身扫壳的 CPU 对照

[`createShellSweep`](../../src/mmdVrShowcase/movement/orbitalSurfaces.ts) 现在先用整身扫过的范围筛一遍星，再按原图册顺序检查各身体截面。范围包括马达脚、追踪偏移后的脚、整个身高轴、未截短的真实头位、截面半径和本步位移。候选星仍用原来的壳和细分阈值判断接触；引力所属星不限制碰撞候选。

同一次飞行的相邻扫掠可以复用上次真正求过的右端点：新查询必须从段首开始，且星体身份、半径和参与地形计算的三个星心相对坐标完全相同。复用的是静态壳的原始径向净空，本段按自己的截面半径重新算阈值。候选表、端点和命中对象都属于该飞行，归程和另一位调用者没有前一程的缓存。潮洞仍查询原来的三角地面，没有另设高度捷径。

## 实现前后

两组都用同一工作区的 `stepOrbit`、地形和输入；只在对照组加载 `899f22c` 的旧扫壳器。Node 26.12.1 单线程、i9-13900HX，启用扫掠记录窗口。以 72 Hz 传入时间，预热后交替测 11 轮；每轮六次完整模拟。单位为每个模拟显示帧的平均耗时，再取轮间中位数 ± MAD，**不是 Quest 帧耗时**。求值次数是一次静止追踪姿态航程的实际调用总数。

| 路径 | 旧 → 新（μs/模拟帧） | 壳面净空求值：旧 → 新 |
|---|---:|---:|
| 棱盐普通跳 | 13.99 ± 0.15 → 7.93 ± 0.31 | 3,877 → 2,540 |
| 棱盐 → 玄釉（印外） | 10.20 ± 0.78 → 5.46 ± 0.36 | 1,021 → 718 |
| 玄釉 → 棱盐（印外） | 14.89 ± 1.03 → 6.11 ± 0.29 | 1,340 → 897 |
| 潮洞台阶普通跳 | 86.36 ± 6.28 → 68.81 ± 6.33 | 3,610 → 2,527 |
| 深空漂移（100 帧） | 5.83 ± 0.59 → 0.56 ± 0.04 | 0 → 0 |

**逐值对照。** 七条路径 × 四组帧序（72/90/120 Hz 和不均匀）× 固定／移动追踪偏移，共 56 趟、6,955 帧。每帧的脚位、速度、归属、擦碰和落点记录完全相同。另比对 3,091 次扫掠，含 11 星、长段多候选、倾斜、超范围眼高和近切线；命中时间比例、点、法线、部位和追踪标记无差异。相同输入序列内的对照不要求不同输入帧序产生相同的追踪路径。[专项测试](../../src/mmdVrShowcase/movement/orbitalSurfaces.test.ts)也独立核对潮洞真实取样数、交错调用和头位重新标定。

**切线热点仍在。** 硫珠平帽净空 0.31 mm、切向移动 20 mm，旧／新均作 1,042 次净空求值；单次扫掠 349 ± 20／361 ± 27 μs。Quest 计数只记扫掠器实际求过的端点和递归中点；缓存命中、粗筛、命中点重建和潮洞内部二分不计。每次扫掠报告总数以及所有截面合计求值最多的星，并列按图册顺序，零次没有星体。用此指标区分罕见逼近壳面的代价与普通在轨帧。

本机复算：`node --single-threaded --import ./local-review/verification/gravity-review/product-loader.mjs ./local-review/verification/gravity-review/product.mjs`。`product-results.json` 保留实现指纹、完整计数、耗时范围和每趟落地结果；计时版本未加独立的取样探针。

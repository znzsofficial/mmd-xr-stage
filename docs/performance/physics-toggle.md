# 物理切换：同一副骨架换运行时

开启物理仍用 `DefaultMmdRuntime` 和专属 Bullet 世界；关闭仍按 loader 原规则选择 PMX 的 WASM 动画运行时或兼容求值器。两条路径共享当前角色的渲染对象。只在本次切换批次保留待安装的运行时；不开常驻双世界，也不跨场景缓存模型。绑定前还原首次导入时的局部骨骼姿态，在下一次舞台求值时从当前时间重新播种。未完成准备时保留旧模型；已有部分绑定且失败时走旧的文件恢复路径。

## 同条件桌面对照（2026-11-19）

同一指定原版 PMX（505 骨、317 个动态刚体）、同一屏幕观看页、Edge / SwiftShader，各运行一轮「开、关、开、关」。测 `physicsBusy` 起止墙钟，未播放动作。旧路径仅在本地对照中启用。

| 模式 | 第一次开／关 | 第二次开／关 | 每次 2048² 整图读回 |
|---|---:|---:|---:|
| 整体重载 | 7.526 / 3.316 秒 | 3.188 / 3.573 秒 | 3 |
| 原地切换 | 0.683 / 0.707 秒 | 0.574 / 0.607 秒 | 0 |

两个模式各自起页、先旧后新，首次开还含冷启动与调度成本。这是页面忙段，不是原生 Bullet 步进时间，也不能换算为 Quest 帧率。

另跑[固定时钟、真实 Bullet 对照](../../scripts/physics-toggle-probe.html)。同一角色、同一段合成 VMD、同一位置旋转与缩放，比较开启、改自碰撞、关闭、再次开关后的首帧和后续帧；15 个姿态样本、121980 个骨矩阵／表情 Float32 数值，最大差值 0。新路径 5 次均未调用 GPU 预准备。动画与静态双角色[暂停拨衣](../../scripts/paused-cloth-smoke.html)在开关后仍有实际接触、抬升、寻址和恢复；模拟 XR 播放时腕骨持物在开／关后继续运动。单测还覆盖第二个世界准备失败、部分绑定失败回滚、异步时清场／退出与资源释放。

## 关物理：复用上场时的那一次读取

导入背包不读模型字节。首次放置照常读一次；若页内在场／正在放置的角色合计还有 **32 MiB** 源字节额度，就把同一份 `Uint8Array` 交给模型加载器，关闭物理时直接用它创建动画求值器。按原 `File` 对象计费，未完成读取也先占额度；同一文件同时上场只读、计费一次。同名的另一个文件不能命中。额度不足或单文件超限时走原文件路径，不挤掉在场演员；原地开物理不读文件，也不会为稍后关闭而预建第二个世界。

移除最后一个引用、清场、换房或退出释放租约；失败的加载不占位，晚到的旧结果不能填回新租约。这个限额只管保留的原始模型字节，不是总堆或加载峰值：已发出的 File I/O 不能取消，解析临时量、WASM 和 GPU 资源另计。命中时仍需建求值器、重新绑定 VMD；关闭报告看 `physicsRebuilds[].work.modelByteHits`／`modelByteReads`（本次角色数）及原有 `readModelMs`，不要将此前真机的 846 ms 当成新版已测节省量。

**实模验证。** [Node 切换探针](../../scripts/verify-mounted-model-bytes.mjs)用同一本地约 19.0 MiB 的 PMX、同一身体 VMD，顺序运行零预算和正常预算，各做「放置 → 开 → 关 → 开 → 关」。五次各自的模型读取数：**1 / 0 / 1 / 0 / 1 → 1 / 0 / 0 / 0 / 0**。探针保留背包的 `File`，对每次返回的 `ArrayBuffer` 另留弱引用，跨任务强制 GC：正常预算下，在场时该源缓冲仍占约 19.0 MiB，移除后池计费和仍可取回的源缓冲均归零。两组首开前均零世界，全程各建、销毁两个，峰值一个。四次切换后的 23,928 个骨矩阵、表情和蒙皮采样数值完全一致。Node 的内存 File 不代表 Quest 文件系统。

## 何时优化或更换引擎

目前保留 TypeScript 和 Bullet。TypeScript 类型在构建时擦除；物理步进已在 WASM 中执行。11 月 19 日教室报告把后端墙钟 5.64 ms 拆开，原生步进占 5.30 ms，输入与输出合计约 0.30 ms。先分析碰撞对和约束；只有在相同画质、物理质量、手部接触与动作样本下优化后仍无法达标，才值得做替代引擎的单模型 A/B。[当前优先级与验收](./README.md)

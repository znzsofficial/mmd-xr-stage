# 印外擦坡与北台偏置低顶｜CPU 复测

[原始反例](./orbital-review.md)。普通弹道以起跳为时钟起点，子步最长 1/120 秒、高速时再限到 6.5 厘米。显示帧可以消耗半个子步；命中瞬间只用已花时间更新速度，余时继续扫。斜坡按命中部位的壳面净空梯度反弹，落地导航仍取星体径向。一次连续擦碰只扣一次切向速度；整身脱离 2 毫米才重新计数。

复算：`pnpm exec vitest run --maxWorkers=1 orbitalGrazes orbitalFlight orbitContact planetFixtures tideTravel TwinLeapMotor`，6 文件、67 项。六档输入是模拟显示时间，不代表头显帧率。

**IWER 复验：**

1. 在验证构建上复用 `local-review/continuous-horizon.cjs` 的双眼矩阵记录器和真实 `device.controllers` 输入。06 风道到伞灯，离开足印，走到报告脚位；小幅推杆收敛到毫米级，头高设为 1.65 m。世界切向 `(-0.349687, 0.726560, 0.591464)` 变到当前导航局部空间，按脚本的逆死区映射推满，同时按右 A；次帧松杆。记录**实测**起跳位置、双眼、帧时、起落／擦碰计数。前向结果对照该实际起点，不能把相距几厘米的起跳当作同一临界样本。单独跑 `capture` 核对盐→釉头先触地、持 A 落地后第一步；`routes` 为 06 风道／足印往返对照。
2. **北台偏置低顶已跑。** `node local-review/offaxis-orbit-roof.cjs` 自启独立 Vite 和单个 Edge/IWER，也可用 `QA_ORIGIN` 指向另行启动的验证构建。准备页导入脚本自建的 GLB，再以 XR 背包、手柄射线实际放置；下面的数值来自当前开发源码，没有写入相机或舞台状态。

   放置后的板中心 `(0.500, 2.080, 2.158)`、底面 Y=2.050 m。先在板旁按右 A，双眼中点升 **77.77 cm**。站定后实际头位沿 X 移 **50.00 cm**，同一马达原点、双眼都在板的水平范围内，再跳只升 **30.53 cm**，最高 Y=1.935 m，距底面 **11.50 cm**；全程没有一只眼进板。另在板侧把真实头位提高，再横向探入 50.00 cm：两眼都能进入板内，追踪原点位移 <0.001 mm。逐帧眼位、实测板变换与汇总在 `local-review/verification/offaxis-orbit-roof/{frames,result}.json`。

**构建包的印外实跳。** 模拟双眼从 06 风道走到伞灯星，原生摇杆将起点定位在报告脚位 0.20 mm 以内；头高 1.65 m，真实右 A 起跳。1,873 个双眼采样帧保持起跳视野，导出一次起跳、两次擦坡、零落地，最终离开引力井，和 CPU 临界样本的结局一致。该航程最重单次扫掠是琥珀屿的 182 次实际净空求值。另走 03 到棱盐，在印外被玄釉捕获；208 个飞行采样帧扣除头部侧转后未测得额外基座转角，落地直接续走、主动 Y 后从 04 返航。06 风道与足印也已双向走通。以上不是头显 FPS。

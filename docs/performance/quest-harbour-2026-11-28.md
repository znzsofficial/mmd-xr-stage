# Quest 3S 海站：同页 WebGPU 与 WebGL 回访

两份记录来自 `8695550` 的入口制品 `index-BRxGwRYT.js`。同场地、同一条 14.8 秒动作时长，均为实际 **120 Hz**、每眼 **1428×1496**、周边着色实得 **0.5**、阴影关。WebGPU 播放段全程仿终末地，裙摆报告 `bullet`；WebGL 用其原 MMD 路径。动作时长相同，采样端点、画风和机位未锁定，数字按各自的一趟记录看。

查询时间在演员更新之外。两个后端的原生步进中位都已超过 120 Hz 的 **8.33 ms** 帧预算；而这轮远手柄优化在可能补多个子步时会保留精确读取，所以不能拿桌面 72 Hz 的短步收益推算本趟。报告有正接触查询（269／181 次），这不是振动次数。WebGPU 空场 71 窗回调 FPS 中位约 54，说明还要把布景、视角和提交分开查；导出未启用 GPU 分段，无法量出双眼渲染耗时。

**下一次真机对照：**锁定原 MMD、机位和舞段，并选实际 72 Hz；先看新版能否开启 GPU 衣摆、压低开物理播放的 CPU 慢帧，同时保住拨衣。暂缓改默认画质和求解参数。另报的树盘闪烁已在 [9cab064](https://6f5e5b11.mmd-xr-stage.pages.dev) 修复。

**外套下摆修复：**原衣 PMX 的下摆链没有现有的裙摆命名。新版结合外套标签、原衣蒙皮权重和作者关节，要求多条挂在躯干且横向相连、垂至胯部的布料链，避开独立附件。实模识别 168 个节点、945 个布料接触面；GPU 驱动就绪后，Bullet 保留 **396／564** 个作者刚体，另外 22 个玩家／道具槽照常。五份原始模型覆盖这件外套、原有命名的两份正例及两份保留 Bullet 的负例。正式入口桌面模拟 XR 实放三份实模开始播放，均有最终双眼像素；外套双手柄托起两个原衣取样区 **78／110 mm**，先撤左手时右侧仍托住约 **93 mm**，全部撤掉后恢复。固定同一 VMD 与 60 Hz 步长，纯 CPU 的 Bullet 供数、步进和回写合计中位 **1.413→0.873 ms**、P95 **1.887→1.155 ms**。这不含新增的 GPU 衣摆计算，Quest 实得帧率仍待核对。公园空场另见[逐组隐藏对照](./scenery-render-work.md#海站公园空场逐组隐藏对照)。

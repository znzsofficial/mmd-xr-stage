# 指尖轻触：局部表面凹陷

角色物理开启时，已恢复追踪的指尖碰到有胸骨蒙皮的正面皮肤或贴身衣料，会压出一个随指尖滑动的小凹陷。手掌和深按仍由原有胸骨形变与 Bullet 接触处理；舞蹈手臂不作为玩家指尖。暂停在零秒仍可触碰，不新增开关。

## 实现与回退

- 输入是两手最多十个指腹胶囊，沿用物理层的尺寸、世界姿态与逐槽恢复掩码。模型恢复实际显示缩放后，先完成 VMD、物理、显示滤波、手动表情和胸骨响应，再取**当前蒙皮与顶点 morph 后的位置**。表面使用最近的胶囊轴点、切平面穿透深度和 `2.3 × 指腹半径` 的径向衰减；多指取最大局部压入，不累加。最大深度受 **3.8 mm** 与局部肩宽比例双重限制。
- 在贴近的顶点上沿法线向内移动，并按凹面斜率调整着色法线。上一帧接触的指尖轻压时降低本次胸骨响应；指尖更深入后恢复宽范围压缩。回弹时间常数 65 ms，停止后精确恢复原始浮点值。切换物理、隐藏、重绑定、跳帧与销毁会清理显示偏移；每次求值前先还原，既不修改手臂、手腕、刚体或碰撞定义，也不使用 Bullet 重置来做回弹。
- 按专用胸骨权重及正面法线选区，不按材质名称猜衣料。既支持单几何体共享给绘制／描边代理，也支持 loader 的分材质 morph 网格。没有附加 draw call、shader hook 或 morph 槽。非候选网格不创建逐帧层，也不上传顶点；无有效指尖且回弹完毕后不采样几何体。
- 第一次出现有效指尖才分帧建立索引。每帧名义预算 0.65 ms，在固定大小工作块之间查钟，并非硬时限；建表期间保留原有宽范围按压。缓存按模型实例持有，移除时释放。每帧先用受骨骼与激活 morph 影响的包围盒筛格，再仅对临近格精确蒙皮。
- 无合适胸骨、超限（16 万个输入顶点、96 万个索引、4096 个候选或 256 个格等）、候选采用 SDEF/QDEF、非相对位置 morph 或法线 morph 时，保留原有响应。三角边长相对手指过大时渐退局部效果，避免拖动整块粗面。不会给刚性盔甲、仅随脊柱的衣物或无合适权重的模型强行添加凹痕。它是显示形变，不新增布料自由度；不承诺所有 PMX 都适用。

## 实测（桌面 Chromium，2026-11-20）

在开发服务器打开 `scripts/fingertip-indent-probe.html?pixels`，选择**本机**一个 PMX 和配套贴图。探针用实际 runtime 与随包 Bullet，在暂停 0 秒、显示缩放 0.10、根绕 Y 旋转 32° 时，从远处给食指解锁，移到 A 点、滑至另一处 B 点，再撤手。仓库不含测试角色、路径或截图。

| 观察 | 一次本机运行 |
|---|---|
| 候选范围 | 32675 个源顶点中，506 个正面胸骨加权候选 |
| A 点 | 18 个顶点移动，目标的表面偏移约 2.03 mm；B 点为 0 |
| B 点 | 11 个顶点移动，目标约 2.03 mm；原 A 点回到 0 |
| 松手／丢失追踪 | 下一帧约 1.57 mm，90 帧后所有顶点完全还原；本角色上贴身恢复的 12 帧无新凹陷 |
| 关闭物理 | 再次接近、峰值约 1.23 mm 时关物理，当帧回到 0 |
| 实际出图 | 同姿态同材质，仅还原／应用表面顶点与法线；384² 画面有 698 个像素的 RGB 至少一通道相差 >2 |
| 局部 CPU 成本 | 同模型独立索引 20 个切片共 14.3 ms，最大切片 1.0 ms；热身后各 300 次，远处／接触平均 0.028／0.450 ms |

毫米数是绑定空间表面偏移乘显示缩放，**不含**胸骨/Bullet 同时造成的移动。微基准只计局部显示 pass 的 CPU 时间，不含渲染上传、物理、应用余下逻辑或 GPU 时间。旧 `scripts/tracked-pressure-probe.html` 的手掌与深入指压也保留明显的胸骨缩放变化，撤手及不合格追踪恢复后归零。

单测覆盖径向梯度、滑动、平滑释放、手掌／远指不触发、移动与缩放的 morph 分网格、被排除的手臂／背面、低密度及不兼容蒙皮回退。尚未验证 Quest 的真实手追抖动、两眼近看质感、双手多指同时按三角色时的帧耗或长时间显存趋势。

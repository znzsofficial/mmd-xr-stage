# 星门、庭院投影和两处星球远景

基线 `eea2217`。下列是两个生产构建的桌面 WebGL 实际提交；画布 1100×646、balanced、无演员、同机位。阴影开时包括方向光深度绘制。表中三角形不是可见像素，也不是 Quest 帧率。

**星门。** 六扇门的门框、底座、门背各用一次实例绘制；可点击门面、门牌和悬停指示仍各自独立。侧面贴近一扇门时是 29→26 次，但合并包围球多送 1,612 个三角形；门背是 43→30 次。固定星仪角度，三个机位各 710,600 像素，有 13／2／1 个像素任一色道差超过 8/255。六个目的地分别用屏幕鼠标、模拟 XR 扳机来回；核对悬停、按住不提前进入、松开进入正确房间、返回大厅。

**庭院投影。** 相机仍画原轿杆、宴桌及凳脚。仅深度绘制对小截面的旋转件、圆盘和弯杆减少圆周分段，共享原顶点。花轿加两桌的投影从 44,054 降至 33,750 个三角形。默认入口、正厅、门口、桌脚近景的同帧对照没有大于 8/255 的色道差；近看桌面时有 1,671 个像素超过此阈值，最大差 28/255。礼拜堂柏树不减面，只跳过光源看不到的连续尾段：默认树冠深度提交 34,560→7,680。将光移到树边复核，候选树影与完整树影逐像素一致，关掉树木投影才有明显差异。在两景中央分别放入同一演员，单独撤去演员投影可观测到 7,683／11,682 个变亮像素，前后计数一致。已验证设置里开关阴影以及回到别景时释放资源。

**星球。** 赭砾、霜岬远档分别为 9,396、11,460 面，离月心 18 m 以内恢复原来的 15,904 面，退到 20.5 m 才换回。只切换渲染索引；接缝、极点、原近景、行走支撑与风道均保留。屏幕落地朝向各自地表时，单独绘制月壳与基线逐像素相同。原始网格到远档的表面偏差不超过 16 mm；18 m 切档点以天体居中，赭砾／霜岬各有 47／9 个剪影像素变化。模拟双眼以实际控制器乘 01、02 风道往返，去程和返程均只切一次，两眼在同一帧选同一档，落地和转头保持近档。两个远档额外占用 125,136 字节索引，随房间释放。

**菌圃。** 把不透明的茎冠和发亮菌褶按 33 个林片排在原有两个索引缓冲中；每眼只裁掉自己视锥外的连续首尾，中间不能省就照画。半透明伞缘不重排。合影机位仅这两批从 98,624 降至 59,536 面，其余整帧差来自远月。屏幕合影与全景的静态菌圃 RGB 各通道最大差 1/255，林下和苗圃零差。模拟 XR 实际乘风到站转头，60 份眼图在相同姿态下比较裁剪和强制全画的菌伞、菌褶、伞缘，RGB 最大差 0。屏幕另验导览、步行、滚轮缩放、绕看、菌圃放置原衣演员和跨岛返程。

**能否说帧率提高？** 另用同一个桌面 WebGL 上下文固定机位，每组预热后做 16 对、每窗 12 次完整绘制，交替先后。开阴影的大厅入口，原独立静件与实例版本的 GPU 窗中位为 0.156→0.126 ms；北台仅切换两个远月索引，0.305→0.328 ms，未见稳定收益。菌圃、树影和家具均可确认少提交三角形，不把桌面的小差额换算成 Quest FPS。真机复测用同一画质、机位、阴影；先空场，再放同一角色并关物理，最后才单独开启角色物理。

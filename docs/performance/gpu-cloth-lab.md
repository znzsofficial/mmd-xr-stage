# 原衣裙摆：WebGPU 与 Bullet 三档对照

[打开裙摆实验](https://mmd-xr-stage.pages.dev/labs/cloth/) · [源码](../../experiments/gpu-cloth/) · [Bullet 关节迭代的独立测量](./bullet-step-profile.md#主迭代行循环)

这是独立的 WebGPU 查看器；正式舞台仍用 WebGL 和原有 Bullet。点「试用样裙」无需文件；用自己的原衣 PMX 选模型目录，或同时选 PMX 和贴图。目录有多个 PMX 时可换角色。实验只在设备本地读取文件，报告不含文件名、骨骼名或模型几何。

## 在 Quest 上试什么

先确认屏幕能显示角色，再点「进入 VR」。浏览器须同时支持 WebGPU 和 WebGPU 的沉浸式绑定；仅有 `navigator.gpu` 不能保证入场。[Meta 发布说明](https://developers.meta.com/horizon/downloads/package/browser/146.0) · [标准示例](https://immersive-web.github.io/webxr-samples/webgpu/vr-barebones.html)。没有绑定时，屏幕上的三个求解档仍可使用。

1. 在同一机位按左 **X** 切换 **原版 Bullet → 移除裙链 → GPU 裙摆**，看角色旁的模式牌。每档站稳至少十秒。第一、二档之间的差值包含去掉裙摆刚体、关节、接触与写回的全部影响；第二、三档才是在同一个剩余 Bullet 世界上加回 GPU 布料的代价。
2. 右 **A** 让同一个角色从站立过渡到仰卧抬腿，再按一次返站。手柄靠近裙边、抬起、撤回；看前幅是否聚向小腹，再从侧面看里衬、后摆和髋部。屏幕的「拨一次裙摆」在三档使用同一条相对腰骨的探针路径。
3. 退出 VR 点「导出对照 JSON」。只比较 `kind: xr`、同姿势、相同眼数、尺寸与实际 `refreshHz` 的窗口，最好回到第一档再测一次。`fps` 和 `intervalP95Ms` 取交付给页面的帧回调，不是合成器或 GPU 耗时；超 250 ms 的间断另记 `gaps`。支持 `timestamp-query` 才有 `clothGpuMsPerStepP50`（只含布料预测／约束，不含两眼绘制），缺样写 `null`。`bulletWorldP50Ms` 含零子步调用，尤其在桌面高刷新率下不能当作一次有效物理子步的耗时。

## 实际解算的内容

- 实验从 PMX 可识别的动态裙骨、骨父子与刚体关节还原相邻节点和腰口固定点。低分辨率节点驱动原始高分辨率蒙皮；衣料、色纹和里衬仍用所选模型的网格与基础贴图。材料使用实验光照与线性蒙皮，不复刻正式舞台的 toon、轮廓、SDEF/QDEF 或摆姿后的额外裙面修正。
- 「移除裙链」实际过滤传入原生后端的动态体，重编保留的刚体、关节双方和冲量索引；身体骨序不变，另外的两个手柄代理在三档中都保留。外裙和里衬如果受同一组裙骨加权，都会随之运动。不是关掉整身物理，也不是只在显示时隐藏刚体。
- 「GPU 裙摆」每个固定 1/72 秒步预测节点位置，进行五轮并行距离约束，使用允许接触的作者静态胶囊／球和两个手柄球投影。一次 XR 帧只推进一份状态，左右眼直接用同一 GPU 缓冲绘制；不逐帧读回布料。时间戳只稀疏异步读回两个数字。暂不解裙片自碰撞、独立内外层互撞或反作用力；首版也不支持任意非命名裙骨、复杂碰撞分组或手追／触觉。

## 已验和未验

桌面 Edge 在实际 WebGPU 设备上编译并派发 WGSL。一次本机原衣回归：39,340 个三角形，21 个带贴图的材质，288 个裙摆节点、24 个固定点；作者刚体／关节 **343／605 → 55／29**（不含两档共有的手柄）。

固定步进、同初始状态，重复「不拨／拨一次」，取同一时刻的 GPU 节点及原外裙蒙皮权重：外裙顶点的最大位移差峰值 **86.8 mm**，撤回约 3 秒后 **6.6 mm**；固定腰口误差为零。已观察仰卧抬腿与原衣侧面、恢复站立。这个数只衡量拨动，不证明抬腿时已无穿模，也不是全层接触质量验收。

独立的真实屏幕回调测试，两轮六段切换，每档取四个稳定秒窗，三档均在 **162–165 FPS 左右**。GPU 档四窗的布料求解时间戳中位为 **0.066–0.197 ms/步**，不含绘制；桌面帧率未显示有意义的分档收益。另外在同一设备上用测试用 XR 接口传入左右眼视点、两层真实 GPU 纹理和按键，检查每眼都有不同图像、只解一次、可换姿势／求解档、退出再入与导出。这不是 Quest 合成器测试。

本轮没有接入物理头显。**Quest 3S 能否维持 72 Hz、是否比正式舞台更快、实戴能否接受裙型与拨裙手感都待验。** 本机原始记录与原衣截图在 `local-review/verification/gpu-cloth/`。构建用 `pnpm build`（只重建实验可用 `pnpm build:cloth-lab`），运行 `pnpm preview` 后可访问 `/labs/cloth/`；独立回归入口见 [`smoke.cjs`](../../experiments/gpu-cloth/smoke.cjs)，设 `PLAYWRIGHT_CORE`、`CLOTH_URL`，可选 `CLOTH_MODEL_DIR` 与本机 `CLOTH_OUTPUT`。

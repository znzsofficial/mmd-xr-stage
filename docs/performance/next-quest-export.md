# Quest 3S 短测：教室看舞、暂停拨衣、回场导出

这轮只测 [Three 正式版](https://mmd-xr-stage.pages.dev)（功能提交 `37a0ef3`）。一趟回答三个问题：同一支舞开物理后是否掉帧、第一次开启时是否仍在等 Bullet 模块、回教室时在等模型还是动作。不用打开 Babylon 对比页、强设 120 Hz 或手动计时。

## 只做这一趟就够了

1. **关物理看 20 秒。** 新开页面进教室，手动放下上次的角色，绑同一支舞并播放。沿用原画质，阴影关；收起菜单，空手在固定机位观看。
2. **开物理看 20 秒。** 右手 **B → 更多 → 角色** 开物理，留意第一次开启卡不卡。收起菜单，在原机位继续看，先别碰角色。
3. **暂停拨衣，再恢复播放。** 用手柄从裙摆下方慢慢托起、横拨、撤手，看第一次接触是否有反应、撤手后能否自然落回。然后恢复播放，**关物理**。
4. **泳池 → 回教室 → 导出。** 保留角色和动作，用场景菜单去泳池再回教室。等角色重新跳起来，正常退出 VR，在准备页点 **「导出上次 VR 性能记录（JSON）」**。先下载，再刷新、关页或重进。反馈一份 JSON 加一句话：`第一次开物理___；拨衣___；回教室___。`

## 有时间再做

- **琉璃小行星**：教室 JSON 下载后另开一趟，不用再导出。在普通模式下用常速走过赤道、按 A 跳一次。反馈「脚下滑不滑、地平线转过去时舒不舒服」即可。[球面行走与摆放范围](../scenery/opal-planet.md)
- **礼拜堂播放帧率**：另日同一礼拜堂机位保持物理开，在「环境」只切阴影，开／关各稳定播放约 30 秒；收起菜单、空手，留一句哪段转头更顺。开关顺序写明即可。
- **校园三区**：另一次游玩再测。教室留一个正在播放的角色，去空草坪，穿廊架到泳池，再经草坪回教室，等角色继续跳。若要查资源增长，在相同布局下多往返几次，单独导出这次会话。两区旧报告已收到，不必专门复刻。
- 握姿、天空细纹、逐指轻触和 15 分钟长测可留到另一趟；这次的手柄拨衣以手感反馈为准。

## 收到报告后怎么读

- `physicsRebuilds[]` 筛教室成功开启事件。先看 `work.moduleAtFirstRequest` 为 `cold`、`warming` 还是 `warmed`，再看 `work.bulletModuleMs` 和 `durationWallMs`，并核对空场首帧及首次放置时间。[字段及下一步](./physics-warm-start.md)
- 播放只比前两段完整稳定窗：从 `windows[]` 筛教室、单角色、`playing: true`、空手、阴影关；按物理开关分组，开启组要求实际步进。排除起播、切换、播种、暂停拨衣和回场首窗。比较窗口 FPS、`modelUpdateCpuMs`、`bulletStepWork.worldStepMs`；全场 P95 不是分段值。
- 回场只看 `roomRestores[]` 中目标明确且成功的事件。若 `taskWallMs.body` 长，查 `motionWork[]` 的 `cache`、`evaluator`、`loadWallMs` 和 `setAnimationMs`。这些分项已在队列总时间里，不再相加。原始 JSON 留在本机即可。

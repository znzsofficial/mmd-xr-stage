# 下次 Quest 导出：一名角色、一次往返、一份 JSON

[线上舞台](https://mmd-xr-stage.pages.dev) · [固定版 `ad58264`](https://ada02f65.mmd-xr-stage.pages.dev)。下次有空戴头显时顺手做即可。优先看新版播动作时有多卡，以及回教室等角色的时间花在哪里。历史原始 JSON 保存在本机即可，仓库保留测量摘要。

## 最小一趟

1. **教室放一个角色。** 尽量用上次的原版「珠霜舒芙蕾」、配套贴图和同一段循环 VMD。用平时的画质，两段之间保持机位、画质、阴影、胸部受压设置不变，暂时空手。旧教室样本是阴影关、头显报告 120 Hz，不用为了这次短测强设 120 Hz。
2. **同一支舞，物理关／开各看约 30 秒。** 在 B → 更多 → 角色里只切「物理」，收起菜单，确认角色在跳，等切换稳定再计时。「胸部受压形变」保持默认开，「角色托裙摆」保持默认关。正常导出无需开额外物理调试。
3. **留角色在教室播放，去空草坪，再回教室一次。** 不收回角色、不退出 VR，用场景菜单直达就行。等角色出现并继续跳几秒，留意是首次放置慢、开物理时卡，还是回教室才等得久。
4. **正常退出 VR → 准备页「导出上次 VR 性能记录（JSON）」。** 在再次进入 VR、刷新或关页**之前**下载。发一份 JSON 加一句感受即可；无需私有模型、动作或视频。没有走完也可以发，少了哪个环节就标没测。

## 形变靠看，顺手即可

有手臂经过胸前的动作时，看手臂是否沿原舞姿通过，接触处的胸部和上衣是否压缩、移开后回弹，是否仍穿透或抖动。想看差别，可在性能采样后固定物理状态，重播同一小段，在「角色 → 胸部受压形变」关／开各看一次。**当前 JSON 不记这个开关、接触命中、位移或手臂轨迹**，需一句观察；没有合适动作就跳过。

可照填：`教室，物理关→开，开后___；回教室___，角色[继续跳／没恢复]；手过胸前___（或没测）。`

## 留给维护者

- 首次放置看 `placements[]` 中首次新建角色（`kind: model, moved: false`）的 `confirmToReadyFrameMs` 和 `modelWork`；切换物理单独看 `physicsRebuilds[]`。别把挑落点时间算进去。
- 从 `windows[]` 筛 `scenery: classroom, models: 1, playing: true` 的稳定窗口，按 `physics` 分组，排除起播、重建、回场、播种与额外交互。对照窗口 FPS、`modelUpdateCpuMs`、`physicsPoseWork`、`bulletStepWork.worldStepMs`，核对实际 Hz、图层尺寸与阴影。全场 P95 不当作某一段的值。
- 回场筛 `roomRestores[]` 中 `from: lawn, to: classroom, success: true`。先拆 `preQueueMs`、`queueToReadyMs`、`readyToFrameMs`；队列慢再看 `taskWallMs` 和各模型 `modelWork`，子阶段不重复相加。没有成功事件就记为缺样，不从相邻窗口推算。
- **另日再测**：暂停拨衣的静止／接近／首触／移开与追踪恢复；有合适托举动作再验独立掌面试验。地台／草坪各 15 分钟的长测要分场导出。以上、道具握姿和菜单舒适度都不是这次短测的前提。

# 母星走速：同一杆量、同一秒钟

旧版在 90 Hz 将轻推和满杆都走成约 2.29 米／秒，20 Hz 的满杆却只有 0.71 米／秒（[复现条件](./orbital-review.md)）。现在每个有输入的 XR 帧消耗实际经过的时间，沿用马达的 50 ms 上限；超过 1/60 秒就均分为最多三个子步。每步先向胶囊施加切向冲量与本星重力，再推进**同一段** Rapier 时间，最后按真实支撑与头部扫掠接回脚位。常速设置仍是 2.4 m/s，按脚底而不是胶囊中心的半径换算目标速度。

原生轴先过原有的 0.16 死区：0.25 映成 0.1071，平坦切面目标为 0.2571 m/s。保留轻推幅度和约 0.1 秒的加速时间常数。JS 后备仍直接起步。母星不再挂 Ecctrl 的独立渲染回调；离星后胶囊禁用，无坡面／悬挂查询。松杆仍检查脚下是否移除了道具，支撑未变无需推进物理。`seed` 只搬胶囊，位置、朝向和已在走动的切向速度来自当前玩家。

## 单线程复算

`node --single-threaded scripts/bench-home-walk.mjs`：本机 i9-13900HX、Node 26.12.1、已安装 Rapier 0.19.2 WASM；运行[正式胶囊](../../src/mmdVrShowcase/movement/homeCapsule.ts)和正式静态碰撞地形。从北台出生点向右推两秒，取**第二秒的脚位累计距离（米）**，包括走上实际坡面的高度差。未载入角色或道具。

| 显示 Hz | Rapier：原生 0.25 / 1 | JS：原生 0.25 / 1 | 每个移动帧的物理步 |
|---:|---:|---:|---:|
| 20 | 0.2574 / 2.4345 | 0.2573 / 2.4403 | 3 |
| 36 | 0.2573 / 2.4348 | 0.2573 / 2.4406 | 2 |
| 72 | 0.2573 / 2.4351 | 0.2573 / 2.4412 | 1 |
| 90 | 0.2573 / 2.4348 | 0.2573 / 2.4412 | 1 |
| 120 | 0.2573 / 2.4347 | 0.2573 / 2.4413 | 1 |

所有移动轨迹的 WASM 步长和均为 2 秒（误差 <1 µs）。停住一秒、再停放一秒：新增物理步与头部查询均为 0，漂移 <1 µm。预热后取五趟均耗时的中位数；20／36／72／90／120 Hz 满杆，每显示帧分别约 **65／44／26／29／27 µs**，JS 约 **2.2／1.1／1.7／1.7／1.2 µs**。桌面耗时含适配器和 WASM 求解，不含渲染，不用于推算 Quest FPS。

- **专项回归：** `pnpm exec vitest run --maxWorkers=1 src/mmdVrShowcase/movement/homeCapsule.test.ts`。真胶囊挡墙、偏置头位撞梁、松杆站住、已在行走时接入、反半球返航重新起步。
- **串行 IWER：** 在验证构建完成且没有其他图形进程时，从根目录运行 `node scripts/verify-home-walk-iwer.cjs`。读取 `dist`，自带静态服务；`XR_SMOKE_DIR` 可指向含 `iwer.js`、`node_modules/playwright-core` 的目录。一次 Quest 3 模拟双眼会话，延迟原生模块，用真实手柄轴 0.25 / 1 走两段，静止时放行模块，再反向走两段。核对逐帧原生轴、双眼矩阵、实际时钟、松杆漂移及最终导出的后端；写入 `local-review/verification/home-walk/`。五档固定频率的数据来自上面的 CPU 复算，而非模拟头显的标称刷新率。04 风道完整往返可另跑[既有串行路线](./planet-horizon.md#只补验-04-回站走速)。

**实际模拟手柄结果。** 同一会话的延迟组，常速轻推／满推在 JS 后备为 0.257／2.484 m/s，原生就绪后反方向为 0.257／2.471 m/s（双眼显示脚位在坡面上的路径长度）。旧发行版同轴量 0.25 从约 0.257 跳到 2.15 m/s。另做独立的延迟／拒载首入及再入：新版轻推均约 0.26 m/s，右杆 30° 转向仍可用，静止放行时无脚位跳变。记录在 `local-review/verification/planet-repair/`；不是 Quest 性能记录。

# 屏幕观看

普通电脑或触屏浏览器只需支持 WebGL 2。在准备页导入模型包、配套贴图和动作，点「屏幕观看」。没导入文件也可以进场逛布景。

- **镜头**：拖动画面环绕，滚轮或双指缩放，鼠标右键拖动平移。「重置视角」回到当前布景的起始机位；选中角色后「看向选中项」会按尺寸重新取景。
- **摆放**：打开「背包」，点某个角色或物件，再点地上允许放置的位置；也可点「放在中央」。放置时再点「背包」可换一个文件。每个布景最多同时摆 3 个角色和 3 个物件。
- **动作**：选中已放置的角色，在「用于身体」或「用于表情」选动作。下方可以暂停、循环、拖进度或开关物理。支持腕骨的角色还可选择左手或右手拿点亮的星辉光剑。收起背包后，点角色会再打开工具。
- **继续看**：返回准备页后，点「屏幕观看」会恢复当前所选布景的布局；在支持 VR 的同一页面点「继续上次舞台」可戴头显续看。换浏览器、换设备、刷新或关闭页面不会传递模型。光剑和机位不会随布局保存。

手追拨衣、手柄握键、吹泡泡和盖印需进入 VR。屏幕观看不会生成或覆盖 Quest 性能记录。

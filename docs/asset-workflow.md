# 资产导入与继续舞台

## 导入

- 可选择完整文件夹、ZIP 或单个文件，也可拖放。ZIP 按需加载解压库，在本地解压，不上传文件。
- ZIP 路径以包名为前缀，内部相对路径不变。不同包的同名纹理不会互相替换。
- 同路径（忽略大小写、统一分隔符）的后续文件不覆盖原文件，会列在冲突报告里。可重命名包，或清空后重新导入。
- 检查报告中的缺失/歧义引用提供“为此引用选择资源文件”。选中的文件仅绑定到该模型的该引用；精确匹配完整 ZIP 相对路径的普通文件也可补入，不会使用另一个 ZIP 的同名纹理。
- 后续导入动作或纹理不会重新选中已取消选择的模型；只为本批接纳的新模型/物件自动分配空槽位。
- 非 UTF-8 文件名可选择 Shift-JIS 或 GBK 后重新导入。暂不支持加密 ZIP。
- 导入预算：4096 项、单文件 256 MiB、已导入资产总计 512 MiB；大模型仍可能因 GPU 内存限制无法运行。
- 导入检查读取 PMX/PMD 纹理引用及 glTF 外部 buffer/image URI，报告缺失、重名和按文件名回退匹配。检查提示不禁止尝试加载，实际渲染以舞台加载结果为准。

## 继续与重新开始

- 正常退出 XR 时保存舞台快照：当前模型/物件组合、位置/旋转/缩放、可见性、模型材质参数、播放位置、播放/循环状态及物理开关。
- **继续上次舞台**使用快照的文件组合；准备页当前选择不会覆盖它。
- **按当前选择重新开始**从零播放并使用默认模型位置，不自动应用旧快照。
- 快照只存在当前页面内存中；刷新或关闭页面会清除。清空资产按钮也会释放上次舞台的文件引用。
- 若尚在加载或物理重建中退出，保留上一份完整快照，避免以半成品覆盖。
- 即使加载队列已结束，只要存在未恢复的模型、动作或纹理告警，退出也不会覆盖上一份完整快照。
- 不序列化 Bullet 模拟中的速度/接触缓存；恢复后按保存的播放时刻重新初始化物理。

## 纹理失败与重试

模型解析成功但纹理解码/解析失败时，舞台会保留可用模型并显示完整诊断。点击“重试失败项”会重建该模型、保留其摆放和材质设置，并把动作重新绑定到新模型 ID；其他成功模型不重建。缺失的本地文件需返回准备页补入后重新进入。

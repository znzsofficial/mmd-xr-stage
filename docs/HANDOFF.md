## 下一轮工作顺序

1. **定位卡顿。** 看新版放置 `loaderStagesMs` 的最大阶段；固定机位播放同一段 VMD，物理关／开各约 30 秒；退出立即导出。持续观看 15 分钟另测。目前没有依据调上传批次。
2. **验收交互。** 左右手各取一次玩具；侧握键使用，扳机操作菜单。收回后暂停 VMD，用指尖和掌心拨衣，移出视野再返回，观察是否弹飞。顺手检查白按钮／滑块上的准星、角色侧边工具是否挡脸，以及切景返回和同页续场是否恢复摆法。[操作说明](./vr-controls.md)
3. **验收角色持物。** 拿玩具 → 扳机点角色 → 递道具 → 选角色的手。检查握柄贴合、左右换手、微调和随 VMD 运动。模拟手柄已完成交接、微调、播放与收回，238 项测试通过，本地指定原版 PMX 的左右腕均已识别。泡影渡口、返场染印和纸鸢站仍是候选创意。

- 用户主要观看自选游戏角色，手柄操作菜单，手追体验衣物；内置建模优先做环境。约束见 [PRODUCT](../PRODUCT.md)、[DESIGN](../DESIGN.md) 和 [AGENTS](../AGENTS.md)。
- 先看 `git status --short --branch`。用户模型只在本机使用；`.openchamber/` 和 `sample/` 不暂存。生产后端是 WebGL + WebXR。
- 功能改完并验证通过后，由维护代理按[发布约定](./deployment.md)正常推送、上线并核对主域名，回报可用链接。无需让用户执行发布命令；这项约定不授权强推。
